## Блок R. Основы: потери, метрики, bias/variance, transfer learning, adversarial, RL

**R1. Задача — детекция усталости водителя; критично не пропустить усталого. Какая метрика подходит лучше всего?**
- [ ] Accuracy
- [ ] Precision
- [x] Recall
- [ ] Значение функции потерь
> 📌 **P2 · RELATED** · [Stanford CS230, зима 2019, 2(c)](https://cs230.stanford.edu/files/cs230exam_win19_soln.pdf)

Recall = TP/(TP + FN): доля найденных настоящих положительных случаев. Пропуск усталого водителя (FN) дороже ложной тревоги.

**R2. 99 % объектов принадлежат классу 0. Модель всегда отвечает «0». Что верно?**
- [x] Accuracy ≈ 99 %, но модель бесполезна: recall по классу 1 равен 0
- [ ] Модель отличная, так как accuracy высокая
- [ ] Precision по классу 1 равна 1
- [ ] F1 по классу 1 равна 0.99

При дисбалансе accuracy обманчива; по редкому классу recall = 0 и F1 = 0.

**R3. Какая из потерь устойчивее к выбросам в регрессии?**
- [ ] MSE
- [x] MAE
- [ ] Обе одинаково
> 📌 **P2 · RELATED** · [Stanford CS230, зима 2019, 5(b)](https://cs230.stanford.edu/files/cs230exam_win19_soln.pdf)

**R4. Чему равна KL-дивергенция D_KL(p ‖ q) между one-hot целью p и предсказанием q по сравнению с кросс-энтропией H(p, q)?**
- [x] Они равны, так как H(p) = 0
- [ ] KL всегда вдвое больше
- [ ] KL всегда меньше на 1
- [ ] Они несравнимы
> 📌 **P3 · RELATED** · Теория, тема 17

H(p, q) = H(p) + D_KL(p ‖ q); энтропия one-hot распределения равна 0.

**R5. Сопоставьте потерю и задачу.**
= Регрессия; Бинарная классификация; Мультиклассовая классификация
~ MSE :: Регрессия
~ Huber :: Регрессия
~ Binary Cross-Entropy :: Бинарная классификация
~ Sparse Categorical Cross-Entropy :: Мультиклассовая классификация
~ Kullback–Leibler divergence :: Мультиклассовая классификация
> 📌 **P3 · RELATED** · вариант задания про потери, см. P12

KL относят к мультиклассовой классификации: при one-hot целях она совпадает с кросс-энтропией. Sparse CE — та же CE, но метки заданы индексами.

**R6. Классификатор нужно обучить так, чтобы выход можно было трактовать как вероятность. Какую потерю выбрать?**
- [ ] Hinge: max(0, 1 − y·f(x))
- [x] Логистическую: log(1 + e^{−y·f(x)})
- [ ] Обе подходят одинаково
> 📌 **P2 · RELATED** · [Stanford CS230, зима 2019, 5(g)](https://cs230.stanford.edu/files/cs230exam_win19_soln.pdf)

Логистическая потеря — отрицательный логарифм правдоподобия, поэтому σ(f(x)) интерпретируется как вероятность. У hinge такой интерпретации нет.

**R7. Редкий класс составляет 1 % данных (детекция объектов). Какая потеря рассчитана на такой дисбаланс?**
- [ ] MAE
- [x] Focal loss
- [ ] Hinge
- [ ] Poisson loss
> 📌 **P3 · RELATED** · [Lin et al., 2017](https://arxiv.org/abs/1708.02002)

Focal loss умножает CE на (1 − pₜ)^γ и приглушает вклад лёгких примеров, чтобы редкие не терялись.

**R9. Сеть обучили на 20 примерах: обучение сошлось, но train-ошибка высокая. Решили взять 10 000 примеров. Верно ли это решение?**

**R11. Предобученная на миллионе примеров сеть применяется к задаче со 100 примерами. Что делают при transfer learning?**

- [ ] Обучают всю сеть с нуля с большим learning rate
- [ ] Удаляют все свёрточные слои
