## Блок Q. Экзамен: расчётные задачи

**Q1. MLP: три входа 1, 2 и 3, веса к ним 4, 5 и 6. Активация линейная с постоянным множителем 3, то есть f(x) = 3x. Каким будет выход?**
- [ ] 32
- [ ] 64
- [x] 96
- [ ] 128
> 📌 **P0 · EXACT** · вопрос с экзамена (№ 9) · [InterviewBit, тест № 1](https://www.interviewbit.com/deep-learning-interview-questions/) · копия: [Brainly](https://brainly.com/question/37647145)

Взвешенная сумма: 1·4 + 2·5 + 3·6 = 4 + 10 + 18 = 32. Активация: f(32) = 3·32 = **96**. Смещения нет. Вариант 32 — ловушка для тех, кто забыл применить активацию.

**Q2. Изображение 28×28, ядро 7×7, stride 1, без padding. Какой размер будет у результата свёртки?**
- [ ] 20×20
- [ ] 21×21
- [x] 22×22
- [ ] 25×25
> 📌 **P0 · EXACT** · вопрос с экзамена (№ 27) · [InterviewBit, тест № 2](https://www.interviewbit.com/deep-learning-interview-questions/) · **ключ источника под вопросом**

H_out = (H_in + 2p − k)/s + 1 = (28 + 0 − 7)/1 + 1 = **22**. Проверка: левый край ядра может стоять в позициях 0…21 — это 22 позиции.

> ⚠️ При двух извлечениях страницы InterviewBit ответ этого теста определился по-разному (21×21 и 22×22). Padding в условии не указан; при padding 0 верно **22×22**. Ответ 21×21 получится только при ошибке «28 − 7 = 21» без «+1».

**Q3. CNN для изображения 128×128×3. Нотация: CONV-K-N — N фильтров K×K, padding 0, stride 1; POOL-2 — окно 2×2, stride 2; FC-N — N нейронов. Посчитайте размеры карт, число весов и смещений для слоёв CONV-9-32, POOL-2, CONV-5-64, POOL-2, CONV-5-64, POOL-2, FC-3.**
> 📌 **P1 · RELATED** · [Stanford CS230, зима 2019, 3(d)](https://cs230.stanford.edu/files/cs230exam_win19_soln.pdf)

| Слой | Выход | Веса | Смещения |
|---|---|---|---|
| CONV-9-32 | 120×120×32 | 9·9·3·32 = 7 776 | 32 |
| POOL-2 | 60×60×32 | 0 | 0 |
| CONV-5-64 | 56×56×64 | 5·5·32·64 = 51 200 | 64 |
| POOL-2 | 28×28×64 | 0 | 0 |
| CONV-5-64 | 24×24×64 | 5·5·64·64 = 102 400 | 64 |
| POOL-2 | 12×12×64 | 0 | 0 |
| FC-3 | 3 | 12·12·64·3 = 27 648 | 3 |

Размеры: 128 − 9 + 1 = 120; 60 − 5 + 1 = 56; 28 − 5 + 1 = 24. После FC-3 нужна softmax (три взаимоисключающих класса).

**Q4. Softmax применили к вектору [0.3, 0.3, 0.3]. Что получится?**
- [x] [0.33, 0.33, 0.33]
- [ ] [0.3, 0.3, 0.3]
- [ ] [1, 0, 0]
- [ ] [0.1, 0.1, 0.1]
> 📌 **P1 · RELATED** · [Stanford CS230, зима 2019, 3(f)](https://cs230.stanford.edu/files/cs230exam_win19_soln.pdf)

Все логиты равны — все экспоненты равны, каждая компонента равна 1/3. Softmax инвариантен к сдвигу, сама величина 0.3 не важна.

**Q5. Верно ли: двухслойная сеть с 5 нейронами в каждом слое имеет всего 60 параметров (весов и смещений)?**
- [x] Верно
- [ ] Неверно
> 📌 **P2 · RELATED** · [Stanford CS230, осень 2019, 1(a)](https://cs230.stanford.edu/files/cs230exam_fall19_soln.pdf)

Ключ «верно» получается при входе размерности 5: (5·5 + 5) + (5·5 + 5) = 30 + 30 = 60. Размер входа в условии не указан — на экзамене проговорите это допущение.

**Q6. Вход 10×10×3. Сравниваем полносвязный слой из 2 нейронов (с bias, вход вытягивается в вектор) и свёрточный слой из трёх фильтров 2×2 (с bias, padding 0, stride 2). Какая разница в числе обучаемых параметров?**
- [ ] У полносвязного на 566 меньше
- [ ] У свёрточного на 566 меньше
- [ ] У свёрточного на 564 меньше
- [x] У свёрточного на 563 меньше
- [ ] Ничего из перечисленного
> 📌 **P2 · RELATED** · [Stanford CS230, осень 2019, 1(b)](https://cs230.stanford.edu/files/cs230exam_fall19_soln.pdf)

Полносвязный: 300·2 + 2 = 602. Свёрточный: (2·2·3 + 1)·3 = 13·3 = 39. Разница: 602 − 39 = **563**.

**Q7. Какой размер выхода у свёрточного слоя из предыдущей задачи (три фильтра 2×2, stride 2, padding 0, вход 10×10×3)?**
- [ ] (5, 5, 4)
- [x] (5, 5, 3)
- [ ] (4, 4, 4)
- [ ] (4, 4, 3)
> 📌 **P2 · RELATED** · [Stanford CS230, осень 2019, 1(c)](https://cs230.stanford.edu/files/cs230exam_fall19_soln.pdf)

(10 − 2)/2 + 1 = 5; число каналов равно числу фильтров — 3.

**Q8. 300 входных признаков, один скрытый слой из 80 нейронов, один выход. Сколько всего параметров?**
- [ ] 24 080
- [x] 24 161
- [ ] 24 081
- [ ] 24 160
> 📌 **P2 · RELATED** · [Stanford CS230, зима 2020, 1(d)](https://cs230.stanford.edu/files/cs230exam_win20_soln.pdf)

Веса: 300·80 + 80·1 = 24 080. Смещения: 80 + 1 = 81. Всего **24 161**. Вариант 24 080 — только веса.

**Q9. В сети с одним скрытым слоем забыли промежуточную активацию: ŷ = σ(W[2](W[1]x + b[1]) + b[2]). Покажите, что это логистическая регрессия: выпишите w′ и b′.**
> 📌 **P2 · RELATED** · [Stanford CS230, зима 2020, 1(f)](https://cs230.stanford.edu/files/cs230exam_win20_soln.pdf)

Раскрываем скобки: ŷ = σ(W[2]W[1]x + W[2]b[1] + b[2]). Значит w′ = W[2]W[1] (в столбцовой записи — транспонировать), b′ = W[2]b[1] + b[2]. Та же модель, что логистическая регрессия σ(w′x + b′), — линейные слои без нелинейности схлопываются в один.

**Q10. 10 000 обучающих объектов, размер батча 200. Сколько итераций (обновлений весов) в одной эпохе?**
- [x] 50

- [ ] 10 000
- [ ] 2 000 000
> 📌 **P1 · RELATED** · [Top 45, № 23](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

10 000 / 200 = 50.

**Q11. Сколько параметров у свёрточного слоя 3×3 с 64 входными и 128 выходными каналами (с bias)?**
- [x] 73 856
- [ ] 73 728
- [ ] 1 152
- [ ] 577
> 📌 **P3 · SAME_CONCEPT** · к вопросу № 23

(3·3·64 + 1)·128 = 577·128 = 73 856. Вариант 73 728 — без bias, 577 — один фильтр.

**Q12. Вход 32×32, ядро 5×5, stride 2, padding 0. Размер выхода?**
- [x] 14×14
- [ ] 13×13
- [ ] 15×15
- [ ] 16×16
> 📌 **P3 · SAME_CONCEPT** · к вопросу № 27

⌊(32 − 5)/2⌋ + 1 = ⌊13.5⌋ + 1 = 14. Сначала округляем вниз, потом прибавляем 1.

**Q13. Вход 28×28, ядро 3×3, stride 1, padding 1. Размер выхода?**
- [x] 28×28
- [ ] 26×26
- [ ] 27×27
- [ ] 30×30
> 📌 **P3 · SAME_CONCEPT** · к вопросу № 27

(28 + 2·1 − 3)/1 + 1 = 28 — padding «same».

**Q14. MaxPool 2×2 со stride 2 применили к тензору 28×28×32. Какой размер выхода и сколько параметров у слоя?**
- [x] 14×14×32, 0 параметров
- [ ] 14×14×32, 32 параметра
- [ ] 14×14×16, 0 параметров
- [ ] 27×27×32, 0 параметров
> 📌 **P3 · SAME_CONCEPT** · к вопросам № 17 и № 27

(28 − 2)/2 + 1 = 14 по каждой стороне; pooling идёт по каждому каналу отдельно, поэтому каналов остаётся 32; обучаемых параметров у pooling нет.

**Q15. Сколько параметров у свёрточного слоя 5×5, 3 входных канала, 16 фильтров, с bias?**
