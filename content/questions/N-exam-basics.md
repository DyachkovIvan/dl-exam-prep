## Блок N. Экзамен: основы, активации, оптимизация, backprop, инициализация

**N1. Какова роль функции активации в нейронной сети?**
> 📌 **P0 · EXACT** · вопрос с экзамена (№ 1) · [Top 45 Deep Learning Interview Questions, № 6](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf) · та же идея: [Stanford CS230, зима 2019, 3(e)](https://cs230.stanford.edu/files/cs230exam_win19_soln.pdf)

Активация вносит **нелинейность**. Без неё слои складываются в одно линейное отображение: W₂(W₁x + b₁) + b₂ = W′x + b′, и сеть любой глубины эквивалентна линейной (логистической) регрессии — не выучит даже XOR. С нелинейностью сеть становится универсальным аппроксиматором. На выходном слое активация ещё и задаёт диапазон ответа: вероятность (sigmoid), распределение (softmax). Примеры: sigmoid, tanh, ReLU, softmax.

> ⚠️ В источнике роль описана как «решает, срабатывает ли нейрон». Это упрощение; на экзамене ключевое слово — **нелинейность**.

**N2. Что такое функция активации и зачем она нужна?**
> 📌 **P0 · NEAR_EXACT** · вопрос с экзамена (№ 2) · [InterviewBit — Deep Learning Interview Questions, для начинающих № 25](https://www.interviewbit.com/deep-learning-interview-questions/)

Функция f, которую нейрон применяет к взвешенной сумме входов: a = f(wᵀx + b). Нужна, чтобы сеть была нелинейной моделью (см. N1) и могла выучивать сложные зависимости; на выходе подбирается под задачу (sigmoid — вероятность класса, softmax — распределение по классам, линейная — регрессия).

**N3. Что такое функции Softmax и ReLU?**
> 📌 **P0 · EXACT** · вопрос с экзамена (№ 14) · [Top 45, № 12](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

**Softmax:** softmax(z)ᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}. Превращает вектор логитов в распределение вероятностей: все компоненты в (0, 1), сумма = 1. Ставится на **выходной** слой мультиклассовой классификации.
**ReLU:** ReLU(x) = max(0, x); производная 1 при x > 0 и 0 при x < 0. Дёшево считается, не насыщается при x > 0 — стандарт для **скрытых** слоёв. Минус — «умирающие» нейроны (при x < 0 градиент нулевой).

**N4. Сопоставьте тип задачи и функцию активации выходного слоя.**
= Sigmoid; Softmax; ReLU
~ Бинарная классификация :: Sigmoid
~ Мультиклассовая классификация :: Softmax
~ Multi-label классификация :: Sigmoid

> 📌 **P0 · UNCONFIRMED** · вопрос с экзамена (№ 18) · источник не найден

- **Бинарная** — sigmoid: одна вероятность положительного класса.
- **Мультиклассовая** — softmax: классы взаимоисключающие, вероятности в сумме 1.
- **Multi-label** — sigmoid на каждом выходе независимо: метки не исключают друг друга.
- **Регрессия** — строго говоря, стандарт — **линейный выход без активации**. В задании из трёх кандидатов регрессии остаётся ReLU; это допустимо, только если целевая величина неотрицательна (цена, количество). Отдельно скажите на экзамене, что ReLU — прежде всего активация скрытых слоёв.

> ⚠️ Точную форму задания восстановить не удалось: пользователь помнит 4 задачи и 3 кандидата. Ключ «регрессия → ReLU» — вывод из этой структуры, а не из найденного источника.

**N7. Какая из функций активации может приводить к затуханию градиента?**
- [ ] ReLU
- [x] Tanh
- [ ] Leaky ReLU
- [ ] Ни одна из перечисленных
> 📌 **P1 · RELATED** · [Stanford CS230, зима 2019, 1(b)](https://cs230.stanford.edu/files/cs230exam_win19_soln.pdf)

Tanh насыщается на обоих хвостах: tanh′(x) = 1 − tanh²(x) → 0 при |x| → ∞, и произведение таких множителей по слоям затухает. У ReLU производная при x > 0 равна 1, у Leaky ReLU нигде не равна нулю.

> ⚠️ «Умирающий» ReLU — другая проблема (нулевой градиент при отрицательном входе), в ключе CS230 это не считается затуханием градиента.

**N8. Верно ли: градиент, прошедший назад через tanh, по модулю всегда не больше входящего градиента?**

Градиент умножается на tanh′(x) = 1 − tanh²(x) ∈ (0, 1], поэтому по модулю не растёт.

**N11. Что такое Leaky ReLU и зачем он нужен?**
> 📌 **P1 · RELATED** · [Top 45, № 37](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

LeakyReLU(x) = x при x > 0 и αx при x ≤ 0 (α ≈ 0.01). В отрицательной области градиент равен α, а не 0, поэтому нейрон, ушедший в отрицательную зону, может продолжить обучаться — решение проблемы «умирающего ReLU».

**N13. Что такое градиентный спуск?**
> 📌 **P0 · EXACT** · вопрос с экзамена (№ 12) · [Top 45, № 8](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

Итеративный метод минимизации функции потерь L(θ): на каждом шаге параметры сдвигаются против градиента, θ ← θ − η·∇θL, где η — learning rate. Антиградиент — направление наискорейшего локального убывания. В невыпуклых задачах гарантируется только приход в стационарную точку (локальный минимум, седло), а не глобальный минимум.

> ⚠️ В источнике написано, что цель — найти «локально-глобальный минимум». Корректно: метод ищет **локальный** минимум; глобальный гарантирован только для выпуклых функций.

- [x] 4, 3, 1, 5, 2
- [ ] 1, 2, 3, 4, 5
- [ ] 3, 2, 1, 5, 4
- [ ] 5, 4, 3, 2, 1
> 📌 **P0 · NEAR_EXACT** · вопрос с экзамена (№ 13, «шаги градиентного спуска») · [InterviewBit, тест № 3](https://www.interviewbit.com/deep-learning-interview-questions/)

**N15. Что такое пакетный градиентный спуск (Batch Gradient Descent)?**
> 📌 **P0 · EXACT** · вопрос с экзамена (№ 25) · [InterviewBit, для начинающих № 22](https://www.interviewbit.com/deep-learning-interview-questions/)

Градиент на каждом шаге считается **по всей обучающей выборке**: θ ← θ − η·(1/N)Σᵢ∇ℓᵢ. Один шаг за эпоху, градиент точный, траектория гладкая. Минусы: очень медленно и дорого на больших данных, выборка может не поместиться в память, нет «шума», помогающего выходить из седловых точек.

**N16. Чем отличаются пакетный (batch), мини-пакетный (mini-batch) и стохастический градиентный спуск?**
> 📌 **P0 · NEAR_EXACT** · вопрос с экзамена (№ 26) · [Top 45, № 16](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf) · [InterviewBit, для начинающих № 23](https://www.interviewbit.com/deep-learning-interview-questions/)

| | Batch GD | Mini-batch GD | Stochastic GD |
|---|---|---|---|
| Объектов на шаг | все N | B (обычно 32–512) | 1 |
| Шагов за эпоху | 1 | ⌈N/B⌉ | N |
| Градиент | точный | несмещённая оценка, умеренный шум | очень шумный |
| Плюсы | стабильная сходимость | эффективен на GPU, стандарт | частые обновления, онлайн-обучение |
| Минусы | медленно, много памяти | нужно подбирать B | колебания, не векторизуется |

**N19. Почему mini-batch градиентный спуск так полезен на практике?**
> 📌 **P1 · RELATED** · [Top 45, № 36](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

Эффективно использует параллелизм GPU (в отличие от SGD по одному объекту); оценка градиента заметно точнее, чем по одному объекту, но шаг намного дешевле, чем по всей выборке; батч помещается в память; умеренный шум помогает выходить из седел и, по наблюдениям, чаще приводит в «плоские» минимумы, которые лучше обобщаются.

**N20. Что произойдёт, если learning rate слишком мал или слишком велик?**

**N22. Объясните алгоритм оптимизации Adam.**
> 📌 **P1 · RELATED** · [Top 45, № 39](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

Adam = Momentum + RMSProp + коррекция смещения. Хранит скользящее среднее градиента m_t (импульс) и квадрата градиента v_t (масштаб по каждой координате); делит их на (1 − βᵗ), чтобы убрать смещение к нулю в начале, и делает шаг θ ← θ − η·m̂/(√v̂ + ε). Дефолты: β₁ = 0.9, β₂ = 0.999, η = 10⁻³.

**N23. Adam: sₜ = β₂sₜ₋₁ + (1 − β₂)gₜ², s₀ = 0, градиенты независимы и одинаково распределены. Чему равно E[sₜ]?**
- [x] E[g²]·(1 − β₂ᵗ)
- [ ] E[g²]
- [ ] E[g²]·β₂ᵗ
- [ ] E[g²] / (1 − β₂ᵗ)
> 📌 **P2 · RELATED** · [Stanford CS230, зима 2019, 6(c)](https://cs230.stanford.edu/files/cs230exam_win19_soln.pdf)

sₜ = (1 − β₂)Σᵢ β₂^{t−i} gᵢ², E[sₜ] = E[g²](1 − β₂)(1 + β₂ + … + β₂^{t−1}) = E[g²](1 − β₂ᵗ). Оценка занижена в (1 − β₂ᵗ) раз — отсюда деление на этот множитель (bias correction). Без него первые шаги слишком велики, и тем сильнее, чем ближе β₂ к 1.

Параметры, значения которых задаются **до** обучения и не оптимизируются градиентом: архитектура (число слоёв, нейронов), learning rate, batch size, число эпох, коэффициенты регуляризации. Обычные параметры (веса и смещения) обучаются.

**N28. Можно ли построить нейронную сеть только на основе линейной регрессии?**
- [x] Да, но стек линейных слоёв останется линейной моделью
- [ ] Нет, нейросеть обязана содержать нелинейность
- [ ] Да, и глубина даст выигрыш в выразительности даже без активаций
> 📌 **P0 · NEAR_EXACT** · вопрос с экзамена (№ 22) · [InterviewBit, для опытных № 10](https://www.interviewbit.com/deep-learning-interview-questions/)

Один нейрон с линейной активацией и MSE — это и есть линейная регрессия. Сеть из линейных слоёв построить можно, но композиция линейных функций линейна: W₂(W₁x + b₁) + b₂ = W′x + b′. Глубина без нелинейностей ничего не добавляет — такая сеть решает только линейные задачи.

**N29. Что такое многослойный перцептрон (MLP)?**
> 📌 **P1 · RELATED** · [Top 45, № 3](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

Полносвязная сеть прямого распространения: входной слой, один или несколько скрытых слоёв с нелинейной активацией, выходной слой. Каждый нейрон связан со всеми нейронами предыдущего слоя. В отличие от однослойного перцептрона, решающего только линейно разделимые задачи, MLP моделирует нелинейные зависимости. Обучается обратным распространением ошибки.

**N30. Чем сеть прямого распространения отличается от рекуррентной?**
> 📌 **P1 · RELATED** · [Top 45, № 10](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

В сети прямого распространения сигнал идёт только от входа к выходу, циклов нет, выход зависит лишь от текущего входа. В RNN есть рекуррентная связь: скрытое состояние hₜ зависит от входа xₜ и прошлого состояния hₜ₋₁, поэтому сеть «помнит» предыдущие элементы последовательности; веса общие для всех шагов времени.

**N31. Что такое функция стоимости (cost function)?**
> 📌 **P1 · RELATED** · [Top 45, № 7](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

Число, измеряющее, насколько предсказания модели расходятся с правильными ответами (обычно среднее функции потерь по объектам). Обучение — минимизация этой функции; её градиент по весам считает backprop. Примеры: MSE для регрессии, кросс-энтропия для классификации.

**N32. Как выбрать число скрытых слоёв и нейронов?**
> 📌 **P1 · RELATED** · [InterviewBit, для опытных № 11](https://www.interviewbit.com/deep-learning-interview-questions/)

Формулы нет, это гиперпараметры. Начинают с простой архитектуры (ширина между размером входа и выхода, часто степень двойки) и усложняют, пока улучшается метрика на валидации; подбирают перебором или байесовской оптимизацией. Мало нейронов — недообучение, много — переобучение и дорогое обучение (компенсируется регуляризацией).

**N33. Почему глубокая сеть лучше неглубокой?**
> 📌 **P1 · RELATED** · [Top 45, № 43](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf) · ответ, принятый в [Stanford CS230, зима 2020, 1(e)](https://cs230.stanford.edu/files/cs230exam_win20_soln.pdf)

Сети с одним скрытым слоем достаточно, чтобы приблизить любую непрерывную функцию, но ей может понадобиться экспоненциально много нейронов. Глубокая сеть представляет те же функции **с гораздо меньшим числом параметров** и строит иерархию признаков (края → части → объекты). Именно «меньше нейронов/параметров» принимали как правильный ответ в CS230.

**N34. Что такое обратное распространение ошибки (backpropagation)?**
> 📌 **P1 · RELATED** · [Top 45, № 9](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf) · [InterviewBit, для начинающих № 11](https://www.interviewbit.com/deep-learning-interview-questions/)

Алгоритм вычисления градиента функции потерь по всем весам сети через цепное правило. Прямой проход считает и запоминает активации; обратный проход идёт от выхода к входу: δˡ = (Wˡ⁺¹)ᵀδˡ⁺¹ ⊙ σ′(zˡ), ∂L/∂Wˡ = δˡ(aˡ⁻¹)ᵀ. Затем оптимизатор (SGD, Adam) обновляет веса. Backprop сам по себе считает градиент, а не оптимизирует.

**N35. Чем обратное распространение в рекуррентных сетях отличается от обратного распространения в сетях прямого распространения?**
> 📌 **P0 · NEAR_EXACT** · вопрос с экзамена (№ 24) · [InterviewBit, для опытных № 7](https://www.interviewbit.com/deep-learning-interview-questions/)

В RNN используется **BPTT (backpropagation through time)**:
- сеть **разворачивается по времени** в глубокую сеть из T копий одного слоя;
- градиент идёт не только по слоям, но и **назад по шагам времени** через рекуррентную связь;
- веса **общие** для всех шагов, поэтому их градиенты **суммируются** по всем шагам;
- эффективная глубина равна длине последовательности → сильное затухание или взрыв градиента (множитель W_hh в степени числа шагов);
- вычисления по времени нельзя распараллелить, память растёт с длиной; на практике применяют усечённый BPTT.

> ⚠️ В источнике ответ сводится к «у узлов RNN есть дополнительная петля». Этого мало: назовите разворачивание, суммирование градиентов общих весов и затухание/взрыв.

**N36. Вычислите ∂J/∂w для ŷ = w·x, где w — число, x ∈ ℝ^{1×m}, J = (1/m)‖ŷ − y‖².**
- [ ] (1/m)(ŷ − y)xᵀ
- [ ] (1/m)(ŷ − y)x
- [x] (2/m)(ŷ − y)xᵀ
- [ ] (2/m)(ŷ − y)x

J = (1/m)Σᵢ(wxᵢ − yᵢ)², ∂J/∂w = (2/m)Σᵢ(ŷᵢ − yᵢ)xᵢ. Сумма произведений двух строк 1×m записывается как (ŷ − y)xᵀ — скаляр, как и w.

**N37. Что такое затухающий и взрывающийся градиенты?**
> 📌 **P1 · RELATED** · [Top 45, № 22](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf) · [InterviewBit, для опытных № 6](https://www.interviewbit.com/deep-learning-interview-questions/)

При backprop градиент ранних слоёв — произведение множителей всех последующих слоёв (веса × производные активаций). Если множители по модулю меньше 1, градиент экспоненциально **затухает** и ранние слои почти не учатся (sigmoid/tanh, длинные RNN). Если больше 1 — экспоненциально **растёт**: огромные шаги, NaN. Лечение: ReLU, правильная инициализация, нормализация, residual-связи, LSTM/GRU — от затухания; gradient clipping — от взрыва.

**N38. Назовите два способа бороться с затуханием градиента в глубокой сети.**
> 📌 **P1 · RELATED** · [Top 45, № 42](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

Любые два из: ReLU/Leaky ReLU вместо sigmoid и tanh; инициализация Xavier (tanh) или He (ReLU); Batch Normalization; residual-связи (ResNet); LSTM/GRU для последовательностей.

**N39. Что решает проблему взрывающегося градиента?**
- [ ] Переход на SGD
- [ ] Oversampling редких классов
- [ ] Увеличение размера батча
- [x] Gradient clipping
> 📌 **P2 · RELATED** · [Stanford CS230, зима 2021, 1(h)](https://cs230.stanford.edu/files/cs230exam_win21_soln.pdf)

Clipping ограничивает норму градиента: если ‖g‖ > c, то g ← c·g/‖g‖. Остальные варианты на величину градиента по слоям не влияют.

**N40. Что верно про проблему затухающего градиента?**
- [ ] Tanh предпочитают сигмоиде, потому что он не страдает от затухания
- [ ] Из-за затухания глубокие слои учатся медленнее ранних
- [x] Leaky ReLU реже страдает от затухания, чем sigmoid
- [x] Инициализация Xavier помогает предотвратить затухание

Tanh тоже насыщается. При затухании медленнее учатся **ранние** слои, а не поздние: до них градиент доходит через наибольшее число множителей.

**N41. Сеть из 100 слоёв (tanh и ReLU внутри, sigmoid на выходе): градиенты части слоёв почти сразу стали нулевыми. Что может помочь?**
- [ ] Увеличить обучающую выборку
- [x] Заменить все ReLU на Leaky ReLU
- [x] Добавить Batch Normalization перед каждой активацией
- [ ] Увеличить learning rate
> 📌 **P2 · RELATED** · [Stanford CS230, осень 2020, 1(a)](https://cs230.stanford.edu/files/cs230exam_fall20_soln.pdf)

Классическое затухание градиента. Leaky ReLU пропускает градиент и при отрицательном входе; BN держит входы tanh в линейной области, где производная близка к 1. Больше данных проблему динамики обучения не решает; больший шаг не «оживит» нулевые градиенты.

**N42. Можно ли обучить нейронную сеть, если все смещения (bias) инициализированы нулями?**
- [x] Да
- [ ] Нет
> 📌 **P0 · EXACT** · вопрос с экзамена (№ 3 и № 28) · [InterviewBit, для начинающих № 18](https://www.interviewbit.com/deep-learning-interview-questions/)

Да. Нулевые bias — стандартная инициализация: симметрию между нейронами ломают **случайные веса**, а градиент по смещению ∂L/∂b = δ ненулевой, так что смещения начнут обновляться с первого шага.

**N43. Можно ли обучить нейронную сеть, если все веса инициализированы нулями?**
- [ ] Да
- [x] Нет
> 📌 **P0 · EXACT** · вопрос с экзамена (№ 4 и № 29) · [InterviewBit, для начинающих № 18](https://www.interviewbit.com/deep-learning-interview-questions/) · та же тема: [Top 45, № 18 и № 44](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

Нет. Все нейроны слоя вычисляют одно и то же, получают одинаковый градиент и остаются одинаковыми после любого числа шагов (**проблема симметрии**) — слой эквивалентен одному нейрону. При нулевых весах градиент к ранним слоям вообще равен нулю, потому что δ умножается на Wᵀ = 0. То же при любой одинаковой константе.

> ⚠️ Исключение — модель без скрытых слоёв (линейная или логистическая регрессия): там симметрии нет, нулевые веса допустимы.

**N44. Зачем добавлять случайность при инициализации весов?**
> 📌 **P1 · RELATED** · [Top 45, № 44](https://storage.googleapis.com/kaggle-forum-message-attachments/2381758/19505/Top%2045%20Deep%20Learning%20Interview%20Questions.pdf)

Чтобы сломать симметрию: при одинаковых весах нейроны слоя дают одинаковые выходы и градиенты и не могут выучить разные признаки. Масштаб случайности выбирают так, чтобы дисперсия сигнала не росла и не затухала по слоям: Xavier Var(w) = 2/(n_in + n_out), He Var(w) = 2/n_in.

- [ ] −1
- [ ] 0
- [x] 0.5
- [ ] 1
> 📌 **P2 · RELATED** · [Stanford CS230, осень 2018, 1(d)](https://cs230.stanford.edu/files/cs230exam_fall18_soln.pdf)

z = 0·x + 0 = 0 на каждом слое, σ(0) = 0.5.

**N46. Та же сеть с нулевой инициализацией: после одного прямого и обратного прохода и обновления параметров элементы W[1]…**
- [ ] могут быть и положительными, и отрицательными
- [ ] все отрицательные
- [ ] все положительные
- [x] все равны нулю
> 📌 **P2 · RELATED · ключ источника оспорен** · [Stanford CS230, осень 2018, 1(e)](https://cs230.stanford.edu/files/cs230exam_fall18_soln.pdf)

Проверка: ∂L/∂a[1] = (W[2])ᵀ·δ[2], а W[2] = 0, значит δ[1] = 0 и ∂L/∂W[1] = δ[1]xᵀ = 0. После первого шага W[1] остаётся нулевой (меняются только W[2] и смещения).

**N49. MLP с sigmoid в скрытых слоях, веса инициализированы из N(10, 1). Веса первого слоя почти не обновляются. Что поможет?**

**N50. Обученная логистическая регрессия без bias. Если разделить вектор весов W на 2, изменится ли точность на тесте?**
- [ ] Да, изменится
