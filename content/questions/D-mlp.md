## Блок D. Полносвязные сети, инициализация, гиперпараметры

**D1. Можно ли обучить модель, установив все смещения (bias) равными 0?**
**Да.** Нулевая инициализация bias — стандартная практика. Симметрию между нейронами ломают случайно инициализированные **веса**, а градиент по bias (∂L/∂b = δ) ненулевой, поэтому смещения начинают обновляться сразу. Иногда bias вообще не нужен (например перед BatchNorm, где β играет его роль).

**D2. А если все ВЕСА = 0?**
**Нет, не обучится.** Все нейроны слоя получат одинаковые градиенты и останутся идентичными (проблема симметрии), слой эквивалентен одному нейрону; при этом с ReLU и нулевыми весами выход и градиенты могут быть нулевыми вовсе. Исключение — модель без скрытых слоёв (линейная/логистическая регрессия), там нулевая инициализация работает.

**D3. Как выбрать число нейронов в скрытом слое?**
Это гиперпараметр, формулы нет. Практика: старт со значения между размерами входа и выхода (степени двойки), затем подбор по валидационной метрике (random/grid search, Optuna), при переобучении — уменьшить или добавить регуляризацию. Современный подход — большая сеть + сильная регуляризация.

**D4. Как «обучают» гиперпараметры нейронной сети?**
Их не обучают градиентом; их подбирают внешним поиском по **валидационной** выборке: grid search, random search, байесовская оптимизация (TPE/Optuna), Hyperband/ASHA, эволюционные алгоритмы; финальная оценка — один раз на тесте.

**D5. Можно ли построить нейронную сеть на основе линейной регрессии?**
Да: один нейрон с линейной активацией = линейная регрессия; с сигмоидой = логистическая. Но стек линейных слоёв без нелинейных активаций остаётся линейной моделью — для «настоящей» сети нужны нелинейные активации.

**D6. Сколько параметров у Dense-слоя 784 → 256?**
784·256 + 256 = **200 960**.

**D7. На вход подаются 1, 2, 3; веса 4, 5, 6; активация линейная f(x)=3x. Что на выходе?**
Сумма: 1·4+2·5+3·6 = 32. Активация: 3·32 = **96**.

**D8. Что такое эпоха, итерация, batch size?**
Эпоха — один полный проход по обучающей выборке. Batch size — число объектов в одном шаге. Итерация — одно обновление весов; итераций на эпоху = N / batch_size.
