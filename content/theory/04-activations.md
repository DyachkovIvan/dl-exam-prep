# Тема 4. Функции активации

## 4.1 Роль функций активации (главный вопрос билета)

Функция активации вносит в сеть **нелинейность**. Без неё композиция линейных слоёв
`W₂(W₁x + b₁) + b₂ = W'x + b'`
остаётся **линейной моделью** — сколько бы слоёв ни было, сеть эквивалентна одному линейному слою (то есть линейной/логистической регрессии) и не сможет выучить нелинейные зависимости (даже XOR). Нелинейность даёт сети свойство универсального аппроксиматора. Дополнительно активация ограничивает/формирует диапазон выхода (вероятности, неотрицательность) и влияет на распространение градиента.

## 4.2 Основные функции

**Sigmoid (logistic)**
σ(x) = 1/(1+e^(−x)), выход ∈ (0,1), σ'(x) = σ(x)(1−σ(x)) ≤ 0.25.
+ Интерпретируется как вероятность → выходной слой бинарной классификации и multi-label.
− **Затухание градиента** (насыщение на хвостах), выход **не центрирован в нуле** (все градиенты одного знака → зигзаг), экспонента дорогая.

**Tanh**
tanh(x) = (e^x − e^(−x))/(e^x + e^(−x)) ∈ (−1,1), tanh'(x) = 1 − tanh²(x) ≤ 1.
+ Центрирован в нуле → сходится быстрее сигмоиды; используется в LSTM/GRU.
− Всё ещё насыщается → затухание градиента.

**ReLU**
ReLU(x) = max(0, x), производная: 1 при x>0, 0 при x<0 (в нуле доопределяют 0).
+ Не насыщается при x>0 → **градиент не затухает**, очень дёшево считается, даёт разреженную активацию, ускоряет сходимость в разы. Дефолт для скрытых слоёв CNN/MLP.
− **Dying ReLU:** если нейрон ушёл в отрицательную зону, градиент = 0 и он больше никогда не обновится; выход не центрирован в нуле; неограничен сверху.

**Leaky ReLU**
LeakyReLU(x) = x при x>0, αx при x≤0 (α ≈ 0.01).
+ Чинит dying ReLU: **градиент в отрицательной зоне не равен нулю** (равен α), нейрон может «ожить». Почти та же дешевизна.
− α — ещё один гиперпараметр; выигрыш не всегда заметен.
Родственники: **PReLU** (α обучаемая), **ELU** (экспоненциальный отрицательный хвост, среднее ближе к 0), **GELU/SiLU(Swish)** — гладкие, стандарт в трансформерах.

**Softmax** (для выходного слоя, не для скрытых)
$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$
Превращает вектор логитов в **распределение вероятностей**: все компоненты ∈ (0,1) и **сумма = 1**. Ответ на вопрос «есть K элементов, нужно выдать вероятности с суммой 1 — что использовать?» → **softmax**. В реализации вычитают max(z) для численной устойчивости.

## 4.3 Сопоставление «задача ↔ активация выходного слоя» (типовое задание)

| Задача | Выходной слой | Функция потерь |
|---|---|---|
| **Бинарная классификация** | 1 нейрон + **sigmoid** | Binary Cross-Entropy |
| **Мультиклассовая** (ровно 1 класс) | K нейронов + **softmax** | Categorical / Sparse Categorical Cross-Entropy |
| **Multi-label** (много меток сразу) | K нейронов + **sigmoid** на каждом (независимо!) | сумма BCE по меткам |
| **Регрессия** | линейный выход (**без активации**), иногда ReLU если величина ≥0 | MSE / MAE / Huber |

**ReLU** — это активация **скрытых слоёв**, а не «задачи».

**Отличие мультикласса от multi-label:** в мультиклассе классы взаимоисключающие, softmax связывает их (сумма = 1, увеличение одного уменьшает другие); в multi-label метки независимы, каждая своя сигмоида, сумма может быть любой (объект может быть одновременно «кот» и «в помещении»).
