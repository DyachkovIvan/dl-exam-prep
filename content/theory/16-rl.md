# Тема 16. Обучение с подкреплением: MDP, Q-обучение, DQN

## 16.1 Постановка

**Агент** взаимодействует со **средой**: в состоянии s_t выбирает действие a_t, получает награду r_{t+1} и попадает в s_{t+1}. Цель — максимизировать ожидаемую **суммарную дисконтированную награду (return)**
$$G_t = \sum_{k=0}^{\infty}\gamma^k r_{t+k+1} = r_{t+1} + \gamma\, G_{t+1}, \qquad \gamma \in [0,1]$$

**Роль γ — коэффициента дисконтирования:**
- ближе к 0 — «близорукий» агент, важна только ближайшая награда; ближе к 1 — дальновидный;
- при γ < 1 и ограниченных наградах |r| ≤ R_max ряд сходится: |G_t| ≤ R_max/(1−γ);
- γ = 1 допустим только для эпизодических задач, которые гарантированно заканчиваются.

**Интуиция горизонта:** γ = 0.99 — агент «смотрит» примерно на 1/(1−γ) = 100 шагов вперёд.

Рекуррентная форма G_t = r_{t+1} + γG_{t+1} — основа всех уравнений Беллмана ниже.

**Отличие от supervised learning:**
- нет «правильных ответов» — есть только скалярная, часто **отложенная и разреженная** награда (проблема *credit assignment*: какое из прошлых действий привело к успеху?);
- данные **не i.i.d.**: они зависят от политики агента и сильно коррелированы во времени;
- дилемма **exploration vs exploitation**: пробовать новое или использовать уже известное.

## 16.2 Марковский процесс принятия решений (MDP)

Кортеж **(S, A, P, R, γ)**:
- S — множество состояний, A — множество действий;
- P(s′|s,a) — вероятность перехода;
- R(s,a) — ожидаемая награда;
- γ — дисконт.

**Марковское свойство:** будущее зависит только от текущего состояния и действия, а не от всей истории:
$$P(s_{t+1}\mid s_t,a_t) = P(s_{t+1}\mid s_1,a_1,\dots,s_t,a_t)$$

Иерархия: марковская цепь (S, P) → марковский процесс наград (S, P, R, γ) → MDP (+ действия) → POMDP (агент видит не состояние, а наблюдение). Пример POMDP: один кадр Atari не передаёт скорость мяча, поэтому DQN подаёт на вход 4 последних кадра — приближает марковское состояние.

**Политика** π(a|s) — распределение действий в состоянии (детерминированная политика — частный случай).

**Функции ценности:**
$$V^\pi(s)=\mathbb{E}_\pi[G_t\mid s_t=s], \qquad Q^\pi(s,a)=\mathbb{E}_\pi[G_t\mid s_t=s,\ a_t=a], \qquad V^\pi(s) = \sum_a \pi(a|s)\,Q^\pi(s,a)$$

**Уравнения Беллмана для политики π** (подставили G_t = r + γG_{t+1}):
$$V^\pi(s) = \sum_a \pi(a\mid s)\sum_{s'} P(s'\mid s,a)\Big[R(s,a) + \gamma V^\pi(s')\Big]$$

**Уравнения оптимальности Беллмана:**
$$Q^*(s,a)=\mathbb{E}_{s'\sim P(\cdot|s,a)}\Big[R(s,a) + \gamma\max_{a'}Q^*(s',a')\Big], \qquad V^*(s) = \max_a Q^*(s,a)$$

**Почему знать Q\* достаточно:** оптимальная политика — жадная по Q\*: π\*(s) = argmax_a Q\*(s,a). Модель среды P для выбора действия не нужна — в этом преимущество Q перед V.

**Почему итерации сходятся.** Оператор Беллмана (TQ)(s,a) = E[r + γ max_{a′} Q(s′,a′)] — **сжимающее отображение** в sup-норме с коэффициентом γ: ‖TQ₁ − TQ₂‖_∞ ≤ γ‖Q₁ − Q₂‖_∞. По теореме Банаха о неподвижной точке у него единственная неподвижная точка Q\*, и итерации Q ← TQ сходятся к ней из любого начального приближения (value iteration).

## 16.3 Q-обучение (Q-learning)

Watkins, 1989. **Табличный, model-free, off-policy, TD-метод.** Хранит таблицу Q[s][a] и после каждого перехода (s, a, r, s′) обновляет её:

$$Q(s,a) \leftarrow Q(s,a) + \alpha\Big[\underbrace{r + \gamma\max_{a'}Q(s',a')}_{\text{TD-цель}} - Q(s,a)\Big]$$

Выражение в скобках — **TD-ошибка** δ. Для терминального s′ цель равна просто r.

**Свойства — что значат термины:**
- **model-free** — не нужно знать P и R: математическое ожидание из уравнения Беллмана заменяется одним сэмплом реального перехода. Это стохастическая аппроксимация value iteration;
- **TD (temporal difference)** — «бутстрэппинг»: цель строится из текущей же оценки Q(s′,·), не дожидаясь конца эпизода (в отличие от Monte Carlo);
- **off-policy** — цель использует max по действиям, то есть оценивает **жадную** политику. Действовать при этом можно по другой, исследовательской — например **ε-жадной**: с вероятностью ε случайное действие, иначе argmax Q;
- сравните с **SARSA** (on-policy): цель r + γQ(s′,a′) для **реально выбранного** a′. SARSA оценивает ту политику, которой агент действует, включая исследование, поэтому выбирает более «осторожные» пути.

**Пример шага.** Q(s,a) = 2, r = 1, γ = 0.9, max_{a′} Q(s′,a′) = 5, α = 0.5.
- TD-цель: 1 + 0.9·5 = 5.5;
- TD-ошибка: 5.5 − 2 = 3.5;
- новое Q(s,a) = 2 + 0.5·3.5 = **3.75**.

**Гарантия сходимости** (Watkins & Dayan, 1992): Q-learning сходится к Q\* с вероятностью 1 для конечного MDP при условиях:
- каждая пара (s, a) посещается бесконечно много раз;
- шаги удовлетворяют Σ_t α_t = ∞ и Σ_t α_t² < ∞ (например, α_t = 1/t);
- награды ограничены.

**Проблема:** таблица не работает при большом или непрерывном пространстве состояний. Состояние Atari в DQN — 4 кадра 84×84 в 256 градациях серого, это 256^(84·84·4) вариантов. Большинство из них агент никогда не увидит → нужна аппроксимация, которая **обобщает** на похожие состояния.

## 16.4 DQN (Deep Q-Network, DeepMind: NIPS workshop 2013, Nature 2015)

Заменяем таблицу нейросетью Q(s, a; θ): CNN на стопке кадров выдаёт вектор Q-значений **сразу для всех действий** — один проход на выбор действия.

**Функция потерь** — регрессия на TD-цель:
$$L(\theta)=\mathbb{E}_{(s,a,r,s')\sim \mathcal D}\Big[\big(\underbrace{r+\gamma\max_{a'}Q(s',a';\theta^-)}_{y} - Q(s,a;\theta)\big)^2\Big]$$

Градиент берётся **только по Q(s,a;θ)**. Цель y считается константой — это «полуградиент». В Nature-версии TD-ошибка обрезается в [−1, 1], что эквивалентно функции потерь Хьюбера.

**Почему наивная замена таблицы на сеть неустойчива — «смертельная триада»** (Sutton & Barto): одновременное использование **аппроксимации функций + бутстрэппинга + off-policy** обучения может приводить к расходимости. В DQN есть все три компонента, поэтому нужны стабилизирующие трюки.

**Два ключевых трюка (обязательно назвать):**

1. **Experience Replay** — буфер последних переходов (s, a, r, s′) (в Nature — 1 млн); обучение идёт на случайных мини-батчах из него (32 перехода). Зачем:
   - разрывает **корреляцию** последовательных наблюдений — данные ближе к i.i.d., как ожидает SGD;
   - повышает эффективность использования данных — один переход участвует во многих обновлениях;
   - сглаживает распределение данных: оно не «скачет» вслед за текущей политикой, что уменьшает осцилляции.

   Replay возможен именно потому, что Q-learning **off-policy**: старые переходы от старых политик пригодны для обучения.

2. **Target Network** — отдельная копия сети с весами θ⁻, которой считается TD-цель; θ⁻ ← θ копируется раз в C шагов (в Nature C = 10 000 обновлений). Зачем: без неё обновление θ сразу сдвигает и цель y — «гонка за собственным хвостом» (moving target) → осцилляции и расходимость. С замороженной целью каждые C шагов решается почти обычная задача регрессии.

**Остальные детали Nature-DQN:**
- обрезка наград в [−1, 1] — одинаковый масштаб для всех игр;
- стек из 4 последних кадров (скорость и направление движения);
- повтор действия 4 кадра (frame skip);
- ε-жадная стратегия с отжигом ε от 1.0 до 0.1 за первый миллион кадров;
- RMSProp, γ = 0.99, обучение начинается после накопления 50 000 переходов.

**Улучшения DQN (объединены в Rainbow, Hessel et al., 2018):**
- **Double DQN** (van Hasselt et al., 2016). Max по зашумлённым оценкам смещён вверх: E[max_a Q̂] ≥ max_a E[Q̂] — отсюда систематическая **переоценка**. Решение — разделить выбор действия (онлайн-сеть θ) и его оценку (целевая сеть θ⁻):

$$y^{\text{Double}} = r + \gamma\,Q\big(s',\ \arg\max_{a'}Q(s',a';\theta);\ \theta^-\big)$$

- **Dueling DQN** — две ветви, V(s) и A(s,a): Q(s,a) = V(s) + A(s,a) − (1/|A|)·Σ_{a′} A(s,a′). Ценность состояния учится, даже когда выбор действия не важен.
- **Prioritized Experience Replay** — чаще сэмплировать переходы с большой |TD-ошибкой| (с поправкой importance sampling).
- **Multi-step returns** — цель по n реальным наградам: быстрее распространяется награда.
- **Distributional (C51)** — учить распределение return, а не только среднее.
- **Noisy Nets** — исследование через обучаемый шум в весах вместо ε-жадности.

**Ограничения DQN:**
- только **дискретные** действия — max по a требует перебора;
- нестабильность, чувствительность к гиперпараметрам;
- переоценка Q;
- низкая эффективность по данным (десятки миллионов кадров).

Для непрерывных действий — policy-gradient и actor-critic методы: REINFORCE, A2C/A3C, DDPG, TD3, SAC, PPO.

<summary>Проверь себя</summary>

1. **Чем Q-learning отличается от SARSA по формуле и по смыслу?** — *Q-learning: max_{a′}Q(s′,a′), оценивает жадную политику (off-policy); SARSA: Q(s′,a′) для реально выбранного a′ (on-policy).*
2. **Посчитайте обновление: Q = 0, r = −1, γ = 0.5, max Q(s′) = 4, α = 0.1.** — *Цель −1 + 2 = 1, δ = 1, новое Q = 0.1.*
3. **Почему experience replay нельзя напрямую использовать в on-policy методах?** — *Старые переходы порождены другой политикой, а on-policy метод оценивает текущую.*
4. **Что сломается без target network?** — *Цель будет сдвигаться после каждого шага — возможны осцилляции и расходимость.*
5. **Почему DQN не применим к управлению роботом с непрерывными моментами в суставах?** — *Нужен max по бесконечному множеству действий.*
6. **Откуда переоценка в DQN и как её исправляет Double DQN?** — *Max по шумным оценкам смещён вверх; Double DQN выбирает действие одной сетью, а оценивает другой.*
