# Тема 16. Обучение с подкреплением: MDP, Q-обучение, DQN

## 16.1 Постановка

**Агент** взаимодействует со **средой**: в состоянии s выбирает действие a, получает награду r и попадает в s′. Цель — максимизировать **суммарную дисконтированную награду**
$$G_t = \sum_{k=0}^{\infty}\gamma^k r_{t+k+1}, \qquad \gamma \in [0,1)$$
γ — коэффициент дисконтирования: ближе к 0 — «жадный» агент, ближе к 1 — дальновидный; он же обеспечивает сходимость ряда.

Отличие от supervised learning: нет «правильных ответов», есть только **отложенная и разреженная награда**; данные не i.i.d. и зависят от политики агента; есть дилемма **exploration vs exploitation**.

## 16.2 Марковский процесс принятия решений (MDP)

Кортеж **(S, A, P, R, γ)**: множество состояний, множество действий, вероятности перехода P(s′|s,a), функция награды R(s,a), дисконт.

**Марковское свойство:** будущее зависит только от текущего состояния, а не от всей истории:
$$P(s_{t+1}\mid s_t,a_t) = P(s_{t+1}\mid s_1,a_1,\dots,s_t,a_t)$$
Иерархия: Марковская цепь (S, P) → Марковский процесс наград (S, P, R, γ) → MDP (+ действия) → POMDP (частично наблюдаемое состояние).

**Политика** π(a|s) — правило выбора действия.
**Функции ценности:**
$$V^\pi(s)=\mathbb{E}_\pi[G_t\mid s_t=s], \qquad Q^\pi(s,a)=\mathbb{E}_\pi[G_t\mid s_t=s, a_t=a]$$
**Уравнение оптимальности Беллмана:**
$$Q^*(s,a)=\mathbb{E}_{s'}\Big[r + \gamma\max_{a'}Q^*(s',a')\Big]$$

## 16.3 Q-обучение (Q-learning)

**Табличный, model-free, off-policy, TD-метод.** Хранит таблицу Q[s][a] и обновляет её:

$$Q(s,a) \leftarrow Q(s,a) + \alpha\Big[\underbrace{r + \gamma\max_{a'}Q(s',a')}_{\text{TD-цель}} - Q(s,a)\Big]$$

- **model-free** — не нужно знать P и R, учимся из опыта;
- **off-policy** — обновление использует max по действиям (жадная целевая политика), хотя действовать можно по **ε-жадной** политике (с вероятностью ε случайное действие — это и есть exploration);
- сравните с **SARSA** (on-policy): вместо max Q(s′,a′) стоит Q(s′,a′) для реально выбранного a′.

Гарантия: при достаточном исследовании и убывающем α Q-learning сходится к Q*.
**Проблема:** таблица не работает при большом/непрерывном пространстве состояний (кадры игры Atari — 256^(84·84) состояний) → нужна аппроксимация.

## 16.4 DQN (Deep Q-Network, DeepMind, 2013/2015)

Заменяем таблицу нейросетью Q(s,a; θ) (CNN на кадрах → вектор Q-значений для всех действий).

**Функция потерь:**
$$L(\theta)=\mathbb{E}_{(s,a,r,s')\sim D}\Big[\big(r+\gamma\max_{a'}Q(s',a';\theta^-) - Q(s,a;\theta)\big)^2\Big]$$

**Два ключевых трюка (обязательно назвать):**
1. **Experience Replay** — буфер прошлых переходов (s,a,r,s′); обучение идёт на случайных мини-батчах из него. Зачем: разрывает **корреляцию** последовательных наблюдений (данные ближе к i.i.d.), повышает эффективность использования данных (один переход используется много раз), сглаживает распределение обучающих данных.
2. **Target Network** — отдельная копия сети с весами θ⁻, которой считается TD-цель; θ⁻ обновляются копированием θ раз в N шагов. Зачем: иначе цель «убегает» вслед за предсказанием (moving target) → осцилляции и расходимость.

Плюс: reward clipping в [−1,1], стек из 4 кадров (для скорости/направления), ε-жадная стратегия с отжигом ε от 1.0 до 0.1.

**Улучшения DQN (Rainbow):** Double DQN (убирает переоценку максимума: выбор действия сетью θ, оценка — θ⁻), Dueling DQN (раздельные ветви V(s) и A(s,a)), Prioritized Experience Replay, Noisy Nets, Distributional (C51), Multi-step returns.

**Ограничения DQN:** только **дискретные** действия (из-за max по a), нестабильность, переоценка Q. Для непрерывных действий — policy-gradient методы: REINFORCE, A2C/A3C, DDPG, TD3, SAC, PPO.
