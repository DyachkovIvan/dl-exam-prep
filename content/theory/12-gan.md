# Тема 12. GAN: обучение, функция оптимизации, функции потерь

## 12.1 Основные понятия

- **Генеративная модель** — модель, которая учит распределение данных и умеет порождать новые объекты из него.
- **Распределение данных p_data** — «закон», по которому получены реальные объекты (например, фотографии лиц).
- **Латентный шум z** — случайный вектор (обычно из N(0, I) или равномерного распределения), из которого генератор строит объект.
- **Генератор G(z)** — сеть, превращающая шум в объект. Его выходы образуют распределение p_g.
- **Дискриминатор D(x)** — бинарный классификатор, выдающий вероятность того, что x — реальный объект.
- **Состязательное обучение** — две сети оптимизируют противоположные цели.
- **Minimax-игра** — одна сторона минимизирует общую функцию, другая максимизирует.
- **Равновесие Нэша** — состояние, в котором ни одной сети невыгодно менять свою стратегию в одиночку.
- **Mode collapse** — генератор выдаёт лишь несколько видов объектов, игнорируя разнообразие данных.

## 12.2 Что такое GAN

**Определение.** Генеративно-состязательная сеть (Goodfellow et al., 2014) — генеративная модель из двух сетей: **генератор** учится порождать объекты, похожие на обучающие данные, а **дискриминатор** — отличать реальные объекты от сгенерированных. Сети обучаются одновременно и соревнуются.

**Простыми словами.** Фальшивомонетчик (генератор) печатает купюры, эксперт (дискриминатор) проверяет. Эксперт учится ловить подделки, фальшивомонетчик — делать их убедительнее. В идеале подделки становятся неотличимы.

**Главная идея.** Дискриминатор — это **обучаемая функция потерь** для генератора: не нужно вручную придумывать, чем «реалистичная» картинка отличается от нереалистичной (MSE по пикселям даёт размытость).

**Что нужно для обучения:** только набор данных, который хотим имитировать (изображения, аудио). Меток не нужно — это обучение без учителя.

## 12.3 Алгоритм обучения GAN

**Повторять:**
1. Сгенерировать m объектов из шума: G(z⁽¹⁾), …, G(z⁽ᵐ⁾).
2. Взять m реальных объектов x⁽¹⁾, …, x⁽ᵐ⁾ из обучающей выборки.
3. Подать оба набора дискриминатору: он выдаёт числа от 0 («подделка») до 1 («настоящее»).
4. Посчитать функцию потерь **дискриминатора** и обновить **только его** веса (генератор заморожен). Можно повторить k раз, в статье k = 1.
5. Сгенерировать m новых объектов G(z′).
6. Подать их дискриминатору, посчитать функцию потерь **генератора** и обновить **только веса генератора**. Дискриминатор не обновляется, но градиент **проходит через него** до генератора.

**Важно.** Сети обучаются **попеременно**, и ищется **равновесие**, а не минимум одной функции. Поэтому падение loss не означает прогресса: loss генератора может расти, когда дискриминатор просто стал сильнее. Качество оценивают метриками (FID) и глазами.

## 12.4 Функция оптимизации (minimax)

$$\min_G \max_D V(D,G) = \mathbb{E}_{x\sim p_{data}}\big[\log D(x)\big] + \mathbb{E}_{z\sim p_z}\big[\log\big(1 - D(G(z))\big)\big]$$

- **Первое слагаемое** — дискриминатор хочет D(x) ≈ 1 на реальных данных.
- **Второе слагаемое** — дискриминатор хочет D(G(z)) ≈ 0 на подделках, а генератор — наоборот, D(G(z)) ≈ 1.
- **D максимизирует V**, **G минимизирует V**. Для D это ровно логарифм правдоподобия бинарного классификатора.

**Теоретический результат.** При фиксированном G оптимальный дискриминатор
$$D^*_G(x) = \frac{p_{data}(x)}{p_{data}(x)+p_g(x)}$$

и минимизация по G эквивалентна минимизации **дивергенции Йенсена–Шеннона**:
$$C(G) = \max_D V(D,G) = -\log 4 + 2\cdot \mathrm{JSD}\big(p_{data}\,\|\,p_g\big)$$

Глобальный минимум достигается **только** при p_g = p_data; тогда D*(x) = ½ везде, V = −log 4 ≈ −1.386 — **loss дискриминатора выходит на константу**.

> ⚠️ Доказательство сходимости в статье — для идеального случая **в пространстве функций** (D успевает стать оптимальным на каждом шаге). Для реальных сетей с конечной ёмкостью и SGD таких гарантий нет.

<details>
<summary>Подробнее: вывод D* и связь с JSD</summary>

Перепишем V через плотности:

$$V(D,G) = \int_x \Big(p_{data}(x)\log D(x) + p_g(x)\log\big(1-D(x)\big)\Big)\,dx$$

Функция a·log y + b·log(1 − y) на (0, 1) максимальна при y = a/(a + b) (производная a/y − b/(1 − y) = 0). Подставив D*, получаем C(G) = −log 4 + 2·JSD, где JSD(p‖q) = ½KL(p‖m) + ½KL(q‖m), m = (p + q)/2. JSD ≥ 0 и равна 0 только при p = q.

</details>

## 12.5 Функция потерь дискриминатора

**Определение.** Бинарная кросс-энтропия с метками 1 для реальных и 0 для сгенерированных объектов:
$$L_D = -\mathbb{E}_{x\sim p_{data}}\big[\log D(x)\big] - \mathbb{E}_{z}\big[\log(1-D(G(z)))\big]$$

**Простыми словами.** Дискриминатор играет в угадайку на два класса: «настоящее — 1, подделка — 0».

**В равновесии** D = ½: L_D = log 4 ≈ 1.386 для суммы двух слагаемых или log 2 ≈ 0.693, если две части усредняют (как в большинстве реализаций). На практике loss колеблется около этого значения.

## 12.6 Функция потерь генератора

**Исходная (minimax, saturating):**
$$L_G^{mm} = \mathbb{E}_z\big[\log(1-D(G(z)))\big] \to \min_G$$

**Проблема.** В начале обучения генератор слаб, D легко распознаёт подделки, D(G(z)) ≈ 0 — и градиент этой функции почти нулевой. Генератор почти не учится именно тогда, когда хуже всего.

**Практическая (non-saturating):** вместо минимизации log(1 − D(G(z))) генератор **максимизирует log D(G(z))**:
$$L_G^{ns} = -\mathbb{E}_z\big[\log D(G(z))\big] \to \min_G$$

Генератор максимизирует вероятность того, что дискриминатор назовёт подделку настоящей. Реализация: тот же BCE, но сгенерированным объектам ставится метка **1**. Неподвижная точка та же, а сигнал в начале обучения сильный.

<details>
<summary>Подробнее: почему исходная функция насыщается</summary>

Пусть D(x) = σ(l), l — логит дискриминатора на подделке. Производные по l:

$$\frac{\partial}{\partial l}\log\big(1-\sigma(l)\big) = -\sigma(l) = -D, \qquad \frac{\partial}{\partial l}\Big(-\log\sigma(l)\Big) = -\big(1-\sigma(l)\big) = -(1-D)$$

При D(G(z)) ≈ 0 первая производная ≈ 0, вторая ≈ −1.

</details>

## 12.7 Общая функция потерь

**Общая функция** — это сама функция ценности игры V(D, G) из 12.4: дискриминатор её максимизирует, генератор минимизирует. На практике её не минимизируют одним оптимизатором: у каждой сети свой шаг и своя функция (L_D и L_G), а обновления чередуются.

> ⚠️ «Общая функция потерь — среднее потерь дискриминатора и генератора, которое минимизируется» — неверно. Сети преследуют **противоположные** цели, поэтому одной общей минимизируемой функции нет — есть игра.

## 12.8 Проблемы обучения GAN

**Затухающие градиенты (vanishing gradients).** Если дискриминатор слишком хорош, D(G(z)) ≈ 0, и генератор почти не получает градиента. Глубже: реальные данные и выходы генератора лежат на низкоразмерных многообразиях, которые почти не пересекаются; тогда JSD = log 2 — константа с нулевым градиентом (Arjovsky & Bottou, 2017).
- **Лечение:** non-saturating loss; Wasserstein-потеря (WGAN).

**Mode collapse.** Генератор находит несколько объектов, которые дискриминатор сейчас считает настоящими, и выдаёт только их. Дискриминатор переучивается — генератор перескакивает к другой моде, и так по кругу.
- **Признаки:** однообразные сэмплы, колебания loss генератора.
- **Лечение:** WGAN (дискриминатор можно обучать до оптимума, генератор не «прячется» в одну моду), unrolled GAN (генератор учитывает несколько будущих шагов дискриминатора), minibatch discrimination.

**Отсутствие сходимости (failure to converge).** Градиентная динамика minimax-игры может вращаться вокруг равновесия, а не приходить к нему; качество колеблется, иногда деградирует. Со временем дискриминатор, не отличающий подделки, выдаёт случайные ответы, и его сигнал становится бесполезным.
- **Лечение:** добавление шума к входам дискриминатора, регуляризация весов дискриминатора, spectral normalization, TTUR (разные learning rate для D и G).

**Дисбаланс сетей** — D и G нужно держать сопоставимыми по силе.

**Нет явной метрики качества.** Используют **FID** (Fréchet Inception Distance, меньше — лучше) — расстояние между гауссианами, подогнанными под признаки Inception-v3 реальных и сгенерированных картинок:
$$\mathrm{FID} = \|\mu_r - \mu_g\|^2 + \operatorname{Tr}\Big(\Sigma_r + \Sigma_g - 2\big(\Sigma_r\Sigma_g\big)^{1/2}\Big)$$

## 12.9 Улучшения

- **WGAN** — минимизируется расстояние Вассерштейна-1, которое остаётся информативным даже для непересекающихся распределений. Вместо дискриминатора — **критик** f без сигмоиды, 1-липшицевость обеспечивается weight clipping:

$$W_1(p_{data}, p_g) = \sup_{\|f\|_L \le 1}\ \mathbb{E}_{x\sim p_{data}}[f(x)] - \mathbb{E}_{x\sim p_g}[f(x)]$$

- **WGAN-GP** — вместо clipping штраф λ·E[(‖∇D(x̂)‖₂ − 1)²], λ = 10.
- **Spectral normalization** — ограничение константы Липшица дискриминатора.
- **LSGAN** — квадратичная потеря вместо BCE.
- **Label smoothing** — метка 0.9 вместо 1 для реальных.
- **DCGAN** (тема 13) — архитектурный рецепт стабильного обучения; **CGAN** (тема 14) — управляемая генерация.

## 12.10 Где применяются

Генерация изображений (лица, интерьеры), super-resolution, перевод изображение → изображение (pix2pix, CycleGAN), inpainting, аугментация данных, генерация аудио.

## 12.11 Ловушка из билета

> «GAN успешно генерирует изображения яблок. Какое утверждение ЛОЖНО?»
> a) генератор стремится выучить распределение изображений яблок — **верно**;
> b) дискриминатор можно использовать для классификации «яблоко / не яблоко» — **ложно**: он учился отличать *настоящие яблоки от сгенерированных*, «не яблок» не видел, а в равновесии выдаёт ≈ 0.5;
> c) после обучения loss дискриминатора выходит на константу — **верно**;
> d) генератор может порождать невиданные ранее изображения яблок — **верно**.

<details>
<summary>Проверь себя</summary>

1. **Что максимизирует a·log y + b·log(1 − y)?** — *y = a/(a + b).*
2. **Какую дивергенцию минимизирует G при оптимальном D?** — *Йенсена–Шеннона.*
3. **Почему используют −log D(G(z)), а не log(1 − D(G(z)))?** — *Градиент по логиту −(1 − D) ≈ −1 вместо −D ≈ 0 в начале обучения.*
4. **Почему падение loss генератора не означает улучшения?** — *Это игра: loss зависит от текущей силы дискриминатора.*
5. **Назовите три типичные проблемы GAN.** — *Затухающие градиенты, mode collapse, отсутствие сходимости.*

</details>
