# Тема 2. Обратное распространение ошибки (Backpropagation)

## 2.1 Суть

Backprop — это **эффективное применение цепного правила (chain rule)** для вычисления градиентов функции потерь по всем параметрам сети за один обратный проход. Промежуточные результаты переиспользуются, как в динамическом программировании. В терминах автоматического дифференцирования это **reverse-mode AD**.

Backprop — это **не метод оптимизации**, а способ посчитать градиент; оптимизирует уже SGD/Adam (Rumelhart, Hinton, Williams, 1986).

**Почему именно обратный режим.** У нас один скаляр L и миллионы параметров.
- Численное дифференцирование (конечные разности) требует ~1 прохода **на каждый параметр**.
- Прямой режим AD — тоже по проходу на каждое входное направление.
- Обратный режим получает **все** ∂L/∂θ за один проход назад. Его стоимость — небольшое константное число прямых проходов (обычно оценивают как ≤ 3×), независимо от числа параметров («cheap gradient principle»).

## 2.2 Цепное правило на вычислительном графе

Сеть = ориентированный ациклический граф операций. Если переменная x влияет на L через несколько переменных y₁,…,y_m, производные **суммируются по всем путям**:
$$\frac{\partial L}{\partial x} = \sum_{j=1}^{m}\frac{\partial L}{\partial y_j}\,\frac{\partial y_j}{\partial x}$$

В векторной форме для y = f(x), x ∈ ℝⁿ, y ∈ ℝᵐ с якобианом J = ∂y/∂x ∈ ℝ^{m×n}:
$$\nabla_x L = J^\top\, \nabla_y L$$

Каждый узел графа должен уметь только одно — умножить входящий градиент на транспонированный якобиан (**vector-Jacobian product**). Сам якобиан явно не строится: например, для поэлементной функции он диагональный, и VJP — это просто поэлементное умножение.

## 2.3 Forward pass (проход вперёд)

Для слоя l, где a^{l−1} ∈ ℝ^{n_{l−1}}, W^l ∈ ℝ^{n_l × n_{l−1}}, b^l ∈ ℝ^{n_l}:
$$z^l = W^l a^{l-1} + b^l, \qquad a^l = \sigma(z^l)$$

Порядок:
1. Подать x на вход: a⁰ = x.
2. Последовательно, слой за слоем, вычислить z^l и a^l до выходного слоя.
3. Посчитать функцию потерь L(a^L, y).
4. **Сохранить в памяти все промежуточные активации** a^l и z^l — они нужны для backward. Отсюда рост потребления памяти с глубиной и размером батча. Компромисс — *gradient checkpointing*: храним часть активаций, остальное пересчитываем на обратном проходе.

## 2.4 Backward pass (проход назад)

Вводим «ошибку слоя» δ^l = ∂L/∂z^l ∈ ℝ^{n_l}.

**Выходной слой:**
$$\delta^L = \nabla_{a^L} L \odot \sigma'(z^L)$$

**Рекуррентно назад:** z^{l+1} = W^{l+1}σ(z^l) + b^{l+1}, якобиан ∂z^{l+1}/∂z^l = W^{l+1}·diag(σ'(z^l)), поэтому
$$\delta^l = \big((W^{l+1})^\top \delta^{l+1}\big) \odot \sigma'(z^l)$$

**Градиенты параметров** (z_i = Σⱼ W_ij a_j + b_i ⇒ ∂z_i/∂W_ij = a_j):
$$\frac{\partial L}{\partial W^l} = \delta^l\,(a^{l-1})^\top, \qquad \frac{\partial L}{\partial b^l} = \delta^l$$

**Для батча** из B объектов (L — среднее по батчу) градиенты усредняются: ∂L/∂W^l = (1/B) Σ_i δ^l_i (a^{l−1}_i)ᵀ. Размерность ∂L/∂W^l всегда совпадает с размерностью W^l — хорошая самопроверка.

Итого один цикл обучения: **forward → loss → backward → update → обнулить градиенты** (в PyTorch градиенты по умолчанию накапливаются).

## 2.5 Разобранный пример (посчитать руками)

Один нейрон: x = 2, w = 0.5, b = −1, активация sigmoid, потеря L = ½(a − y)², цель y = 1.

**Forward:** z = wx + b = 0, a = σ(0) = 0.5, L = ½(0.5 − 1)² = 0.125.

**Backward:**
- ∂L/∂a = a − y = −0.5
- ∂a/∂z = σ(z)(1 − σ(z)) = 0.25 ⇒ δ = ∂L/∂z = −0.125
- ∂L/∂w = δ·x = −0.25, ∂L/∂b = δ = −0.125

**Шаг SGD** с η = 1: w ← 0.75, b ← −0.875. Новый z = 0.625 и a ≈ 0.651 — предсказание приблизилось к 1.

## 2.6 Softmax + cross-entropy: почему δ = ŷ − y

Пусть ŷ = softmax(z), L = −Σₖ yₖ log ŷₖ, y — one-hot (Σₖ yₖ = 1). Якобиан softmax:
$$\frac{\partial \hat y_k}{\partial z_i} = \hat y_k\,(\mathbb{1}[k=i] - \hat y_i)$$

Тогда
$$\frac{\partial L}{\partial z_i} = -\sum_k \frac{y_k}{\hat y_k}\,\hat y_k(\mathbb{1}[k=i]-\hat y_i) = -y_i + \hat y_i\sum_k y_k = \hat y_i - y_i$$

**Смысл:** градиент по логитам — просто «предсказание минус правда». Логарифм в CE ровно компенсирует экспоненту в softmax, поэтому насыщения на выходе нет. То же верно для sigmoid + BCE: ∂L/∂z = ŷ − y. А вот sigmoid + MSE даёт (ŷ − y)·σ'(z) — при уверенной ошибке σ' ≈ 0, и обучение застревает. Это главный аргумент, почему для классификации берут CE, а не MSE.

## 2.7 Недостатки backprop (прямо спрашивают)

**Затухающий градиент (vanishing gradient).** Раскрыв рекурсию:
$$\frac{\partial L}{\partial z^{1}} = \Big(\prod_{l=2}^{L}\operatorname{diag}\big(\sigma'(z^{l-1})\big)\,(W^{l})^\top\Big)\,\delta^L,
\qquad
\Big\|\frac{\partial L}{\partial z^{1}}\Big\| \le \prod_{l}\big\|W^{l}\big\|\cdot\max|\sigma'|\ \cdot\ \|\delta^L\|$$

Для сигмоиды max σ' = 1/4. Если нормы весов порядка 1, градиент затухает не медленнее (1/4)^{L−1} — экспоненциально по глубине, и ранние слои почти не обучаются.

**Взрывающийся градиент (exploding gradient).** Множители > 1 → экспоненциальный рост, переполнение, NaN. Лечится **gradient clipping**, нормализациями, аккуратной инициализацией, residual-связями.

**Другие недостатки:**
- **Память** — нужно хранить все активации forward-прохода.
- **Последовательность** — слои нельзя обновить параллельно (backward locking): слой l ждёт градиент от слоя l+1.
- **Только локальная информация** — градиентный метод не гарантирует глобальный оптимум. В невыпуклом ландшафте много седловых точек и плато.
- **Требует дифференцируемости** всех операций (почти всюду: ReLU в нуле берут субградиент).
- **Биологическая неправдоподобность** (weight transport problem: обратный проход использует те же веса Wᵀ) — упоминают в теоретических курсах.

## 2.8 Как проверить, что градиент посчитан верно

**Gradient checking** — сравнить аналитический градиент с центральной разностью:
$$\frac{\partial L}{\partial \theta_i} \approx \frac{L(\theta + h e_i) - L(\theta - h e_i)}{2h}, \qquad \text{ошибка } O(h^2)$$

Смотрят относительную ошибку |g_a − g_n| / max(|g_a|, |g_n|); порядка 10⁻⁷ — хорошо, 10⁻² — ошибка в коде. Считать в float64, h ≈ 10⁻⁵.

## 2.9 Ловушки

- «Какая функция помогает бороться со **взрывом** градиента?» — из вариантов *ReLU / tanh / Leaky ReLU / никакая* правильный ответ обычно **«никакая»**. ReLU и Leaky ReLU борются с **затуханием**, а не со взрывом; tanh ограничивает выход, но сам провоцирует затухание. Со взрывом борются clipping, нормализация, правильная инициализация.
- Backprop ≠ градиентный спуск.
- Градиенты от разных путей **складываются** (важно для skip-connections и общих весов).

<summary>Проверь себя</summary>

1. **Какой размерности ∂L/∂W для слоя 128 → 10?** — *10×128, как и сама W.*
2. **Почему backprop дешевле конечных разностей?** — *Один обратный проход даёт все частные производные сразу; конечные разности требуют пары проходов на каждый параметр.*
3. **Чему равен градиент CE по логитам, если ŷ = (0.7, 0.2, 0.1), истинный класс — второй?** — *(0.7, −0.8, 0.1).*
4. **Почему sigmoid + MSE обучается хуже sigmoid + BCE?** — *В MSE остаётся множитель σ'(z), который при насыщении ≈ 0; в BCE он сокращается.*
5. **Что делает ReLU с градиентом на backward?** — *Пропускает без изменений там, где z > 0, и обнуляет там, где z < 0.*
