# Тема 2. Обратное распространение ошибки (Backpropagation)

## 2.1 Суть

Backprop — это **эффективное применение цепного правила (chain rule)** для вычисления градиентов функции потерь по всем весам сети за один обратный проход, с переиспользованием промежуточных результатов (динамическое программирование). Backprop — это **не метод оптимизации**, а способ посчитать градиент; оптимизирует уже SGD/Adam.

## 2.2 Forward pass (проход вперёд)

Для слоя l: `z^l = W^l a^{l-1} + b^l`, `a^l = σ(z^l)`.

Порядок:
1. Подать x на вход: a⁰ = x.
2. Последовательно, слой за слоем, вычислить z^l и a^l до выходного слоя.
3. Посчитать функцию потерь L(a^L, y).
4. **Сохранить в памяти все промежуточные активации** a^l и z^l — они нужны для backward. (Отсюда рост потребления памяти с глубиной/батчем.)

## 2.3 Backward pass (проход назад)

Вводим «ошибку слоя» δ^l = ∂L/∂z^l.

1. Выходной слой: `δ^L = ∇_a L ⊙ σ'(z^L)`
   (для softmax + cross-entropy красиво: `δ^L = ŷ − y`)
2. Рекуррентно назад: `δ^l = ((W^{l+1})^T δ^{l+1}) ⊙ σ'(z^l)`
3. Градиенты параметров: `∂L/∂W^l = δ^l (a^{l-1})^T`, `∂L/∂b^l = δ^l`
4. Шаг оптимизатора: `W ← W − η ∂L/∂W`.

Итого один цикл обучения: **forward → loss → backward → update → обнулить градиенты**.

## 2.4 Недостатки backprop (прямо спрашивают)

- **Затухающий градиент (vanishing gradient).** Произведение множителей σ'(z) < 1 по глубине → градиент экспоненциально убывает, ранние слои почти не обучаются. Классика для sigmoid/tanh.
- **Взрывающийся градиент (exploding gradient).** Множители > 1 → переполнение, NaN. Лечится **gradient clipping**, нормализациями, аккуратной инициализацией.
- **Память:** нужно хранить все активации forward-прохода.
- **Последовательность:** слои нельзя обновить параллельно (backward lock), обучение строго послойное.
- **Только локальный минимум / седловые точки:** градиентный метод не гарантирует глобальный оптимум; в невыпуклом ландшафте много седловых точек.
- **Требует дифференцируемости** всех операций.
- **Биологическая неправдоподобность** (weight transport problem) — упоминают в теоретических курсах.

## 2.5 Ловушки

- «Какая функция помогает бороться со **взрывом** градиента?» — из вариантов *ReLU / tanh / Leaky ReLU / никакая* правильный ответ обычно **«никакая»**: ReLU и Leaky ReLU борются с **затуханием**, а не со взрывом; tanh ограничивает выход, но сам провоцирует затухание. Со взрывом борются clipping, нормализация, правильная инициализация.
- Backprop ≠ градиентный спуск.
