# Тема 2. Обратное распространение ошибки (Backpropagation)

## 2.1 Основные понятия

- **Вычислительный граф** — запись модели как цепочки простых операций (умножение на матрицу, сложение, активация, функция потерь). Узлы — операции, рёбра — промежуточные значения.
- **Прямой проход (forward pass)** — вычисление выхода сети и значения функции потерь по входу, слой за слоем.
- **Предактивация zˡ** — взвешенная сумма входов слоя: zˡ = Wˡaˡ⁻¹ + bˡ. **Активация aˡ** — результат функции активации: aˡ = σ(zˡ).
- **Функция потерь (cost) C или L** — число, измеряющее ошибку предсказания.
- **Цепное правило (chain rule)** — производная сложной функции равна произведению производных звеньев: если L = f(g(x)), то dL/dx = f′(g(x))·g′(x).
- **Локальный градиент (ошибка слоя) δˡ = ∂L/∂zˡ** — насколько изменится потеря при изменении предактивации слоя. Общая часть формул градиентов по весам и смещениям.
- **Обратный проход (backward pass)** — вычисление градиентов потерь по всем параметрам от выхода к входу.
- **Якобиан** — матрица всех частных производных векторной функции по векторному аргументу.

## 2.2 Что такое backprop

**Определение.** Обратное распространение ошибки — алгоритм вычисления градиента функции потерь по **всем** параметрам сети за один проход от выхода к входу с помощью цепного правила и переиспользования промежуточных результатов (Rumelhart, Hinton, Williams, 1986). В терминах автоматического дифференцирования — **reverse-mode AD**.

**Простыми словами.** Сначала считаем ответ и ошибку. Потом идём назад и для каждого слоя выясняем, какую «долю вины» за ошибку несут его веса. Градиенты последующих слоёв переиспользуются для предыдущих, поэтому ничего не считается дважды.

**Место в обучении.** Backprop только **считает градиент**. Обновляет веса оптимизатор (SGD, Adam). Один шаг обучения: **forward → loss → backward → update → обнулить градиенты**.

**Почему именно обратный режим.** У нас один скаляр L и миллионы параметров. Конечные разности требуют пары проходов на каждый параметр, а обратный проход даёт все ∂L/∂θ сразу — за стоимость порядка нескольких прямых проходов (обычно оценивают как ≤ 3×) независимо от числа параметров.

## 2.3 Алгоритм по шагам

Рассмотрим сеть из L слоёв; aˡ⁻¹ ∈ ℝ^{n_{l−1}}, Wˡ ∈ ℝ^{n_l × n_{l−1}} (строк — нейронов текущего слоя, столбцов — нейронов предыдущего), bˡ ∈ ℝ^{n_l}.

**Шаг 1 — прямой проход.**
1. Вход: a⁰ = x.
2. Для каждого слоя по порядку: zˡ = Wˡaˡ⁻¹ + bˡ, aˡ = σ(zˡ).
3. Выход сети: ŷ = a^L.
4. **Сохранить** все zˡ и aˡ — они понадобятся на обратном проходе. Отсюда рост памяти с глубиной и размером батча.

$$z^l = W^l a^{l-1} + b^l, \qquad a^l = \sigma(z^l)$$

**Шаг 2 — расчёт функции потерь.** Сравнить ŷ с правильным ответом y: L = cost(ŷ, y) — MSE для регрессии, кросс-энтропия для классификации.

**Шаг 3 — обратный проход.**

Ошибка выходного слоя:
$$\delta^L = \nabla_{a^L} L \odot \sigma'(z^L)$$

Ошибка предыдущих слоёв (от выхода к входу):
$$\delta^l = \big((W^{l+1})^\top \delta^{l+1}\big) \odot \sigma'(z^l)$$

Градиенты параметров:
$$\frac{\partial L}{\partial W^l} = \delta^l\,(a^{l-1})^\top, \qquad \frac{\partial L}{\partial b^l} = \delta^l$$

Для батча градиенты усредняются по объектам. **Самопроверка:** размерность ∂L/∂Wˡ всегда совпадает с размерностью Wˡ.

**Шаг 4 — обновление.** Оптимизатор: Wˡ ← Wˡ − η·∂L/∂Wˡ, bˡ ← bˡ − η·∂L/∂bˡ. Повторять шаги 1–4 для следующих батчей, пока потеря на валидации уменьшается или не кончились эпохи.

<details>
<summary>Подробнее: цепное правило на графе и откуда формулы</summary>

Если переменная x влияет на L через несколько переменных y₁, …, y_m, производные **суммируются по всем путям**:

$$\frac{\partial L}{\partial x} = \sum_{j=1}^{m}\frac{\partial L}{\partial y_j}\,\frac{\partial y_j}{\partial x}$$

В векторной форме для y = f(x) с якобианом J = ∂y/∂x: ∇ₓL = Jᵀ∇ᵧL. Каждый узел умеет только одно — умножить входящий градиент на транспонированный якобиан (vector-Jacobian product); сам якобиан явно не строится.

**Откуда рекурсия для δ.** zˡ⁺¹ = Wˡ⁺¹σ(zˡ) + bˡ⁺¹, якобиан ∂zˡ⁺¹/∂zˡ = Wˡ⁺¹·diag(σ′(zˡ)). Транспонируя его и умножая на δˡ⁺¹, получаем формулу для δˡ.

**Откуда ∂L/∂W.** zᵢ = Σⱼ Wᵢⱼaⱼ + bᵢ, поэтому ∂zᵢ/∂Wᵢⱼ = aⱼ и ∂L/∂Wᵢⱼ = δᵢaⱼ — это элемент матрицы δ·aᵀ.

</details>

## 2.4 Разобранный пример (посчитать руками)

Один нейрон: x = 2, w = 0.5, b = −1, активация sigmoid, потеря L = ½(a − y)², цель y = 1.

**Прямой проход:** z = wx + b = 0, a = σ(0) = 0.5, L = ½(0.5 − 1)² = 0.125.

**Обратный проход:**
- ∂L/∂a = a − y = −0.5
- ∂a/∂z = σ(z)(1 − σ(z)) = 0.25 ⇒ δ = ∂L/∂z = −0.125
- ∂L/∂w = δ·x = −0.25, ∂L/∂b = δ = −0.125

**Шаг SGD** с η = 1: w ← 0.75, b ← −0.875. Новый z = 0.625, a ≈ 0.651 — предсказание приблизилось к 1.

## 2.5 Softmax + cross-entropy: почему δ = ŷ − y

Для ŷ = softmax(z), L = −Σₖ yₖ log ŷₖ (y — one-hot) градиент по логитам равен просто **ŷ − y**: «предсказание минус правда». То же для sigmoid + BCE. Логарифм в кросс-энтропии компенсирует экспоненту, и выход не насыщается. А у sigmoid + MSE градиент (ŷ − y)·σ′(z): при уверенной ошибке σ′ ≈ 0 и обучение застревает — главный аргумент брать для классификации CE, а не MSE.

<details>
<summary>Подробнее: вывод</summary>

Якобиан softmax:

$$\frac{\partial \hat y_k}{\partial z_i} = \hat y_k\,(\mathbb{1}[k=i] - \hat y_i)$$

Тогда, пользуясь Σₖ yₖ = 1:

$$\frac{\partial L}{\partial z_i} = -\sum_k \frac{y_k}{\hat y_k}\,\hat y_k(\mathbb{1}[k=i]-\hat y_i) = -y_i + \hat y_i\sum_k y_k = \hat y_i - y_i$$

</details>

## 2.6 Недостатки backprop (прямо спрашивают)

**Затухающий градиент (vanishing gradient).** Градиент ранних слоёв — произведение множителей всех последующих слоёв (веса × производные активаций). Для сигмоиды σ′ ≤ 1/4, и при нормах весов порядка 1 градиент уменьшается не медленнее (1/4)^{L−1} — ранние слои почти не учатся.

**Взрывающийся градиент (exploding gradient).** Множители больше 1 → экспоненциальный рост, огромные шаги, NaN. Лечится gradient clipping, нормализациями, аккуратной инициализацией, residual-связями.

**Память.** Нужно хранить активации всех слоёв для каждого объекта батча. Компромисс — gradient checkpointing: часть активаций пересчитывается на обратном проходе.

**Последовательность вычислений.** Слой l ждёт градиент от слоя l+1 (backward locking) — слои нельзя обновлять параллельно.

**Только локальная информация.** Градиентный метод не гарантирует глобальный минимум; в невыпуклом ландшафте много седловых точек и плато.

**Требует дифференцируемости** всех операций (почти всюду: у ReLU в нуле берут субградиент).

**Чувствительность к гиперпараметрам** обучения (η, батч, инициализация) — строго говоря, это свойство градиентного обучения в целом.

**Биологическая неправдоподобность** (weight transport problem: обратный проход использует те же веса Wᵀ).

> ⚠️ **Не являются недостатками самого backprop:** переобучение (это свойство модели и данных), «неспособность работать с последовательностями» (для RNN есть BPTT — тот же backprop на развёрнутой сети), плохая работа на редких классах (проблема данных и функции потерь).

<details>
<summary>Подробнее: затухание градиента формально</summary>

$$\frac{\partial L}{\partial z^{1}} = \Big(\prod_{l=2}^{L}\operatorname{diag}\big(\sigma'(z^{l-1})\big)\,(W^{l})^\top\Big)\,\delta^L,
\qquad
\Big\|\frac{\partial L}{\partial z^{1}}\Big\| \le \prod_{l}\big\|W^{l}\big\|\cdot\max|\sigma'|\ \cdot\ \|\delta^L\|$$

</details>

## 2.7 Как проверить, что градиент посчитан верно

**Gradient checking** — сравнить аналитический градиент с центральной разностью:
$$\frac{\partial L}{\partial \theta_i} \approx \frac{L(\theta + h e_i) - L(\theta - h e_i)}{2h}, \qquad \text{ошибка } O(h^2)$$

Смотрят относительную ошибку |g_a − g_n| / max(|g_a|, |g_n|): порядка 10⁻⁷ — хорошо, 10⁻² — ошибка в коде. Считать в float64, h ≈ 10⁻⁵.

## 2.8 Ловушки

- «Какая функция помогает бороться со **взрывом** градиента?» — из вариантов *ReLU / tanh / Leaky ReLU / никакая* правильный ответ обычно **«никакая»**: ReLU и Leaky ReLU помогают против **затухания**; со взрывом борются clipping, нормализация, инициализация.
- Backprop ≠ градиентный спуск.
- Градиенты от разных путей **складываются** (важно для skip-connections и общих весов).
- Градиенты во фреймворках накапливаются — перед новым шагом их обнуляют.

<details>
<summary>Проверь себя</summary>

1. **Какой размерности ∂L/∂W для слоя 128 → 10?** — *10×128, как и сама W.*
2. **Почему backprop дешевле конечных разностей?** — *Один обратный проход даёт все частные производные сразу.*
3. **Градиент CE по логитам при ŷ = (0.7, 0.2, 0.1) и истинном втором классе?** — *(0.7, −0.8, 0.1).*
4. **Почему sigmoid + MSE обучается хуже sigmoid + BCE?** — *В MSE остаётся множитель σ′(z), который при насыщении ≈ 0.*
5. **Что делает ReLU с градиентом на обратном проходе?** — *Пропускает без изменений там, где z > 0, и обнуляет там, где z < 0.*

</details>
