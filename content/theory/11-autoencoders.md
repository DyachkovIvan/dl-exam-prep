# Тема 11. Автокодировщики и VAE

## 11.1 Что такое автокодировщик (частый открытый вопрос)

**Автокодировщик (autoencoder)** — нейросеть, которая обучается **восстанавливать свой собственный вход** через промежуточное представление. Состоит из:
- **Encoder** f_φ: x → z, сжимает вход в скрытое представление (latent code, «бутылочное горлышко», bottleneck);
- **Decoder** g_θ: z → x̂, восстанавливает вход из кода.

Обучение **без учителя (self-supervised)** — минимизируется ошибка реконструкции:
$$\min_{\varphi,\theta}\ \frac1N\sum_{i=1}^{N}\ \ell\big(x_i,\ g_\theta(f_\varphi(x_i))\big), \qquad \ell = \|x - \hat x\|^2 \ (\text{MSE}) \ \text{ или BCE для данных в } [0,1]$$

Метки не нужны — «правильный ответ» это сам вход.

**Почему MSE или BCE — вероятностный смысл.** Если считать, что декодер задаёт распределение p(x|z):
- **гауссовское** N(x̂, σ²I) с фиксированным σ → −log p(x|z) = ‖x − x̂‖²/(2σ²) + const, то есть MSE;
- **Бернулли** (пиксели в [0,1]) → BCE.

Выбор функции потерь = выбор модели шума данных.

**Зачем:**
- **Снижение размерности** — нелинейный аналог PCA. Линейный AE с MSE выучивает то же **подпространство**, что и PCA: оптимальный код лежит в пространстве главных компонент, хотя сами базисные векторы не обязательно ортогональны (Baldi & Hornik, 1989).
- **Предобучение** и извлечение признаков.
- **Шумоподавление.**
- **Детекция аномалий** — AE учился на «нормальных» данных, поэтому у аномалии большая ошибка реконструкции.
- **Сжатие** и **генерация** (для VAE).

Ключевое: **узкое место (bottleneck)** заставляет сеть выучить сжатое осмысленное представление вместо тождественного отображения. Если размерность z ≥ размерности x и нет регуляризации, AE может выучить копирование (identity) и станет бесполезным.

## 11.2 Типы автокодировщиков

| Тип | Функция потерь / идея |
|---|---|
| **Undercomplete (обычный)** | dim(z) < dim(x), сжатие за счёт узкого горлышка |
| **Denoising (DAE)** | на вход подаётся зашумлённый x̃ ~ C(x̃ \| x), восстанавливать нужно чистый x: ‖x − g(f(x̃))‖². Сеть учится «возвращать» точку на многообразие данных → устойчивые признаки |
| **Sparse** | L + λ·Ω(z), где Ω — L1 на активациях кода или KL(ρ ‖ ρ̂_j) к малой средней активации ρ. Код разреженный, размерность z может быть большой |
| **Contractive (CAE)** | L + λ‖∂f(x)/∂x‖²_F — штраф на норму Якобиана энкодера → представление нечувствительно к малым изменениям входа |
| **Convolutional** | encoder из Conv+Pool/stride, decoder из транспонированных свёрток/upsampling — для картинок |
| **Sequence (LSTM) AE** | для последовательностей |
| **Variational (VAE)** | вероятностный, генеративный — см. ниже |
| **Masked AE (MAE)** | маскируем большую часть входа и восстанавливаем её (BERT для текста, MAE для картинок — 75% патчей) |

## 11.3 Вариационный автокодировщик (VAE)

**Проблема обычного AE:** латентное пространство «дырявое» и неструктурированное — никто не заставлял коды заполнять пространство непрерывно. Если взять случайный z и декодировать, получится мусор. Обычный AE **не является генеративной моделью**: у него нет распределения, из которого можно сэмплировать.

**Идея VAE (Kingma & Welling, 2014).** Это латентная вероятностная модель: p_θ(x) = ∫ p_θ(x|z) p(z) dz, где p(z) = N(0, I).
- **Декодер** задаёт p_θ(x|z).
- Истинное апостериорное p_θ(z|x) вычислить нельзя (интеграл неберущийся), поэтому **энкодер** приближает его распределением q_φ(z|x) = N(μ_φ(x), diag σ²_φ(x)). Энкодер выдаёт не точку, а **распределение**.

**Вывод ELBO — откуда функция потерь.** Для любого q:
$$\log p_\theta(x) = \underbrace{\mathbb{E}_{q_\varphi(z|x)}\big[\log p_\theta(x|z)\big] - D_{KL}\big(q_\varphi(z|x)\,\|\,p(z)\big)}_{\text{ELBO}(x;\ \theta,\varphi)} + \underbrace{D_{KL}\big(q_\varphi(z|x)\,\|\,p_\theta(z|x)\big)}_{\ge\ 0}$$

Так как KL ≥ 0, ELBO ≤ log p(x) — **нижняя граница логарифма правдоподобия** (Evidence Lower BOund). Максимизируя ELBO по θ и φ, мы одновременно:
- увеличиваем правдоподобие данных;
- приближаем q к истинному апостериорному распределению.

$$\mathcal{L}_{ELBO} = \underbrace{\mathbb{E}_{q(z|x)}\big[\log p(x|z)\big]}_{\text{реконструкция}} - \underbrace{D_{KL}\big(q(z|x)\,\|\,p(z)\big)}_{\text{регуляризатор}}$$

**На практике минимизируем** −ELBO (при гауссовском декодере первый член сводится к MSE):
$$L = \underbrace{\|x-\hat x\|^2}_{\text{reconstruction loss}} + \beta\cdot \underbrace{D_{KL}\big(N(\mu,\sigma^2)\,\|\,N(0,I)\big)}_{\text{KL-дивергенция}}$$

Коэффициент β фактически отражает дисперсию шума декодера σ² (β = 1 — «честный» ELBO при соответствующем масштабе).

**KL для диагональной гауссианы и N(0, I)** имеет аналитический вид (сумма по d латентным координатам):
$$D_{KL} = -\tfrac12\sum_{j=1}^{d}\big(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2\big)$$

Энкодер обычно выдаёт **log σ²**, а не σ — так σ гарантированно положительна, а обучение численно устойчиво. KL = 0 ровно при μ = 0, σ = 1.

**Reparametrization trick (обязательно знать!).** Нужен градиент ∇_φ E_{q_φ(z|x)}[log p(x|z)], но сэмплирование z ~ N(μ, σ²) — случайная операция, и через неё не проходит градиент по μ и σ. Записываем
$$z = \mu_\varphi(x) + \sigma_\varphi(x) \odot \varepsilon, \qquad \varepsilon \sim N(0, I)$$
$$\nabla_\varphi\, \mathbb{E}_{q_\varphi(z|x)}\big[f(z)\big] = \mathbb{E}_{\varepsilon\sim N(0,I)}\big[\nabla_\varphi f(\mu_\varphi + \sigma_\varphi\odot\varepsilon)\big]$$

Случайность вынесена в ε, которая от параметров не зависит, а z — детерминированная дифференцируемая функция μ и σ → backprop работает. Матожидание оценивается по одному сэмплу ε на объект. Такая оценка градиента имеет намного меньшую дисперсию, чем score-function (REINFORCE) оценка.

**Генерация:** z ~ N(0, I) → декодер → x̂. Энкодер при генерации не нужен.

**Баланс двух слагаемых — интуиция.**
- Реконструкция тянет коды разных объектов **врозь** (чтобы их различать).
- KL тянет все q(z|x) **к N(0, I)**: коды перекрываются и заполняют пространство без дыр, поэтому соседние z декодируются в похожие объекты.
- Слишком сильный KL (или слишком мощный авторегрессионный декодер) → **posterior collapse**: q(z|x) ≈ p(z), модель игнорирует z.
- **β-VAE** (Higgins et al., 2017, β > 1) даёт более «распутанные» (disentangled) представления — отдельные координаты z отвечают за отдельные факторы (поворот, размер) — ценой качества реконструкции.

**VAE vs GAN:**

| | VAE | GAN |
|---|---|---|
| Обучение | устойчивое, обычная минимизация | minimax-игра, нестабильно |
| Латентное пространство | структурированное, есть энкодер x → z | нет энкодера |
| Правдоподобие | даёт **нижнюю границу** log p(x) (ELBO); точное значение не вычислимо | правдоподобие не определено |
| Покрытие мод | хорошее | риск mode collapse |
| Картинки | **размытые**: MSE соответствует гауссовскому шуму, и оптимальный ответ при неопределённости — среднее правдоподобных вариантов | резкие и реалистичные |

> ⚠️ Неточно говорить, что VAE даёт «явную оценку правдоподобия». Он оптимизирует и позволяет оценить **нижнюю границу** (ELBO); более точные оценки получают importance sampling (IWAE).

<details>
<summary>Проверь себя</summary>

1. **Чем AE со скрытым размером 1000 для MNIST (784 пикселя) рискует без регуляризации?** — *Выучить тождественное копирование.*
2. **Почему ELBO — нижняя граница?** — *log p(x) = ELBO + KL(q ‖ p(z|x)), а KL ≥ 0.*
3. **Чему равна KL при μ = 0, log σ² = 0?** — *Нулю.*
4. **Зачем reparametrization trick, если можно просто сэмплировать z?** — *Через операцию сэмплирования не проходит градиент по μ и σ, а после перепараметризации z — дифференцируемая функция параметров.*
5. **Почему обычный AE плохо генерирует из случайного z?** — *Латентное пространство не приведено к известному распределению, и случайная точка попадает в «дыру».*
