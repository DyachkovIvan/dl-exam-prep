# Тема 11. Автокодировщики и VAE

## 11.1 Что такое автокодировщик (частый открытый вопрос)

**Автокодировщик (autoencoder)** — нейросеть, которая обучается **восстанавливать свой собственный вход**. Состоит из:
- **Encoder** f: x → z, сжимает вход в скрытое представление (latent code, «бутылочное горлышко», bottleneck);
- **Decoder** g: z → x̂, восстанавливает вход из кода.

Обучение **без учителя (self-supervised)**: минимизируется ошибка реконструкции
$$L = \|x - g(f(x))\|^2 \quad (\text{MSE}) \quad \text{или binary cross-entropy для }[0,1]\text{-данных}.$$
Метки не нужны — «правильный ответ» это сам вход.

**Зачем:** снижение размерности (нелинейный аналог PCA — линейный AE с MSE выучивает ровно подпространство PCA), предобучение и извлечение признаков, шумоподавление, детекция аномалий (у аномалии большая ошибка реконструкции), сжатие, генерация (для VAE).

Ключевое: **узкое место (bottleneck)** заставляет сеть выучить сжатое осмысленное представление вместо тождественного отображения. Если размерность z ≥ размерности x и нет регуляризации, AE выучит копирование (identity) и станет бесполезным.

## 11.2 Типы автокодировщиков

| Тип | Идея |
|---|---|
| **Undercomplete (обычный)** | dim(z) < dim(x), сжатие за счёт узкого горлышка |
| **Denoising (DAE)** | на вход подаётся зашумлённый x̃, восстанавливать нужно чистый x → устойчивые признаки |
| **Sparse** | штраф на активации кода (L1 или KL к малой средней активации) → разреженный код, размерность z может быть большой |
| **Contractive (CAE)** | штраф на норму Якобиана энкодера → представление устойчиво к малым изменениям входа |
| **Convolutional** | encoder из Conv+Pool, decoder из транспонированных свёрток/upsampling — для картинок |
| **Sequence (LSTM) AE** | для последовательностей |
| **Variational (VAE)** | вероятностный, генеративный — см. ниже |
| **Masked AE (MAE)** | маскируем часть входа и восстанавливаем (BERT, MAE для картинок) |

## 11.3 Вариационный автокодировщик (VAE)

**Проблема обычного AE:** латентное пространство «дырявое» — если взять случайный z и декодировать, получится мусор. AE **не является генеративной моделью**.

**Идея VAE:** энкодер выдаёт не точку, а **распределение**: q(z|x) = N(μ(x), σ²(x)). Латентное пространство принуждается быть похожим на N(0, I), тогда можно сэмплировать z ~ N(0,I) и генерировать новые объекты.

**Функция потерь (ELBO, максимизируем нижнюю границу правдоподобия):**
$$\mathcal{L} = \underbrace{\mathbb{E}_{q(z|x)}\big[\log p(x|z)\big]}_{\text{реконструкция}} - \underbrace{D_{KL}\big(q(z|x)\,\|\,p(z)\big)}_{\text{регуляризатор}}$$

На практике минимизируем:
$$L = \underbrace{\|x-\hat x\|^2}_{\text{reconstruction loss}} + \beta\cdot \underbrace{D_{KL}\big(N(\mu,\sigma^2)\,\|\,N(0,I)\big)}_{\text{KL-дивергенция}}$$
где KL для гауссианы имеет аналитический вид:
$$D_{KL} = -\tfrac12\sum_{j}\big(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2\big)$$

**Reparametrization trick (обязательно знать!):** сэмплирование z ~ N(μ,σ²) недифференцируемо и через него не проходит градиент. Записываем
$$z = \mu + \sigma \odot \varepsilon, \qquad \varepsilon \sim N(0, I)$$
Теперь случайность вынесена в ε (не зависит от параметров), а z — детерминированная дифференцируемая функция μ и σ → backprop работает.

**Баланс двух слагаемых:** реконструкция тянет к точности, KL — к «гладкости» и непрерывности латентного пространства. Слишком сильный KL → *posterior collapse* (модель игнорирует z). **β-VAE** (β>1) даёт более disentangled-представления ценой качества реконструкции.

**VAE vs GAN:** VAE даёт устойчивое обучение, осмысленное латентное пространство и явную оценку правдоподобия, но картинки **размытые** (из-за MSE/усреднения по распределению). GAN даёт резкие реалистичные картинки, но обучается нестабильно и может схлопываться в mode collapse.
