# Тема 15. Диффузионные модели

## 15.1 Общая идея

Диффузионная модель учится **обращать процесс постепенного зашумления**:
- **Прямой процесс** — данные шаг за шагом превращают в чистый гауссов шум. Процесс фиксированный, без обучаемых параметров.
- **Обратный процесс** — нейросеть учат делать один шаг назад, то есть убирать немного шума.
- **Генерация** — старт из случайного шума и T шагов «расшумления».

**Почему это проще, чем GAN или VAE «за один шаг».** Превратить шум в картинку сразу — очень сложное отображение. Убрать *немного* шума с чуть зашумлённой картинки — простая задача, для которой обратный шаг хорошо приближается гауссианой. Сложная генерация разбивается на много простых шагов, и каждый обучается обычной регрессией (MSE) — без minimax-игры.

Идея — Sohl-Dickstein et al., 2015; практическая форма, которая сделала метод конкурентным, — **DDPM** (Ho, Jain, Abbeel, 2020).

## 15.2 Прямой (forward) процесс — фиксированный, без обучения

Марковская цепь, добавляющая гауссов шум по расписанию дисперсий β₁, …, β_T. В DDPM **T = 1000**, β растёт линейно от 10⁻⁴ до 0.02:
$$q(x_t \mid x_{t-1}) = \mathcal{N}\big(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\big)$$

Множитель √(1−β_t) нужен, чтобы дисперсия сигнала не росла: если Var(x_{t−1}) = 1, то Var(x_t) = (1−β_t) + β_t = 1.

**Ключевое свойство (closed form).** x_t можно получить из x₀ за один шаг. Пусть α_t = 1 − β_t, ᾱ_t = ∏_{s≤t} α_s. Тогда
$$q(x_t\mid x_0)=\mathcal{N}\big(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)I\big)
\quad\Longleftrightarrow\quad
x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon,\quad \varepsilon\sim \mathcal N(0,I)$$

**Почему так (индукция по одному шагу).** x_t = √α_t x_{t−1} + √(1−α_t) ε_t. Подставим x_{t−1} = √ᾱ_{t−1} x₀ + √(1−ᾱ_{t−1}) ε′. Сумма двух независимых гауссиан — гауссиана с суммой дисперсий:
$$\alpha_t(1-\bar\alpha_{t-1}) + (1-\alpha_t) = 1 - \alpha_t\bar\alpha_{t-1} = 1-\bar\alpha_t$$

**Следствия:**
- При обучении не нужно прогонять цепь — достаточно взять случайный t и сразу получить x_t.
- При t → T: ᾱ_T → 0, x_T ≈ N(0, I) — начальная точка генерации не зависит от данных.
- **Отношение сигнал/шум** SNR(t) = ᾱ_t/(1−ᾱ_t) монотонно убывает — удобный взгляд на расписание шума.

## 15.3 Обратный (reverse) процесс — то, что обучается

$$p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\big(x_{t-1};\ \mu_\theta(x_t,t),\ \sigma_t^2 I\big), \qquad p(x_T) = \mathcal N(0, I)$$

Если β_t малы, истинные обратные переходы q(x_{t−1}|x_t) тоже близки к гауссовым — поэтому модель можно искать в таком виде. В DDPM дисперсия не обучается: σ²_t = β_t или σ²_t = β̃_t (см. ниже), оба варианта дали похожие результаты.

**Что мы знаем точно — апостериорное распределение прямого процесса.** Истинное q(x_{t−1}|x_t) неизвестно, но **при известном x₀** оно вычисляется по формуле Байеса и гауссово:
$$q(x_{t-1}\mid x_t, x_0) = \mathcal N\big(x_{t-1};\ \tilde\mu_t(x_t, x_0),\ \tilde\beta_t I\big)$$
$$\tilde\mu_t = \frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}\,x_0 + \frac{\sqrt{\alpha_t}\,(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,x_t, \qquad \tilde\beta_t = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\,\beta_t$$

**Функция потерь из вариационной границы.** Как в VAE, максимизируется ELBO. Она раскладывается на сумму KL-дивергенций между гауссианами:
$$\mathbb{E}\big[-\log p_\theta(x_0)\big] \le \mathbb{E}_q\Big[\underbrace{D_{KL}\big(q(x_T|x_0)\,\|\,p(x_T)\big)}_{L_T\text{ — без параметров}} + \sum_{t>1}\underbrace{D_{KL}\big(q(x_{t-1}|x_t,x_0)\,\|\,p_\theta(x_{t-1}|x_t)\big)}_{L_{t-1}} \underbrace{- \log p_\theta(x_0|x_1)}_{L_0}\Big]$$

Каждое L_{t−1} — KL между двумя гауссианами с одинаковой дисперсией, то есть с точностью до константы ‖μ̃_t − μ_θ‖². **Сеть учится предсказывать среднее апостериорного распределения.**

## 15.4 Параметризация через шум (DDPM)

Из closed form выразим x₀ = (x_t − √(1−ᾱ_t) ε)/√ᾱ_t и подставим в μ̃_t. Получится
$$\tilde\mu_t = \frac{1}{\sqrt{\alpha_t}}\Big(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\varepsilon\Big)$$

Единственное неизвестное здесь — шум ε. Поэтому сеть предсказывает **добавленный шум** ε_θ(x_t, t), а среднее вычисляется по той же формуле:
$$\mu_\theta(x_t,t)=\frac{1}{\sqrt{\alpha_t}}\Big(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\varepsilon_\theta(x_t,t)\Big)$$

Тогда ‖μ̃_t − μ_θ‖² ∝ ‖ε − ε_θ‖². Авторы выбросили весовые коэффициенты перед слагаемыми — получилась **упрощённая (перевзвешенная) граница** — и **функция потерь свелась к обычному MSE по шуму**:
$$L_{simple} = \mathbb{E}_{x_0,\ \varepsilon,\ t}\Big[\big\|\varepsilon - \varepsilon_\theta\big(\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon,\ t\big)\big\|^2\Big]$$

Это и есть «параметризация через предсказание шума» — главный технический ответ на вопрос билета. Без весов меньше внимания уделяется лёгким шагам с малым t, и качество сэмплов на практике выше.

**Связь с score matching (понимание).** Для q(x_t|x₀) градиент логарифма плотности — **score**:
$$\nabla_{x_t}\log q(x_t\mid x_0) = -\frac{x_t - \sqrt{\bar\alpha_t}\,x_0}{1-\bar\alpha_t} = -\frac{\varepsilon}{\sqrt{1-\bar\alpha_t}}$$

Значит, предсказывая шум, сеть оценивает score: ε_θ(x_t, t) ≈ −√(1−ᾱ_t)·∇ log q_t(x_t). Сэмплирование DDPM похоже на **ланжевеновскую динамику** — шаг вверх по градиенту плотности данных плюс шум. Это объединяет DDPM и score-based модели (Song & Ermon) в одну картину.

**Альтернативные параметризации:** предсказывать сам x₀ или **v-prediction** (Salimans & Ho, 2022): v = √ᾱ_t ε − √(1−ᾱ_t) x₀. Она устойчивее при очень низком SNR, где предсказание по ε плохо обусловлено.

**Алгоритм обучения (Algorithm 1):**
1. взять x₀ из датасета;
2. t ~ Uniform{1, …, T};
3. ε ~ N(0, I);
4. составить x_t = √ᾱ_t x₀ + √(1−ᾱ_t) ε;
5. шаг градиента по ‖ε − ε_θ(x_t, t)‖².

**Алгоритм сэмплирования (Algorithm 2):** x_T ~ N(0, I); для t = T, …, 1: z ~ N(0, I), если t > 1, иначе z = 0;
$$x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\Big(x_t - \frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\,\varepsilon_\theta(x_t,t)\Big) + \sigma_t z$$

Результат — x₀. На последнем шаге шум не добавляется.

**Архитектура:**
- U-Net с skip-connections и ResNet-блоками;
- self-attention на средних разрешениях;
- **эмбеддинг шага t** (синусоидальный, как позиционное кодирование в трансформере) подаётся в каждый блок — одна сеть обслуживает все уровни шума.

## 15.5 Ускорение, латентная диффузия, управление

**DDIM** (Song, Meng, Ermon, 2021) — обобщает прямой процесс до не-марковского с теми же маргиналами q(x_t|x₀). Поэтому годится **та же обученная сеть** без переобучения. При η = 0 сэмплирование **детерминированное** и допускает пропуск шагов: 20–100 вместо 1000. Детерминированность даёт осмысленную интерполяцию в x_T.

**Latent Diffusion / Stable Diffusion** (Rombach et al., 2022) — диффузия идёт не в пикселях, а в латентном пространстве предобученного автокодировщика. Для Stable Diffusion 512×512×3 → 64×64×4, понижение в 8 раз по каждой стороне. Вычисления в разы дешевле; условие (текст) подаётся через **cross-attention** в U-Net.

**Classifier guidance** (Dhariwal & Nichol, 2021) — к score добавляется градиент отдельного классификатора, обученного на **зашумлённых** картинках: ∇ log p(x_t) + s·∇ log p_φ(y|x_t). Эта работа показала, что диффузия превосходит GAN по FID на ImageNet («Diffusion Models Beat GANs»).

**Classifier-free guidance** (Ho & Salimans, 2022) — отдельный классификатор не нужен.
- Обучается **одна сеть**: с вероятностью p_uncond (в статье 0.1–0.2; 0.5 было хуже) условие c заменяется на пустой токен ∅. Одна сеть умеет и условное, и безусловное предсказание.
- На сэмплировании — два прохода и экстраполяция от безусловного предсказания к условному:

$$\tilde\varepsilon_\theta(x_t, c) = (1+w)\,\varepsilon_\theta(x_t, c) - w\,\varepsilon_\theta(x_t) = \varepsilon_\theta(x_t) + (1+w)\big(\varepsilon_\theta(x_t,c) - \varepsilon_\theta(x_t)\big)$$

- w — «сила следования условию»: больше w → точнее соответствие промпту и выше качество отдельных сэмплов, но меньше разнообразие. Во многих библиотеках пишут ε_u + s(ε_c − ε_u), где s = 1 + w.

> ⚠️ Classifier-free guidance — это **не** две отдельно обученные модели, а одна сеть, обученная со случайным выбрасыванием условия.

**Диффузия vs GAN:**

| | Диффузия | GAN |
|---|---|---|
| Обучение | устойчивое: обычный MSE, нет minimax-игры | нестабильное |
| Разнообразие и покрытие мод | хорошее | риск mode collapse |
| Качество (FID) | на ImageNet лучше (Dhariwal & Nichol, 2021) | — |
| Скорость генерации | **медленно**: десятки–сотни проходов сети | один проход |
| Правдоподобие | есть вариационная граница | не определено |

## 15.6 DALL·E

**DALL·E 1 (Ramesh et al., 2021)** — авторегрессионный трансформер, **диффузии здесь нет**.
- **Этап 1:** дискретный VAE (dVAE) сжимает картинку 256×256 в сетку **32×32 = 1024 токена**, словарь 8192.
- **Этап 2:** трансформер на **12 млрд параметров** моделирует единую последовательность: до 256 BPE-токенов текста (словарь 16 384), затем 1024 токена изображения — предсказывает следующий токен. Обучен на 250 млн пар текст–изображение.
- **Ранжирование:** генерируется много кандидатов (в оценках статьи — 512), лучшие отбираются моделью **CLIP** по соответствию тексту.

**DALL·E 2 / unCLIP (Ramesh et al., 2022)** — **диффузионная**:
1. текст → CLIP-текстовый эмбеддинг;
2. **prior** переводит его в CLIP-**image**-эмбеддинг. Пробовали авторегрессионный и диффузионный prior; диффузионный вышел не хуже и вычислительно эффективнее;
3. **decoder** — диффузионная модель, модифицированный GLIDE — генерирует изображение 64×64, обусловленное image-эмбеддингом;
4. два диффузионных **upsampler**-а: 64 → 256 → 1024.

Используется classifier-free guidance. Позволяет делать **вариации** картинки (разные декодирования одного эмбеддинга) и **интерполяции** в пространстве CLIP-эмбеддингов.

**DALL·E 3 (Betker et al., 2023)** — основной вклад в данные, а не в архитектуру. Модель обучали на **синтетических подробных подписях**, сгенерированных специально обученным captioner'ом (большая часть обучающих подписей — синтетические). Это резко улучшило следование сложным промптам. В продукте промпт пользователя дополнительно переписывается LLM (ChatGPT).

2. **Что предсказывает сеть в DDPM и какая функция потерь?** — *Добавленный шум ε; MSE ‖ε − ε_θ(x_t, t)‖².*
3. **Как связан предсказанный шум со score?** — *ε_θ ≈ −√(1−ᾱ_t)·∇ log q(x_t).*
4. **Зачем модели номер шага t на входе?** — *Одна сеть расшумляет на всех уровнях шума; ей нужно знать, сколько шума убирать.*
5. **Нужно ли переобучать модель, чтобы сэмплировать DDIM?** — *Нет, DDIM использует ту же сеть с тем же лоссом.*
6. **Что будет при w = 0 в classifier-free guidance?** — *Обычное условное предсказание ε_θ(x_t, c) без усиления.*
7. **Есть ли диффузия в DALL·E 1?** — *Нет: dVAE + авторегрессионный трансформер + ранжирование CLIP.*
