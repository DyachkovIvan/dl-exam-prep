# Тема 10. Трансформеры: внимание, encoder-decoder, seq2seq

## 10.1 Seq2seq и мотивация внимания

**Задача seq2seq:** по входной последовательности x = (x₁,…,x_n) породить выходную y = (y₁,…,y_m), длины могут отличаться. Модель задаёт авторегрессионное разложение
$$p(y\mid x) = \prod_{t=1}^{m} p\big(y_t \mid y_{<t},\ x\big)$$

Классический **seq2seq** (Sutskever et al., 2014; Cho et al., 2014): RNN-энкодер сжимает всю входную последовательность в один вектор контекста c = h_n, RNN-декодер генерирует выход, опираясь на c.

**Bottleneck-проблема:** весь смысл длинного предложения должен уместиться в один вектор фиксированной длины; качество перевода падает с длиной.

**Attention (Bahdanau, Cho, Bengio, 2015):** декодер на каждом шаге t смотрит на **все** скрытые состояния энкодера h_j и берёт их взвешенную сумму. Веса зависят от текущего состояния декодера s_{t−1} («аддитивное» внимание):
$$e_{tj} = v^\top \tanh(W s_{t-1} + U h_j), \qquad \alpha_{tj} = \frac{\exp e_{tj}}{\sum_{k}\exp e_{tk}}, \qquad c_t = \sum_{j}\alpha_{tj}\, h_j$$

Внимание = «мягкий, дифференцируемый поиск по памяти»: вместо выбора одного элемента берётся взвешенное среднее всех. Бонус — матрица α интерпретируема как выравнивание слов при переводе.

**Transformer (Vaswani et al., 2017, «Attention Is All You Need»):** рекуррентность убрали совсем, оставили только внимание и позиционно-независимые полносвязные слои. Отсюда:
- **полная параллелизация по позициям** на обучении — главное практическое преимущество над RNN;
- путь длины O(1) между любыми двумя токенами вместо O(n).

## 10.2 Scaled Dot-Product Attention

Пусть X ∈ ℝ^{n×d_model} — последовательность из n векторов. Проекции:
$$Q = XW^Q \in \mathbb{R}^{n\times d_k},\quad K = XW^K \in \mathbb{R}^{n\times d_k},\quad V = XW^V \in \mathbb{R}^{n\times d_v}$$
$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M\right)V \in \mathbb{R}^{n\times d_v}$$

- **Q (query)** — «что я ищу», **K (key)** — «чем я могу быть найден», **V (value)** — «что я отдам, если меня выберут».
- QKᵀ ∈ ℝ^{n×n} — матрица схожести «все со всеми»: элемент (i, j) — насколько токен i «интересуется» токеном j.
- softmax **по строкам** → веса внимания (каждая строка — распределение, сумма 1); выход i-го токена = взвешенная сумма value.
- M — маска: 0 для разрешённых позиций и −∞ для запрещённых (после softmax их вес станет 0).

**Зачем делить на √d_k — вывод.** Пусть компоненты q и k независимы, со средним 0 и дисперсией 1. Тогда
$$q\cdot k = \sum_{i=1}^{d_k} q_i k_i, \qquad \mathbb{E}[q\cdot k] = 0, \qquad \operatorname{Var}(q\cdot k) = d_k$$

При d_k = 512 типичные значения логитов порядка ±√512 ≈ ±22. Softmax на таких числах почти one-hot → его градиенты почти нулевые. Деление на √d_k возвращает дисперсию к 1.

**Multi-Head Attention:** h параллельных «голов» со своими проекциями, результаты конкатенируются и проецируются:
$$\text{MHA}(X) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\,W^O, \qquad \text{head}_i = \text{Attention}(XW_i^Q,\ XW_i^K,\ XW_i^V)$$

В базовой модели d_model = 512, h = 8, d_k = d_v = d_model/h = 64 — суммарная стоимость как у одной «широкой» головы. Параметров в MHA: 4·d_model² (+ bias).

**Зачем несколько голов:** одна голова даёт одно усреднение и «размывает» разные типы связей; разные головы ловят разные зависимости (синтаксис, кореференция, соседние позиции) — как разные фильтры в CNN.

**Виды внимания:**
- **Self-attention** — Q, K, V из одной последовательности (энкодер; и декодер сам с собой).
- **Masked (causal) self-attention** — в декодере M_ij = −∞ при j > i: позиция i видит только себя и прошлое. Это позволяет на обучении считать все позиции параллельно и при этом не «подглядывать» в правильный ответ.
- **Cross-attention** — Q из декодера, K и V из выхода энкодера: именно здесь декодер «читает» вход.

## 10.3 Блоки

**Encoder-блок:** Multi-Head Self-Attention → Add & LayerNorm → Feed-Forward → Add & LayerNorm.
**Decoder-блок:** Masked Self-Attention → Add&Norm → **Cross-Attention** (на выход энкодера) → Add&Norm → FFN → Add&Norm.

В оригинале N = 6 блоков в энкодере и 6 в декодере.

**Feed-Forward** применяется к каждой позиции **независимо**, с общими весами (d_ff = 2048 = 4·d_model):
$$\text{FFN}(x) = \max(0,\ xW_1 + b_1)\,W_2 + b_2$$

- **Residual connections** — чтобы градиент проходил через десятки слоёв (якобиан I + ∂F/∂x, как в ResNet).
- **LayerNorm** (не BatchNorm!) — не зависит от батча и длины.
- **Post-LN vs Pre-LN.** Оригинал — Post-LN: x ← LN(x + Sublayer(x)). Современный стандарт — Pre-LN: x ← x + Sublayer(LN(x)). У Pre-LN «чистая» residual-магистраль, он устойчивее и часто обходится без долгого warmup (Xiong et al., 2020).

**Positional Encoding** — обязателен. Self-attention **перестановочно-эквивариантен**: SA(XP) = SA(X)P для любой перестановочной матрицы P. Переставили токены — выходы переставились так же, а о порядке модель не знает ничего. «Мама мыла раму» и «раму мыла мама» дали бы одинаковый набор векторов.

Оригинал — синусоиды разных частот, прибавляемые к эмбеддингам:
$$PE_{(pos,\,2i)} = \sin\!\Big(\frac{pos}{10000^{2i/d_{model}}}\Big), \qquad PE_{(pos,\,2i+1)} = \cos\!\Big(\frac{pos}{10000^{2i/d_{model}}}\Big)$$

Свойство, ради которого их выбрали: PE_{pos+k} — **линейная функция** от PE_{pos} (поворот в каждой паре координат), поэтому модели легко выучить относительные сдвиги. Современные варианты — обучаемые эмбеддинги позиций (BERT, GPT-2), RoPE (поворот Q и K, LLaMA), ALiBi.

## 10.4 Обучение и инференс

- **Обучение (teacher forcing):** на вход декодеру подаётся правильный выход, сдвинутый на один токен вправо; causal-маска не даёт видеть будущее. Loss — cross-entropy на каждой позиции, все позиции считаются **параллельно**.
- **Инференс:** авторегрессионно, по одному токену (greedy, beam search, sampling с температурой / top-p). Уже посчитанные K и V прошлых токенов кешируют (**KV-cache**), чтобы не пересчитывать.
- В оригинале: Adam с β₂ = 0.98, warmup с последующим убыванием η ∝ 1/√step, label smoothing 0.1, dropout 0.1.

## 10.5 Три семейства архитектур

| Тип | Что | Примеры | Предобучение | Задачи |
|---|---|---|---|---|
| **Encoder-only** | двунаправленное кодирование | BERT, RoBERTa | masked LM (маскируется ~15% токенов) | классификация, NER, эмбеддинги |
| **Decoder-only** | авторегрессионная генерация с causal-маской | GPT, LLaMA | предсказание следующего токена | генерация текста, LLM |
| **Encoder-Decoder** | seq2seq | оригинальный Transformer, T5, BART | денойзинг / перевод | перевод, суммаризация |

**Encoder vs Decoder кратко:** энкодер строит контекстные представления входа и видит всю последовательность сразу; декодер генерирует выход по одному токену, видит только уже сгенерированное (маска) плюс, через cross-attention, весь вход.

## 10.6 Transformer vs RNN

Сравнение из таблицы 1 оригинальной статьи (n — длина, d — размерность, k — ядро свёртки):

| Слой | Сложность на слой | Последовательных операций | Максимальный путь |
|---|---|---|---|
| **Self-attention** | O(n²·d) | O(1) | **O(1)** |
| **Recurrent** | O(n·d²) | O(n) | O(n) |
| **Convolutional** | O(k·n·d²) | O(1) | O(log_k n) |

| | RNN/LSTM | Transformer |
|---|---|---|
| Параллелизм по времени на обучении | нет | **да** |
| Путь между далёкими токенами | O(n) | **O(1)** |
| Длинный контекст | затухание градиента | хорошо (пока хватает памяти) |
| Память/время по длине | линейно | **квадратично** — главный минус (отсюда Longformer, Performer, FlashAttention) |
| Знание о порядке | встроено | нужен positional encoding |
| Генерация одного токена | O(1) от длины | растёт с длиной контекста (KV-cache) |

3. **Почему без positional encoding «кот съел мышь» ≈ «мышь съела кота»?** — *Self-attention перестановочно-эквивариантен: набор выходных векторов не зависит от порядка.*
4. **Где в декодере Q, а где K и V в cross-attention?** — *Q — из декодера, K и V — из выхода энкодера.*
5. **Почему трансформер обучается параллельно, а генерирует последовательно?** — *На обучении известен весь правильный выход, и маска позволяет посчитать все позиции сразу; при генерации следующий токен ещё не известен.*
