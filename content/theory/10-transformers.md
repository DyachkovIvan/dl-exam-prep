# Тема 10. Трансформеры: внимание, encoder-decoder, seq2seq

## 10.1 Seq2seq и мотивация внимания

Классический **seq2seq** (2014): RNN-энкодер сжимает всю входную последовательность в один вектор контекста c, RNN-декодер генерирует выход из c.
**Bottleneck-проблема:** весь смысл длинного предложения не влезает в один вектор; качество падает с длиной.

**Attention (Bahdanau, 2015):** декодер на каждом шаге смотрит на **все** скрытые состояния энкодера и берёт их взвешенную сумму, где веса зависят от того, что декодер генерирует сейчас. Внимание = «мягкий поиск по памяти».

**Transformer (Vaswani et al., 2017, «Attention is All You Need»):** убрали рекуррентность вообще, оставили только внимание и полносвязные слои → **полная параллелизация по времени** (главное преимущество над RNN) и прямой доступ к любому элементу последовательности (путь длины O(1) вместо O(n)).

## 10.2 Scaled Dot-Product Attention

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

- **Q (query)** — «что я ищу», **K (key)** — «чем я могу быть найден», **V (value)** — «что я отдам, если меня выберут». Все три получаются линейными проекциями входа: Q = XW_Q и т.д.
- QKᵀ — матрица схожести всех со всеми (N×N).
- **Деление на √d_k** — иначе при больших d_k скалярные произведения имеют большую дисперсию, softmax уходит в насыщение и градиент затухает.
- softmax по строкам → веса внимания (сумма 1), умножаем на V → взвешенная сумма значений.

**Multi-Head Attention:** h параллельных «голов» с разными проекциями, результаты конкатенируются и проецируются:
$$\text{MHA}(X) = \text{Concat}(head_1..head_h)W^O, \quad head_i = \text{Attention}(XW_i^Q, XW_i^K, XW_i^V)$$
Зачем: разные головы ловят разные типы зависимостей (синтаксис, кореференция, позиционные) — как разные фильтры в CNN.

**Виды внимания:**
- **Self-attention** — Q, K, V из одной последовательности (энкодер; и декодер сам с собой).
- **Masked (causal) self-attention** — в декодере будущие позиции маскируются (−∞ перед softmax), чтобы при генерации не подглядывать вперёд.
- **Cross-attention** — Q из декодера, K и V из энкодера: именно здесь декодер «читает» вход.

**Сложность:** O(N²·d) по времени и памяти — квадратично по длине последовательности. Это главный минус трансформера (отсюда Longformer, Performer, FlashAttention).

## 10.3 Блоки

**Encoder-блок:** Multi-Head Self-Attention → Add & LayerNorm → Feed-Forward (два линейных слоя с ReLU/GELU, расширение обычно ×4) → Add & LayerNorm.
**Decoder-блок:** Masked Self-Attention → Add&Norm → **Cross-Attention** (на выход энкодера) → Add&Norm → FFN → Add&Norm.

- **Residual connections** — чтобы градиент проходил через десятки слоёв.
- **LayerNorm** (не BatchNorm!) — не зависит от батча и длины. Варианты Post-LN (оригинал) и Pre-LN (устойчивее, стандарт сейчас).
- **Positional Encoding** — обязательно: attention сам по себе **перестановочно-инвариантен**, порядка слов не знает. Оригинал — синусоиды разных частот; современные — обучаемые эмбеддинги позиций, RoPE, ALiBi.

## 10.4 Три семейства архитектур

| Тип | Что | Примеры | Задачи |
|---|---|---|---|
| **Encoder-only** | двунаправленное кодирование | BERT, RoBERTa | классификация, NER, эмбеддинги |
| **Decoder-only** | авторегрессионная генерация с causal-маской | GPT, LLaMA | генерация текста, LLM |
| **Encoder-Decoder** | seq2seq | оригинальный Transformer, T5, BART | перевод, суммаризация |

**Encoder vs Decoder кратко:** энкодер строит контекстные представления входа, видит всю последовательность сразу; декодер генерирует выход по одному токену, видит только уже сгенерированное (маска) плюс, через cross-attention, весь вход.

## 10.5 Transformer vs RNN

| | RNN/LSTM | Transformer |
|---|---|---|
| Параллелизм по времени | нет | **да** |
| Путь между далёкими токенами | O(N) | **O(1)** |
| Длинный контекст | затухание градиента | хорошо |
| Сложность по длине | O(N) | **O(N²)** |
| Знание о порядке | встроено | нужен positional encoding |
