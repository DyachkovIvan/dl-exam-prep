# Тема 6. Свёрточные нейронные сети (CNN)

## 6.1 Зачем свёртки

Полносвязный слой на картинке 224×224×3 (150 528 входов) даже при 1000 нейронах даёт ~150 млн параметров и игнорирует пространственную структуру. Свёртка вносит три априорных предположения (inductive bias):

- **Локальность** — нейрон смотрит на небольшое рецептивное поле: соседние пиксели связаны сильнее далёких.
- **Разделение весов** (weight sharing) — одно ядро скользит по всей картинке: признак «край» полезен в любом месте. Параметров в разы меньше.
- **Эквивариантность к сдвигу** — сдвинули вход, карта признаков сдвинулась так же. Формально, для оператора сдвига T: Conv(T x) = T Conv(x). Это точно выполняется при stride 1 без учёта краёв; stride и pooling эквивариантность частично нарушают.

**Эквивариантность ≠ инвариантность.** Инвариантность (выход не меняется при сдвиге) получается приближённо — за счёт pooling и global average pooling в конце.

## 6.2 Формальное определение

В DL-фреймворках «свёртка» — это на самом деле **взаимная корреляция** (ядро не переворачивается). Для входа X ∈ ℝ^{C_in×H×W}, ядер W ∈ ℝ^{C_out×C_in×k×k}, шага s, паддинга p (вход уже дополнен) и dilation d:
$$Y_{c',\,i,\,j} = b_{c'} + \sum_{c=1}^{C_{in}}\sum_{u=0}^{k-1}\sum_{v=0}^{k-1} W_{c',c,u,v}\; X_{c,\ s\cdot i + d\cdot u,\ s\cdot j + d\cdot v}$$

Математическая свёртка отличается переворотом ядра на 180°. Для обучения это неважно: сеть просто выучит перевёрнутое ядро.

**Важно:** ядро всегда захватывает **все входные каналы** — ядро 3×3 на RGB-входе имеет размер 3×3×3.

## 6.3 Термины

- **Kernel / filter** — обучаемый тензор весов (например 3×3×C_in). Один фильтр даёт одну карту признаков (feature map); число фильтров = число выходных каналов.
- **Stride (шаг)** — на сколько пикселей сдвигается ядро. Stride 2 ≈ уменьшение размера вдвое.
- **Padding** — добавление рамки (обычно нулей).
  - `valid` — без padding, размер уменьшается.
  - `same` — padding подобран так, чтобы при stride = 1 размер сохранился; для нечётного ядра k: p = (k−1)/2.
  - Зачем: не терять края и не «съедать» размер с глубиной.
- **Dilation (расширение, atrous)** — ядро с «дырами»: между элементами ядра вставляются d−1 пропусков. Увеличивает **рецептивное поле без роста числа параметров**. Эффективный размер ядра: k_eff = d·(k−1) + 1. Применяется в сегментации (DeepLab), WaveNet.
- **Pooling** — агрегация по окну: **MaxPooling** (максимум) или **AveragePooling** (среднее). Уменьшает разрешение, даёт локальную инвариантность к малым сдвигам, снижает вычисления. **У pooling НЕТ обучаемых параметров.**
- **Global Average Pooling** — усреднение всей карты в одно число на канал, часто вместо Flatten+Dense в конце. Делает сеть независимой от размера входа.
- **1×1 свёртка** — полносвязный слой по каналам в каждой точке: смешивает каналы, меняет их число, дешёвое «узкое место» (bottleneck).

## 6.4 Формула размера выхода (знать наизусть!)

$$H_{out} = \left\lfloor \frac{H_{in} + 2p - d\,(k-1) - 1}{s} \right\rfloor + 1$$

Без dilation (d = 1) это привычное:
$$H_{out} = \left\lfloor \frac{H_{in} + 2p - k}{s} \right\rfloor + 1$$

**Откуда формула.** После паддинга длина входа H_in + 2p. Ядро с эффективным размером k_eff можно поставить в позиции 0, s, 2s, …, пока начало + k_eff ≤ H_in + 2p. Число таких позиций = ⌊(H_in + 2p − k_eff)/s⌋ + 1, а k_eff = d(k−1) + 1 даёт формулу выше. Формула совпадает с документацией PyTorch `Conv2d`.

**Примеры (типовые задачи билета):**
- Вход 28×28, ядро 7×7, stride 1, padding 0: (28 − 7)/1 + 1 = **22 → выход 22×22**.
- Вход 28×28, ядро 3×3, stride 1, padding 1 (`same`): (28 + 2 − 3)/1 + 1 = **28×28**.
- Вход 32×32, ядро 5×5, stride 2, padding 0: ⌊(32 − 5)/2⌋ + 1 = 13 + 1 = **14×14**.
- MaxPool 2×2, stride 2 на 28×28: (28 − 2)/2 + 1 = **14×14**.
- Вход 32×32, ядро 3×3, dilation 2, padding 0: k_eff = 5, (32 − 5) + 1 = **28×28**.

**Транспонированная свёртка** (upsampling в генераторах и декодерах), формула PyTorch `ConvTranspose2d`:
$$H_{out} = (H_{in}-1)\,s - 2p + d\,(k-1) + \text{output\_padding} + 1$$

Пример (DCGAN): 4×4, k = 4, s = 2, p = 1 → (4−1)·2 − 2 + 3 + 1 = **8×8** — удвоение разрешения.

## 6.5 Число параметров свёрточного слоя

$$\#params = (k_h \cdot k_w \cdot C_{in} + 1)\cdot C_{out}$$

(«+1» — bias на каждый выходной канал).

Пример: Conv 3×3, C_in = 64, C_out = 128 → (3·3·64 + 1)·128 = (576+1)·128 = **73 856**.

**От чего зависит число параметров в CNN:** от размера ядра, числа входных и выходных каналов, наличия bias — и **НЕ зависит** от размера входного изображения (это и есть смысл weight sharing). А вот число **вычислений (FLOPs)** и размер активаций от размера картинки зависят: FLOPs ≈ k_h·k_w·C_in·C_out·H_out·W_out.

**Варианты, которые экономят параметры:**
- **Групповая свёртка** с g группами: (k_h·k_w·C_in/g + 1)·C_out.
- **Depthwise separable** (MobileNet): depthwise k×k по каждому каналу + pointwise 1×1 = k²·C_in + C_in·C_out (без bias). Для 3×3, 64 → 128: 576 + 8192 = 8 768 против 73 728 — в ~8 раз меньше.

> ⚠️ Ловушка: «Всегда ли MaxPooling уменьшает число параметров?» — **Нет.** У pooling вообще нет параметров, он не меняет параметры свёрточных слоёв. Он уменьшает **размер карт признаков (активаций)**, и уже за счёт этого может косвенно уменьшить число параметров **последующего полносвязного слоя**. Если после pooling идут только свёртки (или GAP), число параметров сети не изменится. Кроме того, pooling со stride = 1 и padding вообще не уменьшает размер.

## 6.6 Рецептивное поле

Рецептивное поле (RF) нейрона — область входа, которая на него влияет. Для стопки слоёв с ядрами k_l и шагами s_l:
$$r_l = r_{l-1} + (k_l - 1)\prod_{i<l} s_i, \qquad r_0 = 1$$

- Два слоя 3×3 со stride 1: RF = 1 + 2 + 2 = **5**. Три слоя: **7**.
- **Аргумент VGG:** три свёртки 3×3 видят то же поле 7×7, что одна свёртка 7×7, но у них 3·(9C²) = 27C² параметров против 49C² и три нелинейности вместо одной.
- Stride и pooling умножают прирост RF для всех последующих слоёв — поэтому поздние слои «видят» почти всё изображение.

## 6.7 Слои в архитектуре CNN (открытый вопрос билета)

1. **Input layer** — тензор H×W×C.
2. **Convolutional layer** — свёртки с обучаемыми ядрами → карты признаков.
3. **Activation (ReLU)** — нелинейность (иногда считают частью conv-слоя).
4. **Normalization (BatchNorm)** — стабилизация обучения.
5. **Pooling (max/average)** — понижение разрешения.
6. (повтор блоков Conv→BN→ReLU→Pool, число каналов растёт, разрешение падает)
7. **Flatten / Global Average Pooling** — переход к вектору.
8. **Fully-Connected (Dense) layer** — классификатор.
9. **Dropout** — регуляризация в голове.
10. **Output layer** — softmax/sigmoid.

Типичный паттерн: `[Conv → BN → ReLU] × n → Pool` повторяется, потом `GAP → FC → Softmax`.

**Вехи архитектур (для контекста ответа):**
- **LeNet-5** (1998) — первые свёртки + pooling.
- **AlexNet** (2012) — ReLU, dropout, GPU.
- **VGG** (2014) — стопки 3×3.
- **GoogLeNet/Inception** (2014) — параллельные ветви, 1×1 bottleneck.
- **ResNet** (2015) — residual-блок y = x + F(x). Якобиан ∂y/∂x = I + ∂F/∂x содержит единичную матрицу, поэтому градиент проходит к ранним слоям даже при малом ∂F/∂x. Это позволило обучать сети в 100+ слоёв.

## 6.8 Backprop в CNN

Работает так же (цепное правило), с особенностями:
- **Градиент по ядру** = корреляция входа с градиентом по выходу: ∂L/∂W_{c',c,u,v} = Σ_{i,j} ∂L/∂Y_{c',i,j} · X_{c,i+u,j+v} (при s = 1). Ядро использовалось во всех позициях, поэтому градиенты со всех позиций **суммируются** — это следствие weight sharing.
- **Градиент по входу** = «полная» свёртка градиента выхода с повёрнутым на 180° ядром. Это ровно транспонированная свёртка — отсюда её название.
- **MaxPooling:** градиент проходит только в ту позицию, где был максимум (индексы запоминаются на forward), остальные получают 0.
- **AveragePooling:** градиент равномерно распределяется по окну (делится на размер окна).
- **ReLU:** градиент обнуляется там, где вход был отрицательным.

## 6.9 Визуализация CNN

- **Фильтры первого слоя** — визуально похожи на детекторы краёв и цветовых пятен (фильтры Габора).
- **Карты активаций (feature maps)** — что «загорается» на конкретной картинке.
- **Grad-CAM / CAM** — тепловая карта важности. Карты последнего свёрточного слоя взвешиваются усреднёнными градиентами класса по ним, затем применяется ReLU. Показывает, куда сеть «смотрела», принимая решение.
- **Saliency maps / Vanilla gradient** — |∂y_c/∂x|, важность каждого пикселя.
- **Occlusion sensitivity** — заслоняем части картинки и смотрим падение уверенности (Zeiler & Fergus, 2014).
- **Feature/Activation maximization (DeepDream)** — оптимизируем вход, чтобы максимизировать активацию нейрона: показывает, какой паттерн нейрон «ищет».
- **t-SNE/UMAP по эмбеддингам** предпоследнего слоя — видно, как разделились классы.

Общий вывод визуализаций: **иерархия признаков** — ранние слои ловят края и текстуры, средние — части объектов, поздние — объекты целиком.
