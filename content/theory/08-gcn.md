# Тема 8. Графовые нейронные сети: GCN

## 8.1 Постановка

Граф G = (V, E): матрица признаков вершин X ∈ ℝ^(N×F), матрица смежности A ∈ ℝ^(N×N).
Задачи: классификация вершин (node classification), предсказание рёбер (link prediction), классификация графов (graph classification).

Проблема: граф **не имеет регулярной сетки и фиксированного порядка соседей**, поэтому обычная свёртка не применима. Нужна операция, **инвариантная к перестановке** вершин (permutation invariance/equivariance).

## 8.2 Message passing — общая схема всех GNN

На каждом слое каждая вершина:
1. **Aggregate** — собирает сообщения от соседей (сумма/среднее/max — обязательно перестановочно-инвариантная функция),
2. **Update** — комбинирует со своим состоянием и пропускает через обучаемое преобразование + нелинейность.

$$h_v^{(l+1)} = \text{UPDATE}\Big(h_v^{(l)},\ \text{AGGREGATE}\big(\{h_u^{(l)}: u \in N(v)\}\big)\Big)$$

После L слоёв вершина «видит» соседей на расстоянии L (рецептивное поле = L-hop).

## 8.3 GCN (Kipf & Welling, 2017)

Послойное правило:
$$H^{(l+1)} = \sigma\left(\tilde D^{-1/2}\tilde A \tilde D^{-1/2} H^{(l)} W^{(l)}\right)$$

где:
- **Ã = A + I** — добавление **самопетель** (self-loops), чтобы вершина учитывала собственные признаки;
- **D̃** — диагональная матрица степеней Ã;
- **D̃^(−1/2) Ã D̃^(−1/2)** — симметричная нормализация: не даёт вершинам с большой степенью доминировать и стабилизирует спектр (собственные значения в [−1,1]);
- **W^(l)** — обучаемая матрица весов слоя (общая для всех вершин, аналог weight sharing);
- σ — ReLU (на последнем слое softmax).

По сути каждый слой = **усреднение признаков соседей + линейное преобразование + нелинейность**. Это упрощение (первое приближение Чебышёва) спектральной свёртки на графе через лапласиан L = I − D^(−1/2)AD^(−1/2).

**Типичная модель для node classification:** 2 слоя GCN, обучение полусупервизионное (labels лишь у части вершин), loss — cross-entropy по размеченным вершинам.

## 8.4 Свойства и ограничения GCN

- **Транcдуктивность:** классический GCN обучается на всём графе целиком (нужна полная A) и **плохо работает для новых, не виденных вершин** — при их появлении надо пересчитывать. (Это ровно то, что чинит GraphSAGE.)
- **Over-smoothing:** с ростом числа слоёв представления всех вершин сходятся к одинаковым → глубокие GCN работают хуже. На практике 2–3 слоя.
- **Over-squashing:** информация из экспоненциально растущего числа соседей сжимается в вектор фиксированной длины.
- Масштабируемость: нужна вся матрица смежности в памяти.
- Все соседи учитываются с **фиксированными** весами (по степеням) — нет обучаемого внимания. Это чинит **GAT** (Graph Attention Network), где веса соседей вычисляются механизмом внимания.
