# ШПАРГАЛКА: то, что спрашивают чаще всего

## Ш.0 Перед сном: самое важное по главам

Читать сверху вниз: **одной фразой → что назвать → формула → ловушка**. Если по теме всплывает всё перечисленное, тема освоена.

### Тема 1. Оптимизация (SGD, NAG, AdaGrad, RMSProp, Adam)
**Одной фразой:** шаг против градиента, посчитанного по мини-батчу (несмещённая шумная оценка полного градиента).

**Назвать:**
- batch GD (все N, 1 шаг/эпоху) · mini-batch (B) · stochastic (1)
- Momentum — скорость v = γv + ηg (γ ≈ 0.9), гасит колебания в «овраге»
- NAG — градиент в точке «заглядывания» θ − γv
- AdaGrad — шаг ∝ 1/√(сумма g²): хорош для разреженных данных, но шаг затухает
- RMSProp — скользящее среднее g² вместо суммы · Adadelta — без learning rate
- Adam = Momentum + RMSProp + bias correction (β₁ = 0.9, β₂ = 0.999, ε = 1e-8)

**Формула:** θ ← θ − η·g;  Adam: θ ← θ − η·m̂/(√v̂ + ε)

**Ловушка:** v в Adam — нецентрированный 2-й момент E[g²], не дисперсия; Adam тратит память (m и v); NAG ≠ Momentum только точкой вычисления градиента.

### Тема 2. Backpropagation
**Одной фразой:** цепное правило + переиспользование результатов = градиенты по всем весам за один обратный проход (оптимизатор потом их применяет).

**Назвать:**
- forward: z = Wa + b, a = σ(z), loss; **сохранить активации**
- backward: δᴸ = ∇ₐL ⊙ σ′(zᴸ); δˡ = (Wˡ⁺¹)ᵀδˡ⁺¹ ⊙ σ′(zˡ)
- градиенты: ∂L/∂W = δ·aᵀ, ∂L/∂b = δ
- цикл: forward → loss → backward → update → обнулить градиенты
- недостатки: затухание/взрыв градиента, память на активации, backward locking, локальные минимумы, дифференцируемость

**Формула:** softmax + CE → δ = ŷ − y

**Ловушка:** backprop ≠ градиентный спуск; от **взрыва** помогает clipping, а не ReLU; переобучение — не недостаток backprop.

### Тема 3. Регуляризация (Dropout, BatchNorm, аугментация)
**Одной фразой:** всё, что уменьшает ошибку на новых данных, а не на обучающих.

**Назвать:**
- L2 = weight decay (веса × (1 − ηλ)); L1 → разреженность
- early stopping · аугментация · label smoothing
- **Dropout:** маска Бернулли с p, делим на (1 − p); на тесте **выключен**; ансамбль 2ⁿ подсетей; замедляет сходимость
- **BatchNorm:** (x − μ_B)/√(σ²_B + ε), затем γ·x̂ + β; на тесте running mean/var; ускоряет обучение; плох при малом батче
- LayerNorm (по признакам объекта) — трансформеры/RNN; GroupNorm — малые батчи

**Формула:** y = γ·(x − μ_B)/√(σ²_B + ε) + β

**Ловушка:** Pooling — **не** регуляризация; BN центрирует по **батчу**, не по датасету, и не «вариант dropout»; dropout не ускоряет обучение.

### Тема 4. Функции активации
**Одной фразой:** нелинейность; без неё любая глубина = одна линейная модель.

**Назвать:**
- sigmoid: (0, 1), σ′ ≤ 1/4, затухание, не центрирована → выход бинарной и multi-label
- tanh: (−1, 1), центрирована, насыщается → RNN/LSTM
- ReLU: max(0, x), не насыщается при x > 0; минус — dying ReLU → скрытые слои
- Leaky ReLU: αx при x ≤ 0 — градиент не нулевой; PReLU, ELU, GELU
- softmax: сумма 1, мультикласс; линейный выход — регрессия

**Формула:** softmax(z)ᵢ = e^{zᵢ}/Σⱼe^{zⱼ}

**Ловушка:** бинарная → sigmoid; мультикласс → softmax; multi-label → sigmoid на каждом выходе; ReLU — для скрытых слоёв, а не «для регрессии».

### Тема 5. FCNN, MLP, перцептрон
**Одной фразой:** слои «умножить на W, прибавить b, применить активацию»; сигнал идёт только вперёд.

**Назвать:**
- feedforward vs сети с обратными связями (RNN)
- перцептрон Розенблатта: S → A → R элементы; однослойный не решает XOR
- MLP по Румельхарту = все веса обучаются backprop
- параметры слоя: n_in·n_out + n_out
- теорема об универсальной аппроксимации: **существование**, а не «SGD найдёт»; глубина экономнее ширины
- инициализация: все веса = 0 → симметрия, **не** учится; bias = 0 → учится; Xavier (tanh), He (ReLU: 2/n_in)

**Формула:** 784 → 128 → 10: (784·128 + 128) + (128·10 + 10) = 101 770

**Ловушка:** пример из билета: входы 1, 2, 3, веса 4, 5, 6, f(x) = 3x → 3·32 = **96**; гиперпараметры подбирают по валидации, а не градиентом.

### Тема 6. CNN
**Одной фразой:** ядро скользит по входу; локальность + общие веса + эквивариантность к сдвигу.

**Назвать:**
- kernel, padding (valid / same), stride, dilation, pooling (max / avg / GAP / adaptive)
- виды: 1×1, depthwise separable, групповая, транспонированная (увеличение)
- слои: Conv → BN → ReLU → Pool → … → GAP/Flatten → FC → softmax
- backprop: ∂L/∂F = свёртка X с ∂L/∂O; ∂L/∂X = свёртка с ядром, повёрнутым на 180°; max pooling — градиент в позицию максимума
- визуализация: градиентный подъём по пикселям входа, Grad-CAM, saliency
- adversarial: FGSM x + ε·sign(∇ₓJ), защита — adversarial training

**Формулы:** H_out = ⌊(H + 2p − d(k−1) − 1)/s⌋ + 1;  params = (k²·C_in + 1)·C_out

**Ловушка:** параметры **не** зависят от размера картинки, stride и padding; у pooling параметров нет → max pooling не «всегда уменьшает параметры».

### Тема 7. RNN, LSTM, GRU
**Одной фразой:** скрытое состояние hₜ = tanh(W_hh·hₜ₋₁ + W_xh·xₜ + b), одни и те же веса на каждом шаге.

**Назвать:**
- BPTT: развернуть по времени, градиенты общих весов **суммируются**, truncated BPTT
- затухание/взрыв: λ₁ < 1/γ → затухание; clipping от взрыва
- BiRNN: два прохода, конкатенация; не для потоковых задач и генерации
- LSTM: cₜ = fₜ⊙cₜ₋₁ + iₜ⊙c̃ₜ, hₜ = oₜ⊙tanh(cₜ); три вентиля; ∂cₜ/∂cₜ₋₁ = diag(fₜ) → нет затухания
- GRU: 2 вентиля (update, reset), нет cₜ, ≈ 3/4 параметров LSTM
- dropout: variational (одна маска на все шаги); BN → Recurrent BN или LayerNorm

**Формула:** hₜ = tanh(W_hh·hₜ₋₁ + W_xh·xₜ + b)

**Ловушка:** в RNN tanh/sigmoid (ограничены), не ReLU; BPTT ≠ простой backprop — суммирование по времени и затухание.

### Тема 8. GCN
**Одной фразой:** вершина усредняет признаки себя и соседей (с нормировкой по степеням), затем линейный слой и ReLU.

**Назвать:**
- проблемы графов: нет структуры, произвольный порядок вершин (эквивариантность), масштаб
- message passing: AGGREGATE + UPDATE; k слоёв → k-hop окрестность
- Ã = A + I (самопетли), D̃ — степени Ã
- loss — только по размеченным вершинам (полу-обучение)
- минусы: трансдуктивность, over-smoothing, фиксированные веса соседей (→ GAT)

**Формула:** H′ = σ(D̃^{−1/2}·Ã·D̃^{−1/2}·H·W)

**Ловушка:** нормировка нужна из-за спектра [0, 2] до renormalization trick; нельзя подать матрицу смежности в обычную CNN (нет эквивариантности).

### Тема 9. GraphSAGE
**Одной фразой:** учит функцию-агрегатор, а не таблицу эмбеддингов → индуктивность.

**Назвать:**
- sample соседей (S₁ = 25, S₂ = 10) → aggregate → **concat** с собой → L2-нормировка
- агрегаторы: mean, GCN, pooling (MLP + max), LSTM (случайная перестановка)
- обучение: с учителем (CE) или без — позитивные пары из случайных блужданий, отрицательные примеры
- мини-батчи, стоимость O(∏S_k)

**Формула:** hᵥᵏ = σ(Wᵏ·[hᵥᵏ⁻¹ ‖ AGG({hᵤᵏ⁻¹})])

**Ловушка:** GCN — нормированное среднее, всё в одном; GraphSAGE — concat и сэмплирование; DeepWalk трансдуктивен.

### Тема 10. Трансформеры
**Одной фразой:** внимание вместо рекуррентности: каждый токен взвешенно собирает контекст из всех токенов, параллельно.

**Назвать:**
- seq2seq на RNN и bottleneck → внимание Bahdanau
- Q, K, V; softmax(QKᵀ/√d_k)·V; √d_k нужен, чтобы softmax не насыщался
- multi-head (8 голов, d_k = 64), self / masked / cross-attention
- encoder: MHA → Add & LayerNorm → FFN (512→2048→512); decoder: masked MHA → cross-attention → FFN; вход сдвинут вправо
- positional encoding (sin/cos), residual, LayerNorm
- vs RNN: параллелизм, путь O(1), память O(n²); BERT / GPT / T5

**Формула:** Attention(Q, K, V) = softmax(QKᵀ/√d_k)·V

**Ловушка:** self-attention перестановочно-**эквивариантен** (порядка не знает без PE); LayerNorm, а не BatchNorm.

### Тема 11. Автокодировщики и VAE
**Одной фразой:** энкодер сжимает вход в код, декодер восстанавливает; обучение без меток.

**Назвать:**
- применения: снижение размерности, шумоподавление, аномалии, предобучение
- типы: undercomplete, sparse, contractive, denoising, convolutional, masked
- обычный AE не генеративен — «дырявое» латентное пространство
- VAE: кодировщик → μ и σ; z = μ + σ⊙ε (reparametrization trick)
- loss = реконструкция + KL(q(z|x) ‖ N(0, I)); ELBO — нижняя граница log p(x)
- posterior collapse, β-VAE; изображения размытые

**Формула:** L = ‖x − x̂‖² + KL;  KL = −½Σ(1 + log σ² − μ² − σ²)

**Ловушка:** AE с кодом ≥ входа выучит копирование; VAE даёт **нижнюю границу** правдоподобия, а не точную оценку.

### Тема 12. GAN
**Одной фразой:** генератор делает подделки из шума, дискриминатор отличает их от реальных; игра minimax.

**Назвать:**
- V(D, G) = E log D(x) + E log(1 − D(G(z))); D максимизирует, G минимизирует
- оптимальный D* = p_data/(p_data + p_g); в равновесии D = ½, JSD → 0
- L_D = BCE (реальные 1, подделки 0); L_G non-saturating = −log D(G(z)) (подделкам метка 1)
- обучение: чередуем D и G, вторая сеть заморожена
- проблемы: vanishing gradients, mode collapse, отсутствие сходимости; WGAN, FID

**Формула:** L_G^ns = −E log D(G(z))

**Ловушка:** дискриминатор нельзя использовать как «яблоко / не яблоко»; loss дискриминатора выходит на константу; падение loss ≠ прогресс.

### Тема 13. DCGAN
**Одной фразой:** GAN из свёрточных сетей по набору правил для стабильности.

**Назвать:**
- без pooling: strided conv в D, транспонированные свёртки в G
- без полносвязных скрытых слоёв
- BatchNorm везде, **кроме** выхода G и входа D
- G: ReLU, на выходе tanh; D: LeakyReLU(0.2)
- Adam lr = 2e-4, β₁ = 0.5; веса N(0, 0.02)
- G: z → 4×4×1024 → … → 64×64×3; арифметика в латентном пространстве

**Ловушка:** loss тот же, что у обычного GAN — новое только в архитектуре; ConvTranspose даёт шахматные артефакты.

### Тема 14. CGAN
**Одной фразой:** условие y подаётся и в генератор, и в дискриминатор — управляемая генерация p(x | y).

**Назвать:**
- G(z, y), D(x, y); V с условием
- условие в D нужно, иначе G игнорирует условие
- как подают: конкатенация, embedding, conditional BN, projection, AC-GAN
- применения: pix2pix (U-Net + PatchGAN + L1), text-to-image, super-resolution

**Формула:** min_G max_D E log D(x|y) + E log(1 − D(G(z|y)|y))

**Ловушка:** функция оптимизации (игра) ≠ оптимизатор (SGD/Adam); CycleGAN работает без пар.

### Тема 15. Диффузия
**Одной фразой:** прямой процесс добавляет шум (фиксирован), обратный — обучаемый — его убирает.

**Назвать:**
- прямой: q(x_t | x_{t−1}) = N(√(1−β_t)·x_{t−1}, β_t·I), T = 1000, β от 1e-4 до 0.02
- за один шаг: x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε
- обратный: p_θ(x_{t−1} | x_t) — гауссиана; сеть предсказывает **шум** ε_θ(x_t, t); loss — MSE
- U-Net + эмбеддинг шага t; DDIM — быстрее; латентная диффузия (Stable Diffusion)
- classifier-free guidance: (1 + w)·ε(x, c) − w·ε(x) — **одна** сеть с выбрасыванием условия
- DALL·E 1 — dVAE + трансформер + CLIP (без диффузии); DALL·E 2 — prior + диффузионный декодер

**Формула:** L = ‖ε − ε_θ(√ᾱ_t·x₀ + √(1−ᾱ_t)·ε, t)‖²

**Ловушка:** в DALL·E 1 диффузии нет; диффузия медленная, но стабильная и разнообразная.

### Тема 16. RL
**Одной фразой:** агент учится максимизировать суммарную дисконтированную награду, взаимодействуя со средой.

**Назвать:**
- G = Σγᵏ·r; γ — дисконт; MDP (S, A, P, R, γ); марковское свойство
- V, Q; уравнение Беллмана: Q* = E[r + γ·max Q*(s′, a′)]
- исследование/эксплуатация: ε-жадная, softmax, UCB
- Monte Carlo (конец эпизода, без смещения, большая дисперсия) vs TD (каждый шаг, бутстрэппинг)
- Q-learning — off-policy, max; SARSA — on-policy, реальное a′
- DQN: сеть вместо таблицы, **replay buffer** (разрывает корреляции) + **target network** (цель не «убегает»)
- policy gradient: REINFORCE, baseline, actor-critic

**Формула:** Q ← Q + α·[r + γ·max Q(s′, ·) − Q]

**Ловушка:** DQN только для **дискретных** действий; RL — не частный случай обучения с учителем.

### Тема 17. Потери, метрики, bias/variance
**Одной фразой:** потеря — то, что оптимизируем, метрика — то, что оцениваем; смещение и дисперсия говорят, что чинить.

**Назвать:**
- регрессия: MSE (выбросы страшны), MAE (устойчива), Huber (компромисс)
- бинарная — BCE; мультикласс — categorical и sparse CE (одна потеря, разный формат меток); KL ≠ расстояние; hinge — SVM; focal — дисбаланс
- precision = TP/(TP+FP), recall = TP/(TP+FN), F1 — гармоническое; accuracy обманчива при дисбалансе
- train высокая → смещение (модель больше); train ≪ dev → дисперсия (регуляризация, данные)
- transfer learning: заморозить ранние слои; multi-task; end-to-end

**Формула:** CE = H(p) + KL(p ‖ q); F1 = 2PR/(P + R)

**Ловушка:** больше данных лечит дисперсию, но не смещение; dev и test — из одного распределения; MAE как потеря ≠ L1-регуляризация.

## Ш.1 Функции потерь ↔ задачи (задание «сопоставьте» из билета)

| Функция потерь | Формула | Задача |
|---|---|---|
| **MSE (Mean Square Error)** | (1/n)Σ(y−ŷ)² | **Регрессия** (чувствительна к выбросам) |
| **MAE (Mean Absolute Error)** | (1/n)Σ\|y−ŷ\| | **Регрессия** (устойчива к выбросам, недифференцируема в 0) |
| **Huber Loss** | MSE при малой ошибке, MAE при большой | **Регрессия** (компромисс, робастна) |
| **Binary Cross-Entropy** | −[y log ŷ + (1−y) log(1−ŷ)] | **Бинарная классификация** (+ multi-label) |
| **Multi-class (Categorical) Cross-Entropy** | −Σ_k y_k log ŷ_k, метки one-hot | **Мультиклассовая классификация** |
| **Sparse Multi-class Cross-Entropy** | то же, но метки — целые числа, а не one-hot | **Мультиклассовая классификация** (экономия памяти) |
| **Hinge Loss** | max(0, 1 − y·ŷ), y ∈ {−1,+1} | Бинарная классификация (SVM), редко в DL |
| **Kullback–Leibler Divergence** | Σ p log(p/q) | Сравнение **распределений**: VAE, дистилляция, не «задача» из трёх |

**Ответ на задание из билета:**
- Regression problem → **2 (MSE), 5 (MAE), 6 (Huber)**
- Binary classification → **3 (Binary Cross-Entropy)** (и 7 Hinge, если разрешено несколько)
- Multi-class classification → **4 (Multi-class CE), 8 (Sparse Multi-class CE)**
- KL Divergence (1) — к этим трём задачам напрямую не относится (это про распределения / VAE / GAN); если надо обязательно распределить — ближе всего к мультиклассовой (CE = KL + энтропия метки).

## Ш.2 Задача ↔ выходная активация

| Задача | Активация выхода | Loss |
|---|---|---|
| Бинарная классификация | sigmoid (1 нейрон) | BCE |
| Мультикласс | softmax (K нейронов) | Categorical CE |
| Multi-label | sigmoid на каждом из K | Σ BCE |
| Регрессия | нет (linear) | MSE / MAE / Huber |
| Скрытые слои | ReLU / Leaky ReLU / GELU | — |

## Ш.3 Supervised / Unsupervised (задание на сопоставление)

| Метод | Тип |
|---|---|
| **CNN** | Supervised (обычно; классификация по меткам) |
| **RNN/LSTM** | Supervised (обычно; языковое моделирование — self-supervised) |
| **Autoencoder** | **Unsupervised** (self-supervised: вход = цель) |
| **GAN** | **Unsupervised** (генеративная модель без меток; CGAN — условная) |
| **Diffusion** | Unsupervised / self-supervised |
| **RL (DQN)** | Третий тип — **обучение с подкреплением**, ни то, ни другое |

> Тонкость для устного ответа: CNN и RNN — это **архитектуры**, а не режимы обучения; их можно обучать и без учителя (автоэнкодер на свёртках). Но в задании «сопоставьте» ожидают: CNN, RNN → supervised; AE, GAN → unsupervised.

## Ш.4 Две формулы, которые надо знать наизусть

**Размер выхода свёртки/пулинга:**
$$H_{out} = \left\lfloor \frac{H_{in} + 2p - d(k-1) - 1}{s}\right\rfloor + 1 \xrightarrow{\ d=1\ } \left\lfloor\frac{H_{in}+2p-k}{s}\right\rfloor+1$$

**Число параметров:**
- Dense: `n_in · n_out + n_out`
- Conv2D: `(k_h · k_w · C_in + 1) · C_out`
- Pooling / Flatten / активации / Dropout: **0 параметров**
- BatchNorm: `2 · C` обучаемых (γ, β) + 2·C буферов

## Ш.5 Что борется с переобучением, а что нет

✅ Dropout, L1/L2 (weight decay), Early stopping, Data augmentation, увеличение выборки, упрощение модели, BatchNorm (побочно), label smoothing, ансамбли.
❌ **Pooling** (это downsampling), увеличение числа эпох, увеличение размера модели, увеличение learning rate.

## Ш.6 Затухание и взрыв градиента

| Проблема | Лечение |
|---|---|
| **Затухание (vanishing)** | ReLU/Leaky ReLU, residual connections, BatchNorm/LayerNorm, LSTM/GRU, правильная инициализация (He/Xavier) |
| **Взрыв (exploding)** | **Gradient clipping**, нормализации, меньший lr, аккуратная инициализация. Функции активации тут **не помогают** |

## Ш.7 Формулы тем 8–17

**GCN:** $$H^{(l+1)} = \sigma\big(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}H^{(l)}W^{(l)}\big), \quad \tilde A = A + I$$
**GraphSAGE:** $$h_v^k = \sigma\big(W^k\cdot[\,h_v^{k-1}\,\|\,\text{AGG}(\{h_u^{k-1}\})\,]\big), \quad h_v^k \leftarrow h_v^k/\|h_v^k\|_2$$
**Attention:** $$\text{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$
**VAE:** $$L = \|x-\hat x\|^2 + D_{KL}\big(N(\mu,\sigma^2)\,\|\,N(0,I)\big), \quad z = \mu + \sigma\odot\varepsilon$$
**GAN:** $$\min_G\max_D\ \mathbb{E}\log D(x) + \mathbb{E}\log\big(1-D(G(z))\big), \quad L_G^{ns} = -\mathbb{E}\log D(G(z)), \quad D^* = \tfrac{p_{data}}{p_{data}+p_g}$$
**Диффузия:** $$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon, \qquad L = \|\varepsilon - \varepsilon_\theta(x_t,t)\|^2$$
**Classifier-free guidance:** $$\tilde\varepsilon = (1+w)\,\varepsilon_\theta(x_t,c) - w\,\varepsilon_\theta(x_t)$$
**Q-learning:** $$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\big]$$
**SARSA:** $$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\,Q(s',a')-Q(s,a)\big]$$
**TD(0):** $$V(s)\leftarrow V(s)+\alpha\big[r+\gamma V(s')-V(s)\big]$$
**REINFORCE:** $$\nabla_\theta J = \mathbb{E}\big[\nabla_\theta\log\pi_\theta(a|s)\,(G_t-b)\big]$$
**DQN loss:** $$\big(r+\gamma\max_{a'}Q(s',a';\theta^-)-Q(s,a;\theta)\big)^2$$
**FGSM:** $$x_{adv} = x + \varepsilon\,\operatorname{sign}\big(\nabla_x J(\theta,x,y)\big)$$

## Ш.8 Потери и метрики (тема 17)

| | Формула | Когда |
|---|---|---|
| Huber | ½e² при \|e\| ≤ δ, иначе δ(\|e\| − ½δ) | регрессия с выбросами |
| Focal | −(1 − pₜ)^γ log pₜ | дисбаланс классов |
| KL | Σ p log(p/q) | распределения; CE = H(p) + KL |
| Precision | TP/(TP + FP) | цена ложной тревоги |
| Recall | TP/(TP + FN) | нельзя пропускать |
| F1 | 2PR/(P + R) | баланс при дисбалансе |

**Диагностика:** высокая ошибка на train → смещение (модель больше, дольше обучать); train ≪ dev → дисперсия (регуляризация, данные, аугментация).
