# ШПАРГАЛКА: то, что спрашивают чаще всего

## Ш.0 Перед сном: сжатый конспект по главам

Каждая глава — полная срезка теории в коротком виде: суть, понятия, алгоритм, формулы, плюсы и минусы, ловушки. Прочитал → закрыл глаза → пересказал по памяти → сверился.

### Тема 1. Стохастическая оптимизация

**Суть.** Минимизируем эмпирический риск L(θ) — среднюю потерю. Шаг делаем против градиента, посчитанного по случайному **мини-батчу**: это несмещённая шумная оценка полного градиента, шум ∝ 1/B.

**Режимы.**
- **Batch GD** — все N объектов, 1 шаг за эпоху; точно, но медленно и не влезает в память.
- **Mini-batch** — B = 32–512, стандарт; эффективен на GPU, шум помогает выходить из седел.
- **Stochastic** — B = 1; очень шумно, годится для онлайн-обучения.

**Алгоритм SGD.** Инициализация (Xavier/He) → батч → forward + loss → backward → θ ← θ − η·g → повторять по эпохам.

**Методы.**
- **SGD** — один η для всех параметров; медленно в «оврагах»; у минимума колеблется.
- **Momentum:** v = γv + η·g, θ ← θ − v, γ ≈ 0.9. Гасит скачки поперёк оврага, ускоряет вдоль (шаг ×1/(1−γ) = ×10).
- **NAG:** градиент в точке «заглядывания» θ − γv; меньше перелётов; стоит как Momentum.
- **AdaGrad:** G += g², θ ← θ − η·g/(√G + ε). Свой шаг у каждого параметра, хорош для **разреженных** признаков; минус — G только растёт → шаг затухает.
- **RMSProp:** скользящее среднее g² (β ≈ 0.9) вместо суммы → шаг не затухает.
- **Adadelta:** вместо η — RMS прошлых обновлений.
- **Adam:** m = β₁m + (1−β₁)g, v = β₂v + (1−β₂)g², m̂ = m/(1−β₁ᵗ), v̂ = v/(1−β₂ᵗ), θ ← θ − η·m̂/(√v̂ + ε). Дефолты β₁ = 0.9, β₂ = **0.999**, ε = 1e-8, η ≈ 1e-3…3e-4. Bias correction нужна, потому что m₀ = v₀ = 0 занижает оценки. **AdamW** — weight decay отдельно от адаптивного шага.

**Плюсы/минусы Adam.** Быстро, мало настройки, стандарт для трансформеров. Минусы: память (m и v — втрое больше весов), иногда обобщает хуже SGD+momentum; при дообучении нужно восстанавливать **состояние оптимизатора**.

**Практика.** η слишком велик → расходимость, мал → медленно. Расписания (step, cosine), **warmup**, linear scaling (батч ×k → η ×k), **gradient clipping**: g ← c·g/‖g‖. Седловые точки и плато — шум SGD, momentum и адаптивные методы помогают.

**Ловушки.** v в Adam — E[g²], не дисперсия · NAG отличается от Momentum только точкой градиента · AdaGrad создан именно для разреженных данных · backprop считает градиент, оптимизатор решает, как шагать.

### Тема 2. Обратное распространение ошибки

**Суть.** Цепное правило + переиспользование промежуточных результатов = градиенты по **всем** весам за один обратный проход (reverse-mode AD). Backprop только считает градиент, веса обновляет оптимизатор.

**Понятия.** z = Wa + b (предактивация), a = σ(z), δˡ = ∂L/∂zˡ — «ошибка слоя».

**Алгоритм.**
1. **Forward:** zˡ = Wˡaˡ⁻¹ + bˡ, aˡ = σ(zˡ) до выхода; посчитать L; **сохранить** все zˡ, aˡ.
2. **Backward:** δᴸ = ∇ₐL ⊙ σ′(zᴸ); δˡ = (Wˡ⁺¹)ᵀδˡ⁺¹ ⊙ σ′(zˡ).
3. **Градиенты:** ∂L/∂Wˡ = δˡ(aˡ⁻¹)ᵀ, ∂L/∂bˡ = δˡ (размерность = размерности W).
4. **Update** оптимизатором; цикл: forward → loss → backward → update → обнулить градиенты.

**Формулы.** Softmax + CE (и sigmoid + BCE): δ = ŷ − y. Градиенты по разным путям суммируются. Gradient check: (L(θ+h) − L(θ−h))/2h.

**Недостатки.** Затухание градиента (σ′ ≤ 1/4 → (1/4)ᴸ) · взрыв (clipping, нормализация, инициализация) · память на активации (checkpointing) · backward locking · локальные минимумы и седла · нужна дифференцируемость.

**Ловушки.** Backprop ≠ градиентный спуск · от **взрыва** помогает clipping, а не ReLU/Leaky ReLU · sigmoid + MSE застревает (множитель σ′), поэтому для классификации CE · переобучение и «плохо с последовательностями» — не недостатки самого backprop (для RNN есть BPTT).

### Тема 3. Регуляризация

**Суть.** Всё, что уменьшает ошибку на **новых** данных, а не на обучающих. Переобучение: train низкая, val/test высокая.

**Методы.**
- **L2 (weight decay):** L + (λ/2)‖θ‖², шаг умножает веса на (1 − ηλ); **L1:** постоянное притяжение → нули, разреженность.
- **Early stopping:** остановка по валидации (patience), берём лучшие веса.
- **Аугментация:** отражения, повороты, crop, яркость, Cutout, Mixup; текст — синонимы, обратный перевод; преобразование не должно менять метку.
- **Label smoothing:** (1−α)·y + α/K.
- **Dropout:** обнуляем нейрон с вероятностью p, остальное делим на (1−p) (inverted dropout); на тесте **выключен**; ансамбль 2ⁿ подсетей; p = 0.5 в FC, 0.1–0.3 в CNN. Плюс: сильная регуляризация. Минусы: **замедляет** сходимость, плохо до BN (variance shift).
- **BatchNorm:** x̂ = (x − μ_B)/√(σ²_B + ε), y = γx̂ + β; γ, β обучаются; на тесте running mean/var. Плюсы: быстрее обучение, больший lr, лёгкая регуляризация. Минусы: плох при малом батче, разное поведение train/eval, неудобен для RNN.
- **Нормализации по осям:** BatchNorm (по батчу, на канал) · LayerNorm (по признакам объекта; трансформеры, RNN) · InstanceNorm · GroupNorm (малые батчи).

**Ловушки.** **Pooling — не регуляризация** · BN центрирует по **батчу**, не по датасету, и не «вариант dropout» · dropout не ускоряет обучение · больше эпох, модель больше, lr больше — не лечат переобучение.

### Тема 4. Функции активации

**Суть.** Нелинейность: без неё W₂(W₁x + b₁) + b₂ = W′x + b′ — сеть любой глубины линейна и не решает XOR. С нелинейностью — универсальный аппроксиматор.

**Функции.**
- **Sigmoid:** 1/(1+e⁻ˣ), (0, 1), σ′ = σ(1−σ) ≤ 1/4. Минусы: затухание, не центрирована, экспонента. Выход **бинарной** и **multi-label**, вентили LSTM.
- **Tanh:** (−1, 1), центрирована, tanh′ ≤ 1; всё ещё насыщается. RNN/LSTM.
- **ReLU:** max(0, x). Не насыщается при x > 0, дёшева, разреженность; минус — **dying ReLU**. Скрытые слои CNN/MLP.
- **Leaky ReLU:** αx при x ≤ 0 (α ≈ 0.01) — градиент не нулевой. PReLU (α обучается), ELU, GELU (трансформеры), Swish/SiLU.
- **Softmax:** e^{zᵢ}/Σe^{zⱼ}, сумма 1; инвариантна к сдвигу (вычитают max), температура T. Выход **мультикласса**.
- **Линейная:** выход регрессии.

**Задача ↔ выход ↔ потеря.** Бинарная: sigmoid + BCE · мультикласс: softmax + CE · multi-label: sigmoid на каждом выходе + сумма BCE · регрессия: линейный + MSE/MAE/Huber.

**Ловушки.** ReLU — для скрытых слоёв, а не «для регрессии» · sigmoid на выходе остаётся стандартом · недифференцируемость ReLU в нуле не мешает (субградиент) · мультикласс (softmax, сумма = 1) ≠ multi-label (независимые sigmoid).

### Тема 5. Сети прямого распространения: FCNN, MLP, перцептрон

**Суть.** Слои «умножить на W, прибавить b, применить активацию»; сигнал идёт **только вперёд**. Сети с обратными связями — RNN.

**Понятия.** Нейрон a = f(wᵀx + b); слои: входной (не считается), скрытые, выходной; полносвязный слой — каждый с каждым; глубина, ширина; параметры и гиперпараметры.

**Перцептрон Розенблатта.** S-элементы (сенсоры) → A-элементы (порог θ, связи ±1, 0) → R-элемент (сумматор с любыми весами). Элементарный, однослойный, многослойный по Розенблатту; **по Румельхарту** — все веса обучаются backprop (это современный MLP). Правило: w ← w + η(y − ŷ)x; сходится для линейно разделимых; **не решает XOR**.

**MLP.** f(x) = W_L·σ(…σ(W₁x + b₁)…) + b_L. Число параметров слоя n_in·n_out + n_out; 784→128→10: 101 770.

**Универсальная аппроксимация** (Cybenko, Hornik): один скрытый слой приближает любую непрерывную функцию на компакте. Это теорема **существования**: не говорит, что SGD найдёт веса, сколько нейронов нужно и как будет обобщение. Глубина экономнее ширины.

**Инициализация.** Все веса = 0 (или равны) → симметрия, **не обучится** (кроме регрессии без скрытых слоёв); **bias = 0 — нормально**. Xavier: Var(w) = 2/(n_in + n_out) (tanh/sigmoid); He: 2/n_in (ReLU).

**Плюсы/минусы MLP.** Универсален, прост, блок других сетей; много параметров, не учитывает структуру (пиксели, порядок слов), переобучается, фиксированный вход.

**Гиперпараметры** подбирают по валидации (grid, random, Optuna, Hyperband), **не** градиентом; test — один раз в конце.

**Ловушка.** Входы 1, 2, 3, веса 4, 5, 6, f(x) = 3x → (4 + 10 + 18)·3 = **96**. NN на линейной регрессии: один линейный нейрон — это и есть регрессия; стек линейных слоёв остаётся линейным.

### Тема 6. Свёрточные сети

**Суть.** Ядро скользит по входу; три идеи: **локальность**, **общие веса** (в разы меньше параметров), **эквивариантность к сдвигу** (инвариантность — приближённо, через pooling/GAP).

**Понятия.**
- **Kernel** — обучаемая матрица k×k×C_in; фильтров C_out → C_out карт признаков.
- **Padding:** valid (без) / same (p = (k−1)/2, размер сохраняется).
- **Stride** s — шаг; s = 2 вдвое уменьшает размер.
- **Dilation** d — пропуски; k_eff = d(k−1)+1, поле растёт без новых параметров.
- **Pooling:** max, average, **GAP** (карта → число на канал), adaptive (задаётся размер выхода); параметров нет.

**Формулы.** H_out = ⌊(H + 2p − d(k−1) − 1)/s⌋ + 1 · params = (k_h·k_w·C_in + 1)·C_out (**не зависит** от размера картинки, stride, padding) · рецептивное поле r_l = r_{l−1} + (k_l−1)·∏s.

**Виды свёрток.** 1×1 (смешивает каналы) · spatial separable (k×1, затем 1×k) · depthwise (своё ядро на канал) · **depthwise separable** = depthwise + 1×1 (≈ в 8 раз меньше параметров) · групповая · **транспонированная** (увеличение разрешения: H_out = (H−1)s − 2p + d(k−1) + 1).

**Слои.** Input → [Conv → BN → ReLU → Pool]×n → Flatten/GAP → FC → Dropout → softmax. ResNet: y = x + F(x).

**Backprop в свёртке.** ∂L/∂F = свёртка X с ∂L/∂O (градиенты со всех позиций **суммируются**); ∂L/∂X = свёртка ∂L/∂O с ядром, повёрнутым на 180° (= транспонированная свёртка). Max pooling: градиент только в позицию максимума; average — делится поровну; ReLU — обнуляет там, где вход < 0.

**Визуализация.** Градиентный подъём по **пикселям входа** при замороженных весах (максимизация активации), фильтры 1-го слоя, карты активаций, Grad-CAM, saliency, occlusion. Иерархия признаков: края → части → объекты.

**Состязательные примеры.** Малое возмущение → уверенная ошибка. FGSM: x + ε·sign(∇ₓJ) (один шаг), PGD — итеративно. Цель «похож на x₀, но класс y»: ½‖f(x) − y‖² + λ‖x − x₀‖². Защита: adversarial training, детектор.

**Ловушки.** Max pooling **не** «всегда уменьшает параметры» (у него их нет; косвенно — только следующий FC) · параметры не зависят от размера входа.

### Тема 7. Рекуррентные сети

**Суть.** Скрытое состояние hₜ = tanh(W_hh·hₜ₋₁ + W_xh·xₜ + b), yₜ = g(W_hy·hₜ + b_y); **общие веса** на всех шагах → любая длина. Выбор tanh/sigmoid, не ReLU: ограниченное состояние не «разбегается».

**Минусы vanilla RNN.** Затухание и взрыв градиента, нет параллелизма по времени, контекст «портится» шумом.

**BPTT.** Развернуть сеть по времени (T копий), forward по всем шагам, L = ΣLₜ, backward от конца к началу, градиенты общих весов **суммируются**; truncated BPTT — только k шагов назад. λ₁ < 1/γ → затухание; λ₁ > 1/γ → возможен взрыв (λ₁ — наибольшее сингулярное значение W_hh, γ = 1 для tanh, 1/4 для sigmoid). Clipping: если ‖g‖ ≥ τ, g ← τ·g/‖g‖.

**BiRNN.** Два прохода (→ и ←), состояния конкатенируются; видит прошлое и будущее; не годится для потока и генерации.

**LSTM.** Два состояния: cₜ (долгосрочное) и hₜ. Вентили: forget fₜ, input iₜ, output oₜ (σ); кандидат c̃ₜ = tanh(…). cₜ = fₜ⊙cₜ₋₁ + iₜ⊙c̃ₜ, hₜ = oₜ⊙tanh(cₜ). ∂cₜ/∂cₜ₋₁ = diag(fₜ) → градиент не затухает. Bias forget gate = 1. Параметры: 4·h(h + n + 1).

**GRU.** Два вентиля: update zₜ, reset rₜ; нет cₜ; hₜ = (1−zₜ)⊙hₜ₋₁ + zₜ⊙h̃ₜ. ≈ 3/4 параметров LSTM, быстрее; LSTM чуть лучше помнит.

**Генерация.** ⟨START⟩ → токен → на вход → … → ⟨END⟩; teacher forcing на обучении; проблема exposure bias.

**Dropout в RNN.** Наивный ломает память. Варианты: на эмбеддингах слов · только на нерекуррентных связях · **variational** (одна маска на все шаги) · recurrent dropout (вектор обновлений i⊙c̃). Zoneout.

**BatchNorm в RNN.** Recurrent BN: отдельно нормировать W_h·h и W_x·x; cₜ не нормировать; **статистики на каждый шаг свои**, γ, β общие; γ₀ = 0.1. Стандарт — **LayerNorm**.

**Ловушки.** BPTT ≠ обычный backprop: суммирование по времени и затухание · BiRNN нельзя для генерации · GRU-конвенция z может быть «перевёрнута».

### Тема 8. Графовые сети: GCN

**Суть.** Вершина усредняет признаки себя и соседей (нормировка по степеням), затем линейный слой + ReLU.

**Понятия.** G = (V, E), матрица смежности A, степень d, окрестность N(v), признаки X, лапласиан L = D − A; эквивариантность к перестановке вершин; трансдуктивное vs индуктивное обучение.

**Проблемы графов.** Нет регулярной структуры · произвольный порядок вершин (поэтому нельзя подать A в CNN) · масштабируемость.

**Message passing.** hᵥᵏ = UPDATE(hᵥᵏ⁻¹, AGGREGATE({hᵤᵏ⁻¹})); k слоёв = k-hop окрестность.

**Агрегации.** Сумма (помнит степень) · среднее (теряет степень) · симметричная нормировка (GCN) · max/pooling · set pooling (Deep Sets) · Janossy · LSTM (нужна перестановка) · **attention** (GAT) · GIN: MLP((1+ε)h + Σh) — достигает мощности теста Вейсфейлера–Лемана.

**Спектральный взгляд.** Графовое преобразование Фурье по собственным векторам L; полиномиальный фильтр p(L) локален (степень d → d-hop); ChebNet; GCN — первое приближение.

**GCN.** H′ = σ(D̃^{−1/2}ÃD̃^{−1/2}HW), Ã = A + I (самопетли), D̃ — степени Ã. Для вершины: Σ_{j∈N(i)∪i} h_j/√(d̃ᵢd̃ⱼ)·W. Модель: softmax(Â·ReLU(ÂXW⁰)·W¹), CE **только по размеченным** вершинам. **Renormalization trick:** у I + D^{−1/2}AD^{−1/2} спектр [0, 2] → нестабильность при стеке слоёв.

**Минусы.** Трансдуктивность · **over-smoothing** (лечат: меньше слоёв агрегации, skip/jumping knowledge, DropEdge, PairNorm) · over-squashing · веса соседей фиксированы (→ GAT) · весь граф в памяти.

**Граф целиком (readout).** Сумма/среднее по вершинам · [mean ‖ max] · LSTM · SortPool · иерархический pooling.

**DeepWalk.** Случайные блуждания → skip-gram; трансдуктивен, без признаков.

### Тема 9. GraphSAGE

**Суть.** Учит **функцию-агрегатор**, а не таблицу эмбеддингов → **индуктивность**: эмбеддинг новой вершины и новых графов без переобучения.

**Алгоритм** (для k = 1..K, h⁰ = x):
1. **Sample:** S_k соседей (K = 2, S₁ = 25, S₂ = 10; стоимость O(∏S_k), не зависит от степени).
2. **Aggregate:** hₙ = AGG({hᵤᵏ⁻¹}).
3. **Update:** hᵥᵏ = σ(Wᵏ·[hᵥᵏ⁻¹ ‖ hₙ]) — **concat** с собой.
4. **L2-нормировка** hᵥᵏ.

**Агрегаторы.** Mean · GCN (среднее вместе с собой, без concat) · **pooling** (σ(W·h + b), затем max) · LSTM (соседи в случайной перестановке — не строго инвариантен). Лучшие в статье — pooling и LSTM.

**Обучение.** С учителем — CE по меткам. Без учителя: J = −log σ(z_uᵀz_v) − Q·E log σ(−z_uᵀz_{vₙ}); v — сосед по короткому случайному блужданию, vₙ — отрицательные примеры. Мини-батчи: сначала сэмплируются окрестности «снаружи внутрь», потом считается «изнутри наружу».

**Плюсы.** Индуктивность, масштабируемость, использует признаки, concat смягчает over-smoothing. **Минусы.** Нужны признаки, шум сэмплирования, стоимость растёт с K.

**GCN vs GraphSAGE.** Трансдуктивный vs индуктивный · все соседи vs сэмплирование · full-batch vs мини-батчи · нормированное среднее vs concat · фиксированный агрегатор vs выбираемый.

### Тема 10. Трансформеры

**Суть.** Внимание вместо рекуррентности: каждый токен взвешенно собирает контекст из всех токенов, **параллельно**.

**Предыстория.** Seq2seq на RNN: кодировщик сжимает вход в один вектор c → bottleneck. Внимание Bahdanau: декодер на каждом шаге смотрит на все состояния кодировщика, веса α = softmax(e), c_t = Σα·h.

**Внимание.** Q = XW^Q, K = XW^K, V = XW^V; Attention = softmax(QKᵀ/√d_k + M)·V. Q — «что ищу», K — «по чему найти», V — «что отдам». **√d_k:** Var(q·k) = d_k, иначе softmax насыщается и градиент затухает. Маска M: −∞ для запрещённых.

**Виды.** Self · **masked** (decoder не видит будущее) · **cross** (Q из decoder, K и V из encoder). **Multi-head:** h голов (8, d_k = 64), Concat·W^O; разные подпространства.

**Encoder-блок.** MHA → Add & LayerNorm → FFN → Add & LayerNorm; N = 6. **FFN:** max(0, xW₁ + b₁)W₂ + b₂, 512→2048→512, по позициям независимо. Residual пропускает градиент. LayerNorm (не BN): по признакам вектора, Post-LN (оригинал) и Pre-LN (стабильнее).

**Decoder-блок.** Masked MHA → Add&Norm → cross-attention → Add&Norm → FFN → Add&Norm; вход — выход, **сдвинутый вправо**; в конце linear + softmax.

**Positional encoding.** Attention перестановочно-эквивариантен — порядка не знает. PE(pos, 2i) = sin(pos/10000^{2i/d}), PE(pos, 2i+1) = cos(…); бывают обучаемые, RoPE, ALiBi.

**Обучение/инференс.** Teacher forcing, все позиции параллельно; генерация по токену (greedy, beam, top-p, KV-cache). Label smoothing 0.1; BLEU = BP·exp(Σ¼ log pₙ) — n-граммная точность и штраф за краткость.

**Семейства.** Encoder-only (BERT) · decoder-only (GPT) · encoder-decoder (T5).

**vs RNN.** Параллелизм, путь O(1) · но память и время **O(n²)**, нужен PE, много данных.

### Тема 11. Автокодировщики и VAE

**Суть.** Encoder f: x → z (bottleneck) и decoder g: z → x̂; цель — восстановить вход, **без меток** (self-supervised). L = ‖x − x̂‖² (MSE) или BCE.

**Применения.** Снижение размерности (линейный AE ≈ PCA), шумоподавление, аномалии (большая ошибка реконструкции), предобучение, сжатие, генерация (VAE).

**Типы.** Undercomplete · **sparse** (штраф L1 или KL на активации) · **contractive** (штраф ‖∂f/∂x‖²_F) · **denoising** (шумный вход → чистый выход) · convolutional · LSTM-AE · masked AE.

**Проблема AE.** «Дырявое» латентное пространство, не генеративен; при коде ≥ входа выучит копирование.

**VAE.** Encoder выдаёт μ и log σ²; z = μ + σ⊙ε, ε ~ N(0, I) — **reparametrization trick** (градиент идёт через μ и σ). Loss = реконструкция + KL(q(z|x) ‖ N(0, I)); KL = −½Σ(1 + log σ² − μ² − σ²). Генерация: z ~ N(0, I) → decoder.

**ELBO.** log p(x) = ELBO + KL(q ‖ p(z|x)) ≥ ELBO: реконструкция снова + KL — нижняя граница правдоподобия.

**Баланс.** Сильный KL → posterior collapse (код игнорируется); β-VAE (β > 1) — распутанные представления ценой качества.

**VAE vs GAN.** VAE: устойчиво, есть энкодер, нижняя граница, **размытые** картинки. GAN: резкие, нестабильно, mode collapse.

**Ловушка.** VAE даёт **нижнюю границу**, а не точное правдоподобие.

### Тема 12. GAN

**Суть.** Генератор G(z) делает объекты из шума; дискриминатор D(x) — вероятность «настоящее»; игра min–max. D — обучаемая функция потерь для G.

**Функция оптимизации.** min_G max_D V = E log D(x) + E log(1 − D(G(z))).

**Теория.** D* = p_data/(p_data + p_g); тогда V = −log 4 + 2·JSD(p_data ‖ p_g); минимум при p_g = p_data, D = ½. Доказательство — для идеального случая в пространстве функций.

**Потери.**
- **D:** BCE, реальные = 1, подделки = 0.
- **G исходная:** log(1 − D(G(z))) — **насыщается** (градиент ∝ D ≈ 0 в начале).
- **G non-saturating:** −log D(G(z)) — подделкам метка 1, градиент ≈ −1.
- «Общая функция» — это сама игра V(D, G), а не сумма потерь.

**Обучение.** Чередовать: k шагов D (G заморожен, `detach`) → шаг G (D не обновляется, градиент течёт **через** D). Ищем равновесие, не минимум.

**Проблемы.** **Vanishing gradients** (сильный D; непересекающиеся многообразия, JSD = const) · **mode collapse** (одна мода) · отсутствие сходимости (вращение вокруг равновесия) · нет явной метрики → FID.

**Лечение.** Non-saturating loss · WGAN (расстояние Вассерштейна, критик 1-липшицев; clipping) · WGAN-GP (штраф на градиент) · spectral norm · LSGAN · TTUR · label smoothing.

**Ловушки.** Дискриминатор **нельзя** использовать как «яблоко/не яблоко» (в равновесии 0.5) · loss D в равновесии константа (log 4 для суммы, log 2 для среднего) · падение loss ≠ прогресс · GAN — обучение без меток.

### Тема 13. DCGAN

**Суть.** GAN из глубоких свёрточных сетей; loss тот же — новое только в **архитектурных правилах** стабильности.

**Правила.**
1. **Без pooling:** strided conv в D, транспонированные свёртки в G.
2. **Без полносвязных скрытых слоёв** (в G лишь проекция z, в D — выход в одно число).
3. **BatchNorm везде, кроме выхода G и входа D.**
4. **G:** ReLU, на выходе **tanh**; **D:** LeakyReLU (0.2), на выходе sigmoid.
5. **Adam** lr = 2e-4, **β₁ = 0.5**; веса N(0, 0.02); изображения в [−1, 1]; батч 128.

**Архитектура.** G: z (100) → 4×4×1024 → 8×8×512 → 16×16×256 → 32×32×128 → 64×64×3 (tanh); каждая ConvTranspose (k = 4, s = 2, p = 1) удваивает размер. D зеркален.

**Результаты.** Арифметика в латентном пространстве («мужчина в очках» − «мужчина» + «женщина»), плавная интерполяция, признаки D полезны для классификации.

**Минусы.** 64×64, mode collapse и нестабильность всё равно возможны, шахматные артефакты ConvTranspose (лечат: k кратно s или upsampling + conv).

### Тема 14. CGAN

**Суть.** Условие y (метка, текст, картинка) подаётся **и в G, и в D**: G(z, y), D(x, y); учится **условное** p(x | y).

**Функция оптимизации.** min_G max_D E log D(x|y) + E log(1 − D(G(z|y)|y)). Для каждого y — обычный GAN: D*(x, y) = p_data(x|y)/(p_data(x|y) + p_g(x|y)); минимум при p_g(x|y) = p_data(x|y).

**Зачем условие в D.** D оценивает пару (x, y): реален ли объект **и** соответствует ли он условию. Иначе G может игнорировать y.

**Как подают.** Конкатенация (one-hot к z; к входу D — как карты-константы) · embedding · **conditional BN** · projection discriminator · **AC-GAN** (D предсказывает класс).

**Обучение.** Реальные пары (x, y) → 1; (G(z, y), y) → 0; шаг G: метка 1 для пар с условием.

**Применения.** Управляемая генерация (MNIST «сгенерируй 7»), **pix2pix** (U-Net + PatchGAN + L1, λ = 100), text-to-image, super-resolution, inpainting.

**Плюсы.** Управляемость, быстрее и стабильнее сходимость, меньше mode collapse. **Минусы.** Нужны размеченные пары.

**Ловушка.** CGAN ≠ CycleGAN (тот без пар) и ≠ InfoGAN (коды без меток); игра ≠ оптимизатор.

### Тема 15. Диффузионные модели

**Суть.** Прямой процесс **фиксированно** зашумляет данные до чистого шума; обратный (обучаемый) шаг за шагом убирает шум. Генерация: шум → T шагов расшумления. Каждый шаг прост → обучение обычной регрессией (MSE).

**Прямой процесс.** q(x_t | x_{t−1}) = N(√(1−β_t)·x_{t−1}, β_t·I); T = 1000, β от 1e-4 до 0.02 (линейно). α_t = 1 − β_t, ᾱ_t = ∏α_s. **За один шаг:** x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε, ε ~ N(0, I); при t → T x_T ≈ N(0, I).

**Обратный процесс.** p_θ(x_{t−1} | x_t) = N(μ_θ, σ_t²I); дисперсия σ² = β_t или β̃_t (не обучается). Апостериорное q(x_{t−1} | x_t, x₀) гауссово с известным средним μ̃.

**Параметризация.** Сеть предсказывает **шум** ε_θ(x_t, t): μ_θ = (x_t − β_t/√(1−ᾱ_t)·ε_θ)/√α_t. **Loss:** L = ‖ε − ε_θ(√ᾱ_t·x₀ + √(1−ᾱ_t)·ε, t)‖² (MSE). Другие варианты: x₀-prediction, v-prediction. Связь со score: ε_θ ≈ −√(1−ᾱ_t)·∇log q_t.

**Алгоритмы.** Обучение: x₀ → t ~ U{1..T} → ε → x_t → шаг по ‖ε − ε_θ‖². Сэмплирование: x_T ~ N(0, I); для t = T..1: x_{t−1} = (x_t − (1−α_t)/√(1−ᾱ_t)·ε_θ)/√α_t + σ_t·z (z = 0 при t = 1).

**Сеть.** U-Net + skip + attention + эмбеддинг шага t (синусоидальный).

**Ускорение и управление.** DDIM (детерминированный, 20–100 шагов, та же сеть) · **латентная диффузия** (Stable Diffusion: диффузия в латентном пространстве автокодировщика, условие через cross-attention) · classifier guidance · **classifier-free guidance:** ε̃ = (1+w)·ε(x, c) − w·ε(x), **одна** сеть с выбрасыванием условия (p_uncond 0.1–0.2).

**Диффузия vs GAN.** Диффузия: устойчиво, разнообразно, лучше FID, но **медленно**. GAN: быстро, нестабильно.

**DALL·E.**
- **1:** dVAE (256×256 → 32×32 токена, словарь 8192) + трансформер 12 млрд параметров (текст ≤ 256 токенов + 1024 токена картинки) + ранжирование **CLIP**; диффузии **нет**.
- **2 (unCLIP):** текст → CLIP-эмбеддинг → prior → CLIP-эмбеддинг картинки → диффузионный decoder (64×64) → два upsampler до 1024; classifier-free guidance.
- **3:** упор на синтетические подробные подписи (recaptioning).

### Тема 16. Обучение с подкреплением

**Суть.** Агент в состоянии s выбирает действие a, среда отвечает наградой r и новым состоянием s′. Цель — максимизировать **return** G = Σγᵏ·r (= r + γG′), γ ∈ [0, 1]: дисконт, горизонт ≈ 1/(1−γ).

**Отличия от обучения с учителем.** Нет правильных ответов, награда отложенная и разреженная (credit assignment), данные не i.i.d. и зависят от политики, **исследование vs эксплуатация**. RL — **не** частный случай обучения с учителем.

**Понятия.** Агент, среда, состояние, действие, награда, эпизод, политика π(a|s), V(s), Q(s, a), модель среды P, R. **MDP** (S, A, P, R, γ); **марковское свойство:** будущее зависит только от текущего состояния; POMDP — неполное наблюдение (DQN → 4 кадра).

**Уравнения Беллмана.** V^π(s) = Σπ(a|s)·Σ P(s′|s, a)[R + γV^π(s′)]; оптимальность: **Q\*(s, a) = E[r + γ·max Q\*(s′, a′)]**. Оператор Беллмана — сжатие с коэффициентом γ → сходимость; π\* = argmax Q\*.

**Исследование.** Многорукий бандит; жадная · **ε-жадная** (с вероятностью ε случайное действие) · softmax (больцмановская, температура τ) · **UCB:** Q + c·√(ln t/N).

**Категории агентов.** model-based / model-free · value-based / policy-based / actor-critic · on-policy / off-policy.

**MC vs TD.** MC: обновление в конце эпизода по реальному G (без смещения, большая дисперсия). **TD:** V ← V + α(r + γV(s′) − V) — после каждого шага, бутстрэппинг (со смещением, меньше дисперсия).

**Q-learning** (model-free, off-policy, TD): **Q ← Q + α[r + γ·max Q(s′, ·) − Q]**; цель использует max, действовать можно ε-жадно. Сходится при бесконечном посещении всех (s, a), Σα = ∞, Σα² < ∞. **SARSA** (on-policy): в цели Q(s′, a′) для **реально выбранного** a′. Минус таблицы: состояний слишком много (Atari: 256^(84·84·4)).

**DQN.** Сеть Q(s, a; θ) вместо таблицы, выход — Q для всех действий. Loss = (r + γ·max Q(s′, a′; θ⁻) − Q(s, a; θ))². Два приёма: **experience replay** (буфер, случайные батчи → разрыв корреляций, данные используются повторно) и **target network** θ⁻ (копия, обновляется раз в C шагов → цель не «убегает»). Детали: 4 кадра, reward clipping, ε от 1.0 до 0.1, replay 1 млн, C = 10 000. Улучшения: Double DQN (выбор действия — θ, оценка — θ⁻), Dueling, Prioritized replay, Rainbow. Ограничения: **только дискретные** действия, переоценка Q.

**Policy gradient.** ∇J = E[∇log π(a|s)·G]; REINFORCE; **baseline** снижает дисперсию; **actor-critic:** actor = политика, critic = V, advantage A = r + γV(s′) − V(s). Подходит для непрерывных действий (DDPG, TD3, SAC, PPO).

### Тема 17. Потери, метрики, bias/variance, transfer learning

**Суть.** Потеря — то, что оптимизируем (дифференцируема); метрика — то, что оцениваем. Потери = −log правдоподобия: MSE ↔ гаусс, MAE ↔ лаплас, BCE ↔ Бернулли, CE ↔ категориальное.

**Регрессия.** **MSE** (штраф квадратичный, чувствительна к выбросам) · **MAE** (устойчива, постоянный градиент, нет гладкости в 0) · **Huber** (квадрат при |e| ≤ δ, линейно дальше) · MSLE (относительная ошибка, y ≥ 0) · Poisson (счётные данные).

**Классификация.** **BCE** (бинарная и multi-label) · **categorical CE** (one-hot) · **sparse CE** — та же потеря, метки-индексы · **KL** = Σp·log(p/q): несимметрична, не расстояние; **CE = H(p) + KL**, при one-hot p совпадают; VAE, дистилляция · hinge max(0, 1 − y·f) (SVM, нет вероятностей) · focal −(1−pₜ)^γ·log pₜ (дисбаланс). CE, а не MSE: градиент ŷ − y не затухает.

**Метрики.** Accuracy = (TP+TN)/всё (обманчива при дисбалансе) · precision = TP/(TP+FP) · recall = TP/(TP+FN) · F1 = 2PR/(P+R) · ROC-AUC. Нельзя пропустить → recall; дорога ложная тревога → precision. Регрессия: MAE, RMSE, R².

**Данные и диагностика.** train / dev / test (60/20/20; для больших данных 98/1/1), dev и test **из одного распределения**, test — один раз. **Train высокая** → высокое смещение (модель больше, дольше обучение, лучший оптимизатор). **Train ≪ dev** → высокая дисперсия (регуляризация, аугментация, больше данных). Error analysis — разбор ошибок dev вручную.

**Transfer learning.** Предобученная сеть → новая голова → заморозить ранние слои (или fine-tune с малым lr). Новые гиперпараметры: сколько слоёв заморозить, сколько добавить. Помогает при малых данных и близком домене; риск отрицательного переноса. **Multi-task** — общие слои, много данных у соседней задачи. **End-to-end** — без ручных признаков, меньше смещение, но нужно много данных.

**Ловушки.** Больше данных лечит дисперсию, но **не смещение** · MAE в потере ≠ L1-регуляризация (делает разреженными остатки, а не веса) · accuracy 99 % при 99 % класса «0» бесполезна.

## Ш.1 Функции потерь ↔ задачи (задание «сопоставьте» из билета)

| Функция потерь | Формула | Задача |
|---|---|---|
| **MSE (Mean Square Error)** | (1/n)Σ(y−ŷ)² | **Регрессия** (чувствительна к выбросам) |
| **MAE (Mean Absolute Error)** | (1/n)Σ\|y−ŷ\| | **Регрессия** (устойчива к выбросам, недифференцируема в 0) |
| **Huber Loss** | MSE при малой ошибке, MAE при большой | **Регрессия** (компромисс, робастна) |
| **Binary Cross-Entropy** | −[y log ŷ + (1−y) log(1−ŷ)] | **Бинарная классификация** (+ multi-label) |
| **Multi-class (Categorical) Cross-Entropy** | −Σ_k y_k log ŷ_k, метки one-hot | **Мультиклассовая классификация** |
| **Sparse Multi-class Cross-Entropy** | то же, но метки — целые числа, а не one-hot | **Мультиклассовая классификация** (экономия памяти) |
| **Hinge Loss** | max(0, 1 − y·ŷ), y ∈ {−1,+1} | Бинарная классификация (SVM), редко в DL |
| **Kullback–Leibler Divergence** | Σ p log(p/q) | Сравнение **распределений**: VAE, дистилляция, не «задача» из трёх |

**Ответ на задание из билета:**
- Regression problem → **2 (MSE), 5 (MAE), 6 (Huber)**
- Binary classification → **3 (Binary Cross-Entropy)** (и 7 Hinge, если разрешено несколько)
- Multi-class classification → **4 (Multi-class CE), 8 (Sparse Multi-class CE)**
- KL Divergence (1) — к этим трём задачам напрямую не относится (это про распределения / VAE / GAN); если надо обязательно распределить — ближе всего к мультиклассовой (CE = KL + энтропия метки).

## Ш.4 Две формулы, которые надо знать наизусть

**Размер выхода свёртки/пулинга:**
$$H_{out} = \left\lfloor \frac{H_{in} + 2p - d(k-1) - 1}{s}\right\rfloor + 1 \xrightarrow{\ d=1\ } \left\lfloor\frac{H_{in}+2p-k}{s}\right\rfloor+1$$

**Число параметров:**
- Dense: `n_in · n_out + n_out`
- Conv2D: `(k_h · k_w · C_in + 1) · C_out`
- Pooling / Flatten / активации / Dropout: **0 параметров**
- BatchNorm: `2 · C` обучаемых (γ, β) + 2·C буферов

## Ш.5 Что борется с переобучением, а что нет

✅ Dropout, L1/L2 (weight decay), Early stopping, Data augmentation, увеличение выборки, упрощение модели, BatchNorm (побочно), label smoothing, ансамбли.
❌ **Pooling** (это downsampling), увеличение числа эпох, увеличение размера модели, увеличение learning rate.

## Ш.6 Затухание и взрыв градиента

| Проблема | Лечение |
|---|---|
| **Затухание (vanishing)** | ReLU/Leaky ReLU, residual connections, BatchNorm/LayerNorm, LSTM/GRU, правильная инициализация (He/Xavier) |
| **Взрыв (exploding)** | **Gradient clipping**, нормализации, меньший lr, аккуратная инициализация. Функции активации тут **не помогают** |

## Ш.7 Формулы тем 8–17

**GCN:** $$H^{(l+1)} = \sigma\big(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}H^{(l)}W^{(l)}\big), \quad \tilde A = A + I$$
**GraphSAGE:** $$h_v^k = \sigma\big(W^k\cdot[\,h_v^{k-1}\,\|\,\text{AGG}(\{h_u^{k-1}\})\,]\big), \quad h_v^k \leftarrow h_v^k/\|h_v^k\|_2$$
**Attention:** $$\text{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$
**VAE:** $$L = \|x-\hat x\|^2 + D_{KL}\big(N(\mu,\sigma^2)\,\|\,N(0,I)\big), \quad z = \mu + \sigma\odot\varepsilon$$
**GAN:** $$\min_G\max_D\ \mathbb{E}\log D(x) + \mathbb{E}\log\big(1-D(G(z))\big), \quad L_G^{ns} = -\mathbb{E}\log D(G(z)), \quad D^* = \tfrac{p_{data}}{p_{data}+p_g}$$
**Диффузия:** $$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon, \qquad L = \|\varepsilon - \varepsilon_\theta(x_t,t)\|^2$$
**Classifier-free guidance:** $$\tilde\varepsilon = (1+w)\,\varepsilon_\theta(x_t,c) - w\,\varepsilon_\theta(x_t)$$
**Q-learning:** $$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\big]$$
**SARSA:** $$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\,Q(s',a')-Q(s,a)\big]$$
**TD(0):** $$V(s)\leftarrow V(s)+\alpha\big[r+\gamma V(s')-V(s)\big]$$
**REINFORCE:** $$\nabla_\theta J = \mathbb{E}\big[\nabla_\theta\log\pi_\theta(a|s)\,(G_t-b)\big]$$
**DQN loss:** $$\big(r+\gamma\max_{a'}Q(s',a';\theta^-)-Q(s,a;\theta)\big)^2$$
**FGSM:** $$x_{adv} = x + \varepsilon\,\operatorname{sign}\big(\nabla_x J(\theta,x,y)\big)$$

## Ш.8 Потери и метрики (тема 17)

| | Формула | Когда |
|---|---|---|
| Huber | ½e² при \|e\| ≤ δ, иначе δ(\|e\| − ½δ) | регрессия с выбросами |
| Focal | −(1 − pₜ)^γ log pₜ | дисбаланс классов |
| KL | Σ p log(p/q) | распределения; CE = H(p) + KL |
| Precision | TP/(TP + FP) | цена ложной тревоги |
| Recall | TP/(TP + FN) | нельзя пропускать |
| F1 | 2PR/(P + R) | баланс при дисбалансе |

**Диагностика:** высокая ошибка на train → смещение (модель больше, дольше обучать); train ≪ dev → дисперсия (регуляризация, данные, аугментация).
