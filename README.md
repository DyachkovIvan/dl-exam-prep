# Экзамен по Deep Learning — подготовка

Статический сайт для подготовки к экзамену по глубокому обучению: конспект по 16 темам,
шпаргалка с формулами, тренажёр с интервальным повторением, режим экзамена на время
и калькуляторы для расчётных задач.

Ни сборки, ни зависимостей: обычные HTML, CSS и ES-модули. Контент лежит рядом в markdown —
чтобы добавить тему или вопрос, трогать код не нужно.

## Запуск

Открывать `index.html` двойным кликом **нельзя**: страница подгружает файлы из `content/`,
а браузер запрещает такие запросы с `file://`. Нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# или
npx serve .
```

Дальше — `http://localhost:8000`.

## Публикация на GitHub Pages

```bash
git remote add origin git@github.com:<ваш-логин>/dl-exam-prep.git
git push -u origin main
```

В настройках репозитория: **Settings → Pages → Source → GitHub Actions**. Дальше каждый push
в `main` публикует сайт (workflow лежит в `.github/workflows/pages.yml`). Сайт будет на
`https://<ваш-логин>.github.io/dl-exam-prep/`.

Если репозиторий должен остаться приватным, Pages доступен на платных планах; альтернатива —
Netlify или Vercel: они точно так же раздают папку целиком, настройки сборки не нужны.

## Как править контент

**Добавить тему.** Положите файл в `content/theory/`, первой строкой — `# Тема 17. Название`,
и допишите запись в `content/manifest.json`:

```json
{ "num": 17, "id": "ssl", "title": "Self-supervised learning", "file": "content/theory/17-ssl.md" }
```

Порядок вкладки «Теория» и оглавления определяется порядком записей в манифесте.

**Добавить вопросы.** Откройте нужный файл в `content/questions/` и допишите в конец:

```markdown
**F13. Почему в ResNet помогают skip-connections?**
Градиент получает короткий путь к ранним слоям: производная блока x + F(x) содержит
слагаемое 1, поэтому не затухает с глубиной. Плюс сети проще выучить тождественное
отображение, если слой не нужен.
```

Правила разбора простые:

- строка вида `**<ID>. <текст вопроса>**` начинает новый вопрос;
- всё до следующего такого заголовка — ответ (можно markdown: списки, таблицы, формулы);
- **ID должен быть уникальным и больше не меняться** — по нему хранится прогресс повторений.
  Переименуете `F13` — карточка станет новой и потеряет историю.

**Новый блок вопросов.** Создайте файл `content/questions/N-тема.md`, начните его строкой
`## Блок N. Название блока` и добавьте запись в `manifest.json` → `questions`.

**Формулы.** Пишутся в LaTeX между `$$ ... $$` на отдельной строке, рендерит MathJax.
Строчные формулы внутри абзаца лучше писать юникодом (`σ(x) = 1/(1+e⁻ˣ)`) — так надёжнее.

**Ловушки.** Цитата, начинающаяся с ⚠️, превращается в красную выноску «Ловушка»:

```markdown
> ⚠️ Pooling не является методом регуляризации.
```

## Как работает интервальное повторение

Алгоритм SM-2 (`assets/js/srs.js`), по одной карточке на вопрос:

| Оценка | Что происходит |
|---|---|
| Не знал | карточка возвращается в этой же сессии, фактор лёгкости падает на 0.2 |
| Трудно | интервал растёт слабо (×1.2) |
| Знаю | интервал умножается на текущий фактор лёгкости (≈2.5) |
| Легко | интервал растёт быстрее и фактор лёгкости подрастает |

Режим «К повторению» показывает только карточки, у которых наступила дата; «Трудные» —
те, что забывались дважды и больше. Клавиши: `пробел` — показать ответ, `1`–`4` — оценка.

Весь прогресс лежит в `localStorage` этого браузера. Кнопки «Выгрузить / Загрузить прогресс»
переносят его на другое устройство одним JSON-файлом.

## Работа без интернета

По умолчанию `marked` и `MathJax` подключаются с CDN. Чтобы страница работала офлайн
(например, в дороге перед экзаменом), скачайте их локально:

```bash
bash scripts/vendor.sh
```

Скрипт положит библиотеки в `assets/vendor/` и подскажет, какие две строки в `index.html`
заменить на локальные пути.
